# AI 重命名词库

在选项中开启 Beta 后，进入 **选项 → 词库管理**。图片 / 视频 AI 标签和视频语义重命名界面都有 **选择词库 / 类别** 按钮，可搜索、按类别批量勾选，跨词库选择会分别保存到 JoyTag 与语义匹配配置中。下方输入框可以补充候选，同名词优先使用输入框内容。

内置词库无需下载模型即可浏览：

- 常用分类：中文名称，包含动物、植物、景色、人物外观、服饰、活动、物体及成人标签。
- JoyTag：模型的全部 5813 个固定标签。不能用于文件名的原始标签使用稳定的安全名称，原词仍显示在描述和模型标签中。
- Open Images：Google LLC 公布的 V7 boxable class descriptions，共 601 条名称；根据官方的 600 类层次文件归类。原始名称与层次数据为 CC BY 4.0，来源与归类方式见 `licenses/open-images/NOTICE.md`。
- 内容分级候选：NSFW / 非 NSFW 的语义描述，只用于视频语义匹配，需人工确认。JoyTag 没有专门的 SFW / NSFW 分级输出，不能以未检测到成人标签作为非 NSFW 结论。

JoyTag 选择器只允许选择模型支持的标签；Open Images 和任意自定义描述可用于语义匹配。大量候选按每批最多 32 个词生成嵌入，编码进度可见；每次匹配最多 20000 个候选。JoyTag 命名取达到阈值且分数最高的三个词，并遵守命名标签的 100 字符限制；语义匹配仍取最高相似度候选并检查阈值、分差。

## 自定义与交换

可以新建词库、复制内置词库后修改、编辑或删除自定义词库。导入支持 TXT、TSV、JSON，导出为 JSON。JSON 与应用导出的 `WordLibrary` 结构相同。

TXT 每行一个名称，或 `名称=语义描述`。TSV 使用 Tab 分隔四列：

```text
类别    名称    语义描述    JoyTag标签
动物    猫      A photo of a cat.    cat
人物外观    黑长发    A person with long black hair.    black_hair+long_hair
```

最后一列可空，表示仅供语义匹配；组合标签用 `+` 表示需要全部达到阈值。名称在同一词库内不能重复，语义描述最多 512 字符。每个词库最多 20000 个词，导入文件最多 8 MB。词库与候选选择原子保存到当前用户本地应用数据目录 `AvaMedia/word-libraries.json`。

## 处理可视化

分析面板显示实际阶段、采样 / 推理进度、用时与近期进展；展开“阶段结果”可查看已解码画面、采样时间及中间标签 / 相似度。画面复用现有采样结果，不另行抽帧或计算。阶段分数在全部采样结束前会变化，源文件仅在用户预览并执行重命名后修改。
