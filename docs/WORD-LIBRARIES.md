# AI 重命名词库

在选项中开启 Beta 后，进入 **选项 → 词库管理**。图片 / 视频 AI 标签和批量重命名界面都有 **选择词库 / 类别** 按钮，可搜索、按类别批量勾选，跨词库选择会分别保存到 JoyTag 与语义匹配配置中。下方输入框可以补充候选，同名词优先使用输入框内容。

内置词库无需下载模型即可浏览：

- 人物特征：发色、头发、身体、乳房、眼睛、面部、配饰、动作姿态、神态表情、体毛十类中文候选词。可分别选择眼镜、发色、发型、体型、肤色、站坐姿态、微笑、闭眼、体毛等标签，也可整类选择并跨类别累积。类别显示候选数量，自定义词库可自行填写类别。体毛包含阴毛、腋毛、胸毛、腿毛及胡须等模型实际支持的候选；没有毛发密度、修剪方式等独立模型标签时，不提供这些识别选项。
- NSFW 识别标签：68 个 JoyTag/Danbooru 固定词表中的候选，按裸露、性行为、衣着、身体、体毛、接触、道具、场景、遮挡分组。风险与提示分开；衣着或体毛单独命中不会产生“疑似 NSFW”结论。可用于图片 / 视频标签分析和语义匹配。
- NudeNet 分类：上游 18 个裸露、遮挡及上下文类别，带中文名称及原类别编号。仅用于语义候选；未接入 NudeNet 检测模型，不等同于 NudeNet 检测结果，也不映射为不存在的 JoyTag 标签。
- 常用分类：中文名称，包含人物特征、动物、植物、景色、服饰、配饰、活动、物体及成人标签。
- JoyTag：模型的全部 5813 个固定标签，已映射的特征按类别归组，其余显示为“其他标签”。不能用于文件名的原始标签使用稳定的安全名称，原词仍显示在描述和模型标签中。
- Open Images：Google LLC 公布的 V7 boxable class descriptions，共 601 条名称；根据官方的 600 类层次文件归类。原始名称与层次数据为 CC BY 4.0，来源与归类方式见 `licenses/open-images/NOTICE.md`。
- 内容分级候选：NSFW / 非 NSFW 的语义描述，只用于视频语义匹配，需人工确认。JoyTag 没有专门的 SFW / NSFW 分级输出，不能以未检测到成人标签作为非 NSFW 结论。

JoyTag 选择器只允许选择模型支持的标签；Open Images 和任意自定义描述可用于语义匹配。大量候选按每批最多 32 个词生成嵌入，编码进度可见；每次匹配最多 20000 个候选。JoyTag 命名使用全部达标标签，不限制匹配数量；名称过长时在预览中报错，单个候选名称最多 100 字符；语义匹配仍取最高相似度候选并检查阈值、分差。

NSFW 自动判断与标签导出见 [NSFW 标签识别](NSFW-REVIEW.md)。增加词库只整理既有模型输出，不改变权重或校准效果。

## 自定义与交换

可以新建词库、复制内置词库后修改、编辑或删除自定义词库。导入支持 TXT、TSV、JSON，导出为 JSON，复制和导入时保留原词库的来源信息。JSON 与应用导出的 `WordLibrary` 结构相同。

TXT 每行一个名称，或 `名称=语义描述`。TSV 使用 Tab 分隔四列：

```text
类别    名称    语义描述    JoyTag标签
动物    猫      A photo of a cat.    cat
头发特征    黑长发    A person with long black hair.    black_hair+long_hair
```

最后一列可空，表示仅供语义匹配；组合标签用 `+` 表示需要全部达到阈值。名称在同一词库内不能重复，语义描述最多 512 字符。每个词库最多 20000 个词，导入文件最多 8 MB。词库与候选选择原子保存到当前用户本地应用数据目录 `AvaMedia/word-libraries.json`。

## 处理可视化

分析面板显示实际阶段、采样 / 推理进度、用时与近期进展，并直接显示当前采样缩略图和近期候选分数；展开“阶段结果”可查看较大画面、采样时间和近期记录。画面复用现有采样结果，不另行抽帧或计算。阶段分数在全部采样结束前会变化，源文件仅在用户预览并执行重命名后修改。
