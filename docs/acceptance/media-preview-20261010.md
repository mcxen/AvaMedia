# 媒体复用端到端验收（2026-10-10）

用户明确要求端到端测试并在通过后推送标签。本轮围绕任务封面、共享图片编解码、剪辑浏览和天池播放器进行验收。

## 发现及修复

- 转换来源列表重排时，Avalonia 回收列表项会把空数据交给模板，模板读取 `Include` 导致崩溃。模板现在在空项时返回空控件。
- 多来源快速剪辑工作区保存或刷新时也会回收空项；同样修复该模板，保存后可继续编辑其他来源并导出。
- 测试入口按当前界面更新：展开精确坐标、匹配来源列表、键盘按下及释放、等待后台检测启动、关闭后继续检测、多来源工作区、源格式默认值、仅加入队列及内联参数错误。

## 缓存和图片证据

- 四个并发相同视频缩略图请求只启动一次 FFmpeg，返回相同帧字节。
- 相邻逐帧操作只查询一次时间戳窗口。全新进程读取缓存后，视频帧解码及 `-show_frames` 查询均为零；该进程仍需一次普通媒体探测以获取当前媒体信息。
- 全新进程命中任务缓存时，封面字节保持一致，任务预览读取不再探测源文件。摘要没有完整 `RawJson`。
- 测试样本封面 PNG 为 11,877 字节，本地压缩后为 4,692 字节，减少 60.5%；压缩图可以正常解码。该数值是本样本结果。
- 损坏缓存校验数据后重新解码一次并恢复相同源帧；修改源文件时间后，帧、时间戳及任务封面均失效并重建。
- 普通图片读取、旋转导出、缩略图、任务封面及实际 WebP 压缩队列没有启动外部媒体进程。WebP 输出尺寸为 180 × 101，原图字节保持不变。
