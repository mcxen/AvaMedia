# 设置与输出配置走读 · 2026-10-10

当前主分类固定为软件通用、转换、本地模型、在线 AI、工具。版本更新并入软件通用；加载与预热是本地模型页内的子页，MCP 放在工具页。

## 布局与交互调整

| Before | After | Why |
| --- | --- | --- |
| 更新、外观、后台等小分组分散在主分类 | 5 个主分类，软件通用集中常用软件偏好 | 减少寻找入口和切页 |
| 横向标签挤占宽度，表单嵌套卡片 | 左侧固定导航，正文独立滚动，平铺标题和字段 | 保留可读标签与字段空间 |
| 预热比例只有孤立数字 | CPU / GPU 两列，滑条和数字同行；初始比例约束后续比例 | 看清两个阶段并直接调整 |
| 模型操作占据名称空间，列表首屏很少 | 下载设置折叠，名称独占一行，下载与更多固定位置 | 模型名和状态易于扫描 |
| 进入新页后数字初始化会让应用亮起，未访问预热页可能阻止保存 | 数字按值比较草稿，读取尚未格式化的初始值 | 切页不制造修改，首次保存可靠 |
| 切皮肤时模板可能重置页面 | 应用后恢复所选页面与滚动位置 | 保持用户当前位置 |
| 轨道选择器未继承 ComboBox 样式，呈现空白 | 使用 ComboBox 模板，显示已选轨道 | 字段可读且可操作 |
| 一两个文件选项独立占一个输出分类 | 音频、图片、无音轨视频和抽帧的导出字段合入当前页；单页取消侧栏 | 少量选项直接可见 |

## 实际本地走读

使用 macOS ARM64 本地原生窗口，直接实例化生产 `SettingsWindow` 和 `OptionsWindow`，加载生产皮肤、字段、动效与语言样式。走读程序和观测记录位于忽略目录 `artifacts/settings-review-20261010/`。保存只写隔离的 `state` 目录，没有写用户队列与主应用配置。

- 基线与调整后均实际打开设置页面。最终五个主分类、两个模型子页和全部九种输出配置均已逐页读取原生无障碍树；关键页面已查看实际窗口截图。
- 首次未访问预热页时更改文件名选项并应用：保存成功，停留软件通用，应用恢复禁用。
- Ctrl / Cmd + F 搜索 JPEG、更新 / Updates、CPU；CPU 自动进入模型预热子页，更新组完整滚入视区；Escape 清除搜索。
- 多线程关开时数字和滑条同步禁用 / 恢复。自动更新关开时静默更新同步禁用 / 恢复，恢复原值后应用仍禁用。
- 初始 CPU 从 30 调到 70 时，选素材后的 CPU 从 60 自动提高到 70；恢复 30 / 60 后草稿无修改。
- 模型搜索 Qwen 只保留两条匹配模型，下载设置可展开，更多菜单可打开。没有启动下载、导入、校验或删除。
- Light、Dark、Mac OS 9、Windows XP 实际切换；英文实际应用；880×620 最小窗口已查看。皮肤应用保持页面及滚动位置，字段与固定底部操作可用。
- 输出轨道下拉显示“第 1 条”；图片、音频输入、抽帧单页完整显示字段，没有空侧栏。剪辑导出确认可读取默认草稿并关闭。
- 字幕的烧录、保留源轨、附加外部轨三种模式实际展开，轨道、样式、语言与文件字段可见。

这些证据覆盖窗口布局、切页、条件字段和上述草稿交互。没有执行网络获取、系统菜单 / 播放器注册、MCP 服务启用、模型推理、媒体输出或性能测试。关闭设置不取消模型下载沿用应用级 `ModelDownloads` 的生命周期，本轮未执行下载回归。
