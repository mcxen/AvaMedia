# VR 样片验收

日期：2026-10-08。环境：macOS 15.7.1 / Apple Silicon，原生 Avalonia 天池播放器。

按用户“找几个 VR 视频测试一下”的要求下载公开样片，在独立测试实例中播放。功能验收基于 `1324c35` 加本次 VR 修复，提交前再对最新已提交源码加同一修复执行 Desktop/Core 编译。测试实例仅替换启动时的设置存储目录，关闭更新检查和模型自动安装；播放器、解码、投影与截图代码使用实际产品实现。

## 操作证据

- Minecraft：拖动后 yaw `-10.6804°`、pitch `2.8481°`；滚轮将视野从 `90°` 调到 `120°`。Cmd+E 成功保存透视 PNG；R 将方向和视野恢复至 `0° / 90°`。通过 Tab 和方向键切换右眼，播放器没有误调音量或切入全屏。
- Congo：暂停后仍可旋转。yaw 从 `66.1061°` 连续增加 `120°`，回绕为 `-173.8939°`；同一时间 `00:00:09.610` 分别保存上眼和下眼画面，截图包含正确视角，没有播放器控件。
- Alcatraz：暂停在 `00:00:07.100`，拖动同步修改 yaw / pitch，滚轮将视野调至 `30°`；回正后通过设置控件将 roll 调至 `5°`，再次截图。记住设置按钮确认保存，独立存储文件包含该视频的旋转参数。Enter 成功进入全屏，VR 面板保留。
- 六张 PNG 均为 `1672 × 1264`，文件内容已生成；其中 Minecraft 与 Congo 的导出视角做了实际图像检查。

## 发现与修复

1. 视频区域的指针事件抢走设置面板焦点，影响下拉框与键盘操作。过滤 VR 面板、播放列表和快捷键面板的事件，滚轮及右键也保留给控件。
2. 截图在软件画布执行运行时着色器时卡住。改为独立 CPU 球面投影和双线性采样；实际 PNG 保存复验通过。软件绘制采用同一路径，绘制操作持有帧引用直到释放。
3. 原生播放期间切入 VR 时增加会话接管处理。此路径通过编译检查，本轮三段样片使用内置播放器，未单独进行原生会话接管回归。

本轮没有验证 Windows、头显输出、180° 鱼眼素材或软件后端的连续视频播放，也没有进行性能、压力或全量播放器测试。
