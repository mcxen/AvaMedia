# 媒体分类链路精简与消融对照

日期：2026-10-11。基线：`a7c91d5`；精简实现：`d0d988d`。范围为导入、规则与分析、服装分组、任务快照、列表与预览、目录规划、整理及撤销；同时检查了 MCP 分类与整理入口是否复用这条链路。

## 逐环节处理

| 环节 | 删除或合并的工作 | 保留的边界 |
| --- | --- | --- |
| 导入扫描 | 重扫后逐文件在完整路径数组中查找，改为一次构建集合 | 输出目录排除、符号链接与循环跳过、访问错误展示 |
| 规则与分析 | 删除每张媒体及中间推理结果的重复规则校验；只按类型分类不启动 AI，也不探测视频 | 编辑与任务入口校验；按时长分类仍探测视频；模型共享缓存、每文件暂停检查点 |
| 结果发布 | 最终结果不再先按中间结果分类一次；总数与服装完成状态不再每次遍历全批特征向量 | 部分结果、错误、取消及文件级检查点 |
| 服装分组 | 无服装规则直接返回；删除重复人工状态投影、未使用的平均特征、重复背景代表计算；聚类对称样本对及样本对类别分数复用 | 拍摄背景、颜色冲突、完整链接约束、采样一致率与人工确认 |
| 分组标题 | 只在分组产出阶段生成，删除任务读取及目录规划时的再次加工 | 当前任务保存完整标题，不增加旧格式迁移 |
| 任务打开与保存 | 删除每装载 64 个条目就重建列表的步骤、重复等待同一个保存任务 | 分段让出 UI 线程、保存串行化及失败重试 |
| 列表与封面 | 每份不可变媒体结果只完整检查一次服装向量；封面读取合并重复文件元数据查询 | 新结果重新检查；缓存仍校验源文件大小和修改时间 |
| 目录预览 | 预览计划按路径索引，删除逐项从整份计划查找 | 重名处理、输出路径与源文件检查；上一轮已将目录计算移到后台 |
| 整理与撤销 | 移动与复制的界面恢复共用一条路径，删除嵌套查找和重复日志读取分支；普通界面刷新不再读撤销日志 | 执行时重新读取日志，保留独占写入、内容哈希、不覆盖、复制后删源和撤销日志 |
| MCP | 继续共用分类服务和目录规划；未另建执行链路 | 提交时重新核对用户确认的目录计划，防止预览后的文件或目标变化 |

## 消融结果

使用同一份定向检查程序，分别载入修改前保留的 Core/Desktop 程序集和修改后的程序集。基线通过 69 项检查；精简版通过 72 项，增加的断言对应类型分类免推理、向量检查次数、聚类比较次数。

- **25 组快照完全一致**：预设分类结果、服装分组、人工服装调整及目标目录；包含类别、分数、证据、帧、标题和标签。
- **连续 5 次列表状态查询**：完整服装向量检查从 **5 次降到 1 次**；替换媒体结果后会重新检查。
- **3 个样本的完整链接聚类对照**：相似度计算从 **5 次降到 3 次**，分组仍为 `[[a,c],[b]]`。
- **只按类型分类**：两个文件完成分类，视频探测为 0 次，未访问模型或解码器。
- **中断续跑**：首个文件的完成状态保留，恢复后只探测待处理视频；再次执行已完成任务不重复探测。
- **文件整理**：复制与移动、同名目标处理、报告写入和撤销通过；原文件及整理后文件的哈希符合预期。
- 缺失采样继续进入待确认，人工选择保留，源文件身份改变后不复用人工选择；私密规则关闭时不出现在分类结果中。

消融比较的是上述删改组合及两处明确的调用次数变化，没有将结果归因于每个独立删改，也没有测量整机速度提升比例。
