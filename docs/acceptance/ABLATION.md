# 媒体处理消融

采用固定源媒体和固定编码器，先执行完整配置，再每次仅关闭一个处理环节。通过 `MediaEngine.Execute` 生成媒体，使用 ffprobe、解码后的 RGB 和 PCM 测量结果；生产功能保持启用。

视频完整配置包含剪辑、裁剪、缩放、旋转、翻转、变速、淡入淡出、区域模糊和字幕烧录。音频完整配置包含剪辑、变速、音量、倒放、回声、降噪、淡入淡出、采样率转换与声道转换。共 18 组消融、20 个实际输出、35 项检查。

### 真实模型补充验证

按用户追加要求，使用同一批源码快照执行真实推理，验证提交为 `8fb5e3c`。本地使用已安装的 Huihui Qwen3.5 4B Q4_K_M、视觉投影权重和实际 llama-server；线上使用用户已配置的 `dots3-note-prev`。凭据由生产 `Storage.LoadSettings()` 读取，没有写入报告、源码或日志。

每组分别执行本地、线上三条链路：单图描述、关闭补帧的视频描述、开启补帧的视频描述。检查程序调用生产 `MediaCaptionSession`、`MediaCaptionService` 和 `MediaCaptionFrameTool`；未替换模型回复、工具结果或抽帧。视频沿用普通行人场景切换到绿色空画面的八秒样例，实际采样时间为第 2、6 秒。

这些通过项证明执行链路与资源所有权，不代表完整事实准确率。合并组本地、线上均正确描述行人场景与绿色空画面的切换。保留的内容问题包括：仅会话复用组的一次线上工具描述把绿色空画面说成黑屏，实际返回 PNG 与其他线上组的 SHA256 完全相同，核对画面为绿色；部分本地描述仍推测场所用途或细节。提示要求取第 1、6 秒，原始组和合并组的本地模型实际请求第 2、6 秒，其余本地组和全部线上组请求第 1、6 秒；工具均正确返回模型实际请求的画面。因此没有把工具调用成功等同于严格遵循提示或内容完全准确。
