# 本地界面走查 · 2026-10-10

在 macOS 上启动原生 Avalonia 窗口，通过桌面控件和截图走查。基础提交为 `72c5ff4`，构建包含当前共享工作区源码。设置、任务队列与播放偏好使用独立目录，未修改用户原队列。

临时启动器复用生产 `MainWindow`、全部生产主题和工具窗口。媒体探测、缩略图、播放器与 JoyTag 模型预热使用真实后端；总结、标签与下载的长时间队列执行使用受控进度执行器，调用生产队列的暂停、继续和调度逻辑。该走查不证明真实总结、标签识别或网络下载的执行结果。

## 走查发现及修复

| Before | After | Why |
| --- | --- | --- |
| AI 任务暂停时，紧凑进度条和节点进度条直接退出布局，详情内容向上移动。 | 5 DIP 与 6 DIP 的进度槽始终保留，仅隐藏槽内进度条。 | 暂停和继续不改变内容位置。 |
| 任务状态标签随“运行中 100%／已暂停”等文字改变宽度，执行按钮在切换时采用不同的宽度样本。 | 状态预留中英文最长文本，暂停与继续使用相同的按钮宽度样本。 | 百分比跨位数及状态切换不挤压相邻元素。 |
| 预热状态文字插入按钮前的自动换行容器，推动停止、释放和模型管理按钮；预热进度显隐改变行高。 | 预热／停止共用固定槽，释放与模型管理各有固定列，状态放在剩余宽度内并保留两行，预热进度保留 3 DIP 槽。 | 真实模型加载、停止、完成、释放均保持按钮位置。 |
| 英文界面的 AI 耗时控件把已经格式化的译文当作用户原文，显示中文“已用时”。 | 耗时标签使用翻译文本处理。 | 英文界面显示 `Elapsed` 并保留数字宽度。 |
