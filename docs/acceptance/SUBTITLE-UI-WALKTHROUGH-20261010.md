# 自动字幕界面走读

2026-10-10，以 `v1.1.67`（`9e1c6ca`）为基线，使用生产 `SpeechToolsWindow`、`SubtitleReviewWindow`、`SubtitleStyleEditor` 在 macOS 原生 Avalonia 窗口走读。设置、保存的工具偏好及走读程序位于本地 `artifacts/subtitle-review-20261010/`，隔离源码位于 `artifacts/subtitle-source-20261010/`；未使用日常任务队列。

## 当前流程

主窗口自动字幕入口打开识别设置；提交识别请求后，以 SRT 识别任务进入现有后台队列。任务完成后进入字幕校对，修改文字、时间和样式，再选择 SRT、ASS 或带字幕的 MP4／MKV，提交导出任务。任务配置窗口通过现有非模态工具工作流打开。

## 发现与修正

| Before | After | Why |
| --- | --- | --- |
| 识别页固定宽 1120、预览列 420，模型藏在单项折叠区 | 自动字幕默认宽 940、预览列 300；语言和模型直接显示 | 降低空白占用和操作层级 |
| 空文件仍显示黑色预览区及预览操作 | 没有文件时隐藏预览 | 避免展示不可用区域 |
| 校对页单文件也占完整侧栏，输出与目录在右侧滚动区域 | 文件切换在顶部；列表、编辑两列；输出、目录及提交固定在底部 | 小窗口仍能直接访问保存操作 |
| 输出切到 SRT 会隐藏样式按钮 | 保留按钮占位并禁用 | 切换格式不改变操作位置 |
| 切换源文件先等时长读取再更新字幕列表 | 先切换列表与选择状态，再异步读取时长；完成后检查当前源及窗口生命周期 | 避免读取期间显示旧字幕或关闭后更新 |
| 删除选中字幕后编辑区失去选择 | 自动选中相邻条目 | 连续校对不必重新点选 |
| 重新识别期间隐藏按钮 | 保留按钮位置，忙碌时禁用 | 避免操作栏跳动 |
| 源目录模式只禁用目录文本框 | 同时禁用浏览按钮 | 保持目录选择状态一致 |

## 实际走读范围

- 识别设置：空文件、已有视频、任务编辑；原生文件选择器实际导入 `artifacts/readme-20261007/demo.mp4`，移除后保存按钮禁用，再导入后恢复。
- 语言与模型：自动识别切到中文，Base 切到 Tiny；模型下拉中三项可见。检查源目录开关、浏览按钮联动、仅加入队列与后台识别的按钮文字。
- 校对：预设两条字幕草稿，编辑文字并确认列表同步，调整时间并确认时间标签与列表同步；添加草稿、删除草稿，最终版本确认删除后相邻字幕仍选中且可编辑。
- 输出与样式：依次切换 SRT、ASS、MP4、MKV；SRT 禁用样式入口，其他格式启用。实际打开样式窗口、读取视频画面，选择字体、青色和居中位置，确认控件反馈。
- 布局：识别窗口最小 800 × 480；校对最小 850 × 600，编辑区域滚动条可到达添加／删除操作，输出与保存区域不随编辑区域滚动。查看 Light、Dark 以及英文最小窗口；未覆盖 Mac OS 9、Windows XP 或 Windows 原生窗口。
- 编辑表单：实际点击保存并关闭窗口，偏好仅写入走读目录；没有向日常队列提交任务。

校对草稿用于界面交互，不是本次模型识别结果。真实媒体仅用于元数据读取和界面预览；未运行语音识别、模型下载、导出媒体、暂停／继续、重新识别或性能测试，也未运行全量测试。多文件源切换的并发读取防护完成静态检查，未进行并发压力验收。
