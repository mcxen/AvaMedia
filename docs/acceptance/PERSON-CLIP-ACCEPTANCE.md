## 素材与流程

素材为 Pexels 的 [Men Walking In And Out Of An Open Door](https://www.pexels.com/video/men-walking-in-and-out-of-an-open-door-4077522/)，作者 Сергей Кончеков。下载原视频，未拼接或重编码验收输入。源文件为 MP4，11.54 秒，765,863 字节，H.264 / AAC，320×568，30 fps，48 kHz 单声道。抽帧确认尾部无人画面。

源文件 SHA-256：`867fecd8df22bc42b8c0a22532fc499c1b6fdf0e0534842800a10eb5556953a7`。导出前后校验一致。

执行真实 `PersonClipAnalysis`，使用默认 NanoDet + MediaPipe、平衡检测、每秒 4 帧、阈值 0.35、前后保留 0.5 秒、合并间隔 1 秒。实际推理 47 个采样帧；后端为 NanoDet Core ML / CPU、MediaPipe CPU。得到保留区间 **0–10.25 秒**。

将识别结果传给实际 `ClipExportWindow`，以 Avalonia Headless 检查默认表单值和 `CreateRequest()`。默认选择“原格式 / 原码率”，AI 入口默认合并片段。随后通过正式 `QuickClipWorkflow` / `QuickClipBatch` 创建任务，由 `QueueService` 调用 `MediaEngine` 执行。

AI 模型、导出表单与生产队列均使用实际实现。没有进行原生窗口截图或像素验收。媒体验收使用 `b965d04` 加本次修改的隔离源码，避开共享工作区其它未完成改动；提交前再以 `3d01f37` 加本次暂存修改构建桌面项目，0 警告、0 错误，确认与同期已提交代码集成。

另用同一实际视频的 `0–2`、`8–10.25` 两个区间验证连接：输出 472,347 B，实际时长 6.366667 秒，190 个视频包、294 个音频包全部匹配源包，完整解码无错误。验证过程中修复了合并器自动插入 H.264 参数集，以及音频预滚、终点 B 帧导致的接缝时间偏差。

## 边界与平均码率

流复制保留原容器、编码与包内容。边界受关键帧和帧重排限制，因此两段连接的实际时长与请求区间总长 4.25 秒不同。需要精确边界或画面、音频滤镜时，须选择重新编码格式。

原视频总平均码率为 530,927 bit/s，单段保留输出为 553,459 bit/s；统计区间改变会改变平均值，逐包哈希证据证明没有提高编码码率或重新压缩。原格式导出不承诺任意短片段的平均码率数字或容器开销完全不变。
