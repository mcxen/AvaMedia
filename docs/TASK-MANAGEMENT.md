# 任务管理

首页任务列表支持单选和多选。右键未选中的任务会选中该任务；右键已有多选中的一项保留多选。右键空白处取消选择，只保留列表操作。菜单按选中任务的当前状态提供操作，点击时再次检查状态。

已完成任务默认折叠，列表上方的“已完成（数量）”可展开或折叠；“显示 → 折叠已完成任务”也可切换，应用保存这个偏好。折叠只隐藏成功完成的记录，失败、已停止、暂停和等待任务继续显示；真实队列、执行顺序、任务保存及导出不受影响。全选只选当前展开的任务，折叠项退出选择。通知里的“查看任务”、AI 标签和分类工具的任务跳转会自动展开并选中对应记录。

| 状态 | 管理操作 |
| --- | --- |
| 等待开始 | 开始任务、暂停任务、终止、编辑、复制、调整排队顺序、移除 |
| 已暂停 | 继续任务、终止、编辑、复制、调整排队顺序、移除 |
| 正在运行 | 暂停任务、终止任务、复制任务、查看日志 |
| 正在终止 | 查看日志；引擎退出前保留任务记录 |
| 已停止 | 继续任务、编辑、复制、移除 |
| 失败 | 重试任务、编辑、复制、查看日志、移除 |
| 已完成 | 重新执行、编辑、复制、打开输出、播放输出视频或查看视频总结结果、移除 |

“开始任务”只启动选中任务；工具栏“开始”启动所有尚未排队的等待任务。已有任务运行时可以继续加入其他任务、重试失败项或重新执行已完成项。队列不按任务数或工具类别设置并发上限，已启动任务在文件修改冲突允许时直接进入后台执行；共享模型等资源在执行阶段协调。重试、继续和重新执行只提交所选项，不启动列表中其他未排队任务。已暂停任务继续时恢复原执行器，无需等待固定调度名额；详见[跨工具资源调度](MEDIA-RESOURCE-SCHEDULING.md)。

“终止任务”只取消选中项：等待项从排队中撤下，运行项进入“正在终止”，引擎退出后变为“已停止”。工具栏“停止”取消当前整个运行队列，未开始的任务仍保留为等待状态。终止期间不能修改或移除该任务，其他任务可以继续运行。

“暂停任务”适用于等待和运行中的任务，立即显示“已暂停”。后台当前的模型加载、文件分析、原生推理或媒体进程可完成当前单元，再在安全边界等待。暂停期间不自动变成完成；同一应用进程内继续原任务，不清空结果或重新创建执行器。等待项继续后重新排队；已经到达暂停边界的执行器不占该工具的调度位置。仍在执行器内的暂停项保留文件占用，不能编辑或移除。任务窗口、标签、分类、人物拆分和方向检测均提供暂停 / 继续入口。

原生模型现场只保留在当前进程内；退出后再次继续会按任务类型重新执行或使用已保存的分类结果。终止后选择“继续任务（重新执行）”从头处理；下载使用同一任务 ID 和相同参数对应的暂存数据，沿用下载引擎的续传能力，实际能否续传取决于来源。

工具窗口与任务编辑窗口使用非模态展示；编辑只暂停该项的排队，其他工具及任务控制保持可用。模型加载、预热与任务执行由后台线程处理。权重及运行时共享读租约，修复 / 下载 / 删除使用独占租约。重命名和移动仅在相关路径仍被执行器使用时拒绝，具体链路见 [异步任务架构审计](ASYNC-TASK-ARCHITECTURE.md)。

排队顺序支持移到最前、上移、下移、移到最后，多选项保持相对顺序；运行中的任务不重新启动。编辑排队项时临时撤下该项，关闭编辑窗口后，在队列仍运行时重新排队。编辑暂停项仍保持暂停。

复制任务保留来源和参数，使用新任务 ID、空日志和独立输出名称，初始状态为等待。“重新执行”复用原任务记录，并分配不覆盖既有文件的输出名称。复制、重试和继续均避开列表已预留的输出及源文件路径。

菜单还提供打开来源、源文件目录、输出文件与目录、复制文件路径、查看日志、全选和取消选择。工具栏“清理”和列表右键菜单分别提供“清理已完成任务”与“清空列表”。前者包括已折叠的完成项，运行其他任务时仍可使用；没有可清理完成项时禁用。后者在队列运行期间禁用。“移除任务”和清理操作删除任务记录与其日志，保留来源和输出文件。

交互参考：[Motrix 的状态分类与批量操作](https://motrix.app/manual/managing-tasks/)用于区分需要继续处理的任务与完成记录；[HandBrake 的 `ClearCompleted`](https://github.com/HandBrake/HandBrake/blob/master/win/CS/HandBrakeWPF/Services/Queue/QueueService.cs)提供按成功状态单独清理记录的做法。本应用沿用原有虚拟化列表，增量更新显示项，保持任务的相对顺序。

队列完成统计覆盖运行中加入的任务，并将暂停、终止和未执行项计入未完成数。仍有暂停、等待或运行任务时不触发完成后关机。应用意外退出时，运行或正在终止的记录恢复为已停止，允许再次继续。

本次仅执行受影响客户端的编译和必要静态检查，没有运行功能回归、媒体输出或界面验收。

## 任务详情与处理日志

所有任务行的“查看任务详情”和右键同名操作打开独立窗口，主窗口队列继续保留。已完成、失败和取消的任务双击进入详情，等待或暂停且可编辑的普通任务保留双击编辑；AI 专项界面仍可从“打开任务界面…”进入。

详情包含三个区域：

- **结果**：任务状态、真实原因与处理指标。视频瘦身区分采样预估和完整编码结果，指标不存在时显示“—”。
- **文件与参数**：来源、实际产出或计划输出，以及任务所选参数。
- **处理日志**：异步读取任务保留的完整日志，可选择、刷新和复制；显示日志期间，运行任务每两秒读取一次最新记录。

右键“查看日志”直接打开详情的日志区域。失败通知的“查看任务详情”也进入同一个窗口；关闭或清空通知不影响任务详情与日志。

视频瘦身无法在画质要求内获得足够收益时，以“无需瘦身”完成并保留原因，保留原视频、不生成新文件。通知为信息提示；任务行与详情不提供不存在的产出文件的打开、播放、预览或拖拽。已经完整编码但收益不足的任务可查看“编码结果体积（未保留）”和实际节省，采样预估仍单独保留。源文件和配置相同时可复用分析结果；重新执行或编辑任务会清除上次完成状态与日志。
