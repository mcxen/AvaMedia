# 异步任务架构与工具入口审计

日期：2026-10-10。范围：当前 `Catalog.All` 的 62 个工具入口、主窗口调度、任务窗口、模型下载 / 加载 / 预热及暂停控制。结论来自源码与受影响项目编译；未运行功能回归、真实模型并发、媒体输出、性能或 UI 验收。

## 当前链路

`MainWindow.Configure` 接收用户操作，启动独立工具流程。`ToolExecution.ShowAsync` 用非模态窗口收集请求；确认通过 `ToolExecution.Complete` 返回参数，关闭仅结束窗口。`AddToolJobs` 保存任务并提交启动请求，任务由 `QueueService` 管理，执行器经 `Task.Run` 在后台调用 `MediaEngine.Execute`。结果窗口订阅任务状态，窗口生命周期与任务生命周期分开。

每个工具 ID 使用独立调度通道，方向检测使用独立于旋转导出的通道。`ParallelJobs` 是每工具并发上限；关闭多线程时每工具同时执行一项，不限制其他工具。排队扫描跳过正在等待资源或文件保留的工具，继续寻找其他可开始的任务。全局停止正在收尾时，新启动请求保留在主窗口，旧会话结束后自动启动。编辑窗口仅撤下被编辑的任务，其他任务可继续控制。

`ModelStore` 维护按模型目录划分的读写租约：独立推理进程允许同时读取运行时及权重，下载、导入、修复和删除仍独占文件。`ModelAccessGate` 优先放行已经等待的写操作，读租约在进程 / 会话释放时归还。使用中模型无法删除，界面模型管理继续报告占用。

`MediaTagModelCache` 按模型根目录保留标签、NSFW 和嵌入会话，同一缓存会话保持串行；预热、首次加载、GPU 回退与推理均由后台调用。视频总结的 JoyTag 检查使用独立推理会话，不再通过文件锁阻塞标签缓存。总结和标签描述各自持有本地 llama.cpp 进程，移除了整个视频总结服务的全局互斥锁。Whisper 和人物检测的共享资源仍在各自的后台链路内协调。

## 暂停、继续与终止

`QueueService.Pause` 立即记录暂停意图并发布 `JobState.Paused`。界面显示“已暂停”，同一个按钮 / 任务菜单提供继续。进度发布停止更新任务百分比，活动视图停止运行中的动画；迟到的原生结果不能将任务自动切回运行或完成。

`JobExecutionControl` 经异步上下文传递任务控制，不修改执行器接口。安全检查点包括任务进入 / 结束、媒体进程启动、本地 / 在线模型请求的前后、总结结果保存和分类的逐文件边界。已进入的原生调用与媒体进程继续完成当前单元，不调用系统级强制挂起。持有共享推理会话时延后等待，释放当前单元的资源后再停住；分类从整批独占改为逐文件归还缓存会话，并异步保存该文件结果，删除了同步等待异步保存的回调。

标签分析以当前文件为暂停单元，人物检测以当前检测阶段、Whisper 以当前识别阶段为暂停单元；完整 FFmpeg 调用可能处理完当前输出后才到达下一检查点。UI 不等待这些边界。到达边界后暂停项释放工具调度位置，继续唤醒原执行器；快速暂停 / 继续可以撤销等待，保留当前模型和结果，不重复启动原任务。

终止把任务置为“正在终止”，先释放暂停等待，再异步执行取消回调；主窗口不在取消按钮事件中同步等待进程退出。执行器退出后才释放任务记录和文件占用。事务型重命名必须完成提交 / 回滚，已提交的文件修改按成功处理。

停止预热立即撤下 UI 请求、停止按钮与进度。旧原生加载可在后台完成取消清理，其进度 / 最终回调不能覆盖新请求或重新显示预热进度。加载失败和模型占用仍由模型状态展示。

## 62 个入口的覆盖

| 工具入口 | 配置 / 执行方式与检查结果 |
| --- | --- |
| `video-summary`、`media-ai`、`folder-classification`、`person-clip`、`auto-subtitle`、`rotate` | 独立工具 / 任务窗口，后台排队与模型准备；总结、标签、整理、人物、字幕和方向检测之间没有全局运行状态入口锁。通用任务窗口提供暂停 / 继续，标签、整理、人物和方向窗口也提供控制。 |
| `mp4`、`video-compress`、`video-slim`、`join`、`split`、`clip`、`delogo`、`frames`、`voice-enhance`、`mux`、`extract-video`、`repair` | 转换 / 压缩 / 瘦身 / 裁剪配置改为非模态，快速剪辑沿用现有非模态编辑 / 导出链路；确认只提交本次任务。 |
| `audio-mp3`、`audio-flac`、`audio-wav`、`audio-m4a`、`audio-ogg`、`audio-aac`、`audio-ac3`、`audio-wma`、`audio-opus`、`audio-aiff`、`audio-join`、`audio-mix`、`audio-clip`、`audio-enhance` | 通用转换 / 语音工具非模态配置；媒体进程由后台执行器运行，每个工具独立排队。 |
| `image-jpg`、`image-png`、`image-webp`、`image-bmp`、`image-tiff`、`image-gif`、`image-ico`、`image-avif`、`image-tools`、`image-compress`、`images-pdf` | 图片转换、编辑、压缩和图片 PDF 使用非模态配置。图片压缩移除“已有队列运行时不能立即开始”的限制，确认只启动本批新增任务。 |
| `pdf-merge`、`pdf-split`、`pdf-age`、`pdf-compress`、`pdf-text`、`pdf-docx`、`pdf-xlsx`、`text-pdf` | PDF 工作区使用非模态收集请求，统一确认协议和“仅加入队列”选择；探测 / 预览保留窗口自己的取消控制。 |
| `crop`、`batch-rename`、`contact-sheet`、`zip`、`unzip` | 裁剪、重命名、多宫格改为非模态；移除批量工具的全局队列运行拦截。重命名 / 撤销按来源、目标和日志路径保留文件，ZIP / 解压由后台队列执行。 |
| `download` | 解析窗口非模态；解析取消只影响该窗口，请求确认后独立下载排队。 |
| `dvd`、`iso` | 复用非模态转换窗口和后台执行器；保持源设备 / 文件的任务占用保护。 |
| `player`、`image-viewer`、`info` | 保持独立查看窗口，读取 / 播放不依赖媒体队列空闲。 |

所有上述工具的任务编辑窗口也使用非模态协议。文件选择器、当前工具内的参数编辑、设置、危险文件操作确认仍是短期对话框，未用于包裹后台任务生命周期。

## 保留的局部限制

- 同一原生推理会话串行运行；资源占用或模型维护时在后台等待，不禁用主窗口工具入口。
- 源 / 目标文件正在使用时禁止重命名、移动或撤销相关文件。`ReserveFiles` 同时防止新任务在文件修改过程中开始，完成队列路径同步后放行；不涉及这些路径的工具照常操作。
- 执行器尚未退出的任务不能编辑、移除、重新执行；暂停反馈不代表文件或原生资源已经释放。
- 清空整张任务列表及应用更新安装仍需要适当的空闲状态，单任务控制和新工具不依赖这一条件。

源码检查确认主窗口没有按 `_queue.IsRunning` 拒绝打开工具，配置和任务编辑不再使用 `ShowDialog`；该状态仅用于调度会话、停止 / 托盘摘要、清空列表和更新安装。UI 规则见 [UISPEC.MD](../UISPEC.MD#78-后台任务模型准备与即时暂停)，任务操作见 [任务管理](TASK-MANAGEMENT.md)。
