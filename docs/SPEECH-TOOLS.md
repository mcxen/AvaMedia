# 自动字幕与人声增强

## 使用

- 视频分类 → **自动字幕**：添加文件，选择语言与输出内容，再加入队列。首次执行下载语音模型；以后离线识别。音频文件可从拖放路由的“语音转字幕”入口进入。
- **带字幕视频（MP4 / MKV）**：文字写入画面。字体、字号、颜色、九宫格位置和边距可调整，右侧在源视频画面上显示样式预览。
- **字幕文件（SRT）**：保存文字和时间戳，不包含全局字体或颜色样式；界面隐藏样式设置。
- **样式字幕（ASS）**：字幕与视频分开保存，同时保留上述样式。
- 视频 / 音频分类 → **人声增强**：选择输出格式和降噪强度。默认沿用原格式，视频画面直接复制，只重新编码声音。也可在转换、剪辑输入的音频设置中启用人声增强。

队列右键“编辑任务”可以调整语言、模型、字幕样式或降噪强度。任务保持原来的队列位置；输出名称按既有规则避免覆盖源文件或已有结果。下载、识别和导出阶段显示进度，支持停止与重试。

字体从系统字体列表选择；颜色提供常用色块，也可输入 `#RRGGBB`。字幕文件的正文仍可用外部文本编辑器修改，再通过现有字幕设置烧录或附加。

视频预览下方的滑杆可切换画面，也可输入 `时:分:秒.毫秒` 精确定位。预览时间不改变输出区间。在画面上点击或拖动字幕可自由调整位置；方向键微调，Shift 加方向键加大步长。点击九宫格恢复预设位置和边距调整。普通转换与剪辑的字幕配置使用同一套视频预览。

自由位置按画面宽高的比例保存，随任务、预设和队列保留。ASS 导出和视频烧录以字幕中心作为位置锚点；处理外部字幕时，所选位置替换字幕原有的位置或移动指令。预览显示源视频画面与示例文字，识别结果需在完成后检查。

## 模型与处理

默认多语言 **base-q5_1** 为 59,707,625 字节；轻量 **tiny-q5_1** 为 32,152,673 字节。可选 **small-q5_1** 为 190,085,487 字节，视频总结默认使用 Small。三个模型出现在“选项 → 模型管理”，可以下载、校验和删除。识别期间持有模型使用锁，禁止删除正在使用的模型。运行库使用 Whisper.net 1.9.1 / whisper.cpp；不要求用户安装 Python。发布只包含目标平台的原生库。

内置约 864 KB 的 Silero VAD 6.2.0 先检测语音活动，跳过没有语音的识别块，并过滤缺乏语音支持的字幕片段，避免持续噪声或非语言声音被转成重复字幕。无法识别到有效语音时显示现有提示，不保存伪字幕；无需额外下载模型。来源与校验值见 [模型说明](../licenses/speech/silero-vad-model.md)。

识别音频由 FFmpeg 转为 16 kHz 单声道 PCM。按最长五分钟、边缘一秒重叠分段读取，再按 VAD 检出的语音区间分别识别，避免模型在一个解码窗口中提前结束后漏掉后续讲话。输出时间戳按每个语音区间的偏移和速度换算，避免长视频一次读入完整音频。识别任务串行加载模型，其他队列任务仍遵循已有并行设置。字幕先写临时文件，成功后才发布输出；停止或失败会清理本任务的临时结果。

人声增强内置约 300 KB 的 RNNoise 兼容模型：48 kHz 重采样 → 70 Hz 高通 → `arnndn` → 响度归一化 → 输出音轨。强度调整原音与降噪结果的混合比例。普通 `afftdn` 降噪和人声增强同时设置时，以人声增强为准。

此功能面向讲话及录音环境杂音，可能抑制笑声等非讲话声音。背景音乐、同时说话的其他人和严重混响不能保证去除；这类素材需要专门的分离或去混响模型。语音识别结果需要人工校对，轻量模型尤其如此。
