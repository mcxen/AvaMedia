# 自动字幕与人声增强

自动字幕使用[多页任务窗口](TASK-MANAGEMENT.md#多页任务与任务窗口)，流程为“识别处理 / 输出方式 / 生成 / 完成”：先只做识别生成字幕草稿，再选择输出方式，最后生成。关闭窗口不停止队列。

## 识别、校对与导出

视频分类 → **自动字幕**：添加视频或音频，选择语言、识别模型及保存位置，点击开始或仅加入队列。首次执行下载语音模型，以后离线识别。识别阶段先生成字幕草稿，不直接烧录视频；每个文件独立进入现有队列，支持停止、重试和查看识别进度。

识别完成后打开字幕校对窗口，逐条修改文字与起止时间，预览所选区间并调整字体、字号、颜色、九宫格位置或自由位置、边距。修改后的字幕可保存回任务结果，再创建导出任务；导出复用已校对的字幕，不重复识别。部分结果须明确确认后才可导出，校对不能保证识别内容准确。

### 输出方式

识别完成后进入“输出方式”页，右侧样式区上方选择输出方式：

| 输出方式 | 行为 |
| --- | --- |
| 导出字幕文件 | 选择 SRT / ASS / VTT。SRT / VTT 只含文字和时间，字体与位置由播放器决定，样式区折叠并说明原因；ASS 保留字体、字号、颜色、位置和边距 |
| 烧录到视频 | 把已校对的文字烧录到源视频画面，生成 MP4，样式设置生效 |

音频源只能导出字幕文件，页面就近说明原因。输出方式会记住上次选择，主按钮文字随之变化（“烧录并导出视频 / 导出字幕文件”）；点“跳过”按默认 SRT 导出。已提交后可点“修改”回到本页重新生成，后续页随之重置。生成复用已识别的字幕，不重复模型推断；生成期间可用窗口头部的“暂停 / 停止”控制。

生成页显示真实进度与当前步骤，完成后进入“完成”页，展示按媒体比例的输出预览、文件信息与逐页处理记录，输出文件可拖出复制。

队列中的识别任务可重新编辑语言与模型；结果窗口负责字幕文字、时间和导出样式。输出名称遵循已有防覆盖规则，识别、校对保存和导出共用任务结果及状态。网页校对与导出入口见 [MCP 与远程管理](MCP.md)，跨端待完成事项见 [网页视频功能对齐](WEB-VIDEO-PARITY.md)。

视频 / 音频分类 → **人声增强**：选择输出格式和降噪强度。默认沿用原格式，视频画面直接复制，只重新编码声音；也可在转换、剪辑的音频设置中启用人声增强。

## 字幕样式与定位

字体从系统字体列表选择；颜色提供常用色块，也可输入 `#RRGGBB`。外部字幕也可通过现有字幕设置烧录或附加。

字幕样式编辑器使用源视频画面预览，滑杆可切换画面，也可输入 `时:分:秒.毫秒` 精确定位；预览时间不改变输出区间。在画面上点击或拖动字幕可自由调整位置；方向键微调，Shift 加方向键加大步长。点击九宫格恢复预设位置和边距调整。普通转换与剪辑的字幕配置使用同一套样式编辑器；识别提交窗口只提供封面与播放器预览入口。

自由位置按画面宽高的比例保存，随任务、预设和队列保留。ASS 导出和视频烧录以字幕中心作为位置锚点；处理外部字幕时，所选位置替换字幕原有的位置或移动指令。样式预览与最终媒体输出的检查属于不同验证范围。

## 模型与处理

默认多语言 **base-q5_1** 为 59,707,625 字节；轻量 **tiny-q5_1** 为 32,152,673 字节。可选 **small-q5_1** 为 190,085,487 字节，视频总结默认使用 Small。三个模型出现在“设置 → 本地模型”的模型库中，可以下载、校验和删除。识别期间持有模型使用锁，禁止删除正在使用的模型。运行库使用 Whisper.net 1.9.1 / whisper.cpp；不要求用户安装 Python。发布只包含目标平台的原生库。

内置约 864 KB 的 Silero VAD 6.2.0 先检测语音活动，跳过没有语音的识别块，并过滤缺乏语音支持的字幕片段，避免持续噪声或非语言声音被转成重复字幕。无法识别到有效语音时显示现有提示，不保存伪字幕；无需额外下载模型。来源与校验值见 [模型说明](../licenses/speech/silero-vad-model.md)。

识别音频由 FFmpeg 转为 16 kHz 单声道 PCM。按最长五分钟、边缘一秒重叠分段读取，再按 VAD 检出的语音区间分别识别，避免模型在一个解码窗口中提前结束后漏掉后续讲话。输出时间戳按每个语音区间的偏移和速度换算，避免长视频一次读入完整音频。识别任务串行加载模型，其他队列任务仍遵循已有并行设置。字幕先写临时文件，成功后才发布输出；停止或失败会清理本任务的临时结果。

人声增强内置约 300 KB 的 RNNoise 兼容模型：48 kHz 重采样 → 70 Hz 高通 → `arnndn` → 响度归一化 → 输出音轨。强度调整原音与降噪结果的混合比例。普通 `afftdn` 降噪和人声增强同时设置时，以人声增强为准。

此功能面向讲话及录音环境杂音，可能抑制笑声等非讲话声音。背景音乐、同时说话的其他人和严重混响不能保证去除；这类素材需要专门的分离或去混响模型。语音识别结果需要人工校对，轻量模型尤其如此。
