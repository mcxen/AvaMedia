# 动态布局审查

日期：2026-10-10。范围：Desktop 全部 AXAML 布局及以 C# 构造的窗口和共享控件；按动态 Text / Content 更新位置排查横向自适应列、横向 StackPanel、状态换行及进度区域显隐。本记录是源码审查与编译证据。

| Before | After | Why |
| --- | --- | --- |
| 下载图一直占据任务列表下方 | 无运行下载时隐藏，运行下载时显示右下角浮层 | 空闲时移除监控，显隐不改变列表高度 |
| CPU/GPU 共用自然宽度的文字 | 两个固定数值格，180 ms 按增减方向翻页 | 位数变化不推移相邻控件 |
| 下载速度使用两个 Auto 列 | 三个等分列和等宽数字 | 单位、位数变化不移动指标 |
| 通知徽标显隐，百分比/计数按内容占宽 | 保留徽标格，预留百分比与导航计数空间 | 通知按钮及进度条位置稳定 |
| 播放器、编辑器的时间文字依赖字体字宽 | 明确预留时间范围，并使用 `tnum` | XP、Mac OS 9 等比例字体也不改变数值格宽度 |
| 解析、分析、预览、确认等按钮随状态文案伸缩 | `StableLayout.Samples` 按全部状态、字体和语言测量固定空间 | 连续操作时目标位置稳定 |
| 模型状态占自然宽度，预热进度显隐改变行高 | 状态预留列，详情使用伸缩列，固定进度行 | 加载、预热、使用、释放及失败不会推移详情 |
| AI 耗时增加“最近进展”后扩大标题栏 | 固定耗时格，进展间隔在完整 Tooltip 中 | 更新不挤压任务标题 |
| AI 任务行切换进度及状态会重新测量高度 | 按任务类型预留进度区，状态与详情占位 | 运行、暂停、完成不推移后续任务行 |
| 状态换行或体积结果增加会改变正文区域 | 常见实时状态预留两行，体积条保留槽位 | 正文与操作区域保持稳定，完整文案可查看 |

共享入口是 `StableLayout`、`Ui.Status`、`ToolExecution.Configure` 和 `Ui.Button` 的任务状态预留。会随字体、皮肤和语言更新预留尺寸；数值采样和业务进度更新不调整尺寸。

覆盖位置包括主窗口、任务行、下载与浏览器、通知、播放器、编辑器、快速剪辑、视频总结、语音工具、AI 标签、文件夹分类、人物拆分、重命名、视频压缩/瘦身、图片压缩/查看器、批量裁剪/旋转、PDF、WiFi 传输及设置中的供应商和模型状态。设置模型管理已经使用固定按钮列和详情槽位，继续保留；播放器速度和 VR 按钮已有固定宽度，继续复用。

其余布局中，长路径/文件名、媒体信息及结果正文位于伸缩列、固定预览区或滚动正文；表单数值输入、坐标输入和播放器操作按钮已有固定尺寸。用户切换页面、展开详情、增加文件等明确操作保留对应的布局变化。

遵循 `AGENTS.md`，本次只执行受影响 Desktop 项目的 Release 构建及必要静态检查。最终提交源码快照构建通过，0 警告、0 错误；未运行功能回归、截图/像素检查、媒体输出、性能或压力测试。实际平台的视觉与动画观感未做运行验收。
