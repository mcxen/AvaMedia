# 视频剪辑与裁剪

本页描述 AvaMedia 的实际实现。用户提供的快速剪辑截图和控件树记录了入口与列表结构；原软件内部剪辑、裁剪、分割规则尚未完整实测，不能将以下行为视为逐项等效证明。当前优先完成视频编辑，字幕扩展暂停。

## 时间区间

快速剪辑主入口选择视频后直接编辑，可添加任意多个片段；全部编辑完成后选择导出选项，最终才加入队列。每个片段保存独立草稿，公共编码与质量设置保留片段的编辑参数。返回编辑恢复全部片段及导出设置，取消不加入任务。

旧文件列表的“选项”继续打开编辑器，确定返回这一项，取消丢弃本层修改；该兼容列表的公共输出配置保留每项已有的区间、裁剪与去水印区域。

区间使用开始包含、结束排除的语义。界面显示真实结束时间，任务模型的结束值 `0` 表示直到媒体末尾。开始必须小于结束，两者必须在媒体时长范围内；无效输入显示原因并禁用确定。编辑器时间读数统一显示 `hh:mm:ss.fff`，小时数可超过 24；未修改的读数保留内部真实帧时间，显式输入更多小数位也保留精度。分割预览和片段摘要在必要时显示六位小数。

时间轴可拖动边界，± 可移动区间边界，前后定位按钮移动预览位置。“1 帧”使用源视频实际帧时间戳查找前一帧或后一帧，覆盖可变帧率、稀疏帧和非零起始时间戳；音频文件回退到时间步长。帧精度下时间轴仍可连续拖动。持续时间显示选中区间，输出时长计入速度。

开始缩略图显示定位点处的画面；结束缩略图取严格早于结束边界的最后一帧。播放所选区间从开始定位，到结束自动停止并显示区间内的最后画面。预览显示原媒体，处理效果在输出中生效。

## 定位与播放状态

打开已有片段时，预览位置、时间标签和源画面从保存的开始时间对齐。保存的结束时间超出媒体时长时保留输入、提示错误并禁止确认，便于纠正；不会自动改短区间。

播放的时钟从第一帧实际解码并显示时开始，准备解码的耗时不会提前计入源位置。暂停保留当前位置；停止取消播放并显示源文件的起点。视频画面先结束、音轨或容器仍有剩余时长时，保留最后画面并继续到媒体结束；播放所选区间只继续到所选结束边界。

拖动定位、修改区间、逐帧调整、停止、切换片段和关闭窗口会使相应旧请求失效。晚返回的解码画面、区间边界缩略图或逐帧时间不能覆盖较新的操作；关闭后不再更新已释放的图像。时间标签与当前显示画面来自同一有效定位请求。多片段开始时间相同时，切换仍会停止旧播放并重新定位。

Fast Copy 的真实切点受源文件关键帧和容器限制。需要任意帧精确剪辑或画面裁剪时选择 MP4/MKV 重新编码；滤镜与 copy 冲突在提交前验证。

## 视频分割

编辑器“分割当前片段”和旧列表每行的“分割”共用分割窗口，可按段数、源视频时长或源视频时间点拆分当前区间。窗口预览每段开始、结束与计入速度的输出时长；确认仅替换当前片段或行，各段独立保存裁剪与处理草稿。取消和无效参数保留原草稿。切点按开始包含、结束排除执行；Fast Copy 仍受关键帧约束。详细输入格式与边界规则见 [快速剪辑](QUICK-CLIP.md)。

## 画面选区

选区坐标按源视频像素计算，预览缩放和黑边不改变坐标单位。拖动外部绘制新选区，拖动内部移动，拖动四角缩放；选区获得焦点后，方向键移动一个像素步长，Shift+方向键移动十个步长。拖动时按 Esc 恢复拖动前选区。

单文件编辑器可选择自由、原画面、16:9、4:3、1:1 或 9:16 比例，约束后续绘制和缩放。视频区域的 X/Y/宽/高统一对齐到偶数像素，比例边界也受像素步长影响；图片允许精确的奇数像素区域。坐标不能为负，宽高须同时启用，区域不能越过画面，边界检查使用长整数防止溢出。

无效数字在编辑器中即时提示并禁用确定，“应用坐标”只显示有效区域。“重置选区”恢复全画面并移除裁剪滤镜。去水印保留独立区域，使用模糊处理。

## 多文件裁剪

主窗口的视频批量裁剪入口支持勾选文件、预览任一文件、共用选区与独立输出。“同一像素区域”要求区域在每个勾选视频中都有效；“按画面比例”将参考区域按每个视频的尺寸转换，并将边界向内对齐到偶数像素。切换预览不改变参考区域，重新拖动或重置才指定新的参考。

单文件、批量和执行引擎共用 `CropGeometry` 校验。批量草稿全部有效后才分配任务；源文件与已有输出不覆盖。单文件可同时保留时间区间和画面区域。

“原格式 / 原属性”导出对 `yuvj420p` 等全范围像素格式使用对应的 `yuv420p` 等布局，并显式保留全范围和原有色彩标记，避免严格像素格式选择阻止编码器所需的转换。使用 libkvazaar 时，对未满足 8 像素对齐的裁剪尺寸在编码内部复制边缘像素，并通过 HEVC 的可见画面窗口排除对齐区域；保留用户选定的可见尺寸，不增加可见黑边。实现依据 [FFmpeg 像素格式说明](https://ffmpeg.org/ffmpeg.html#Advanced-Video-options) 和 [HEVC metadata 滤镜](https://ffmpeg.org/ffmpeg-bitstream-filters.html#hevc_005fmetadata)。

## 合并、混流与普通转换

每个列表项都有独立草稿，同一源文件可以重复加入并选取不同片段。上移、下移和移除作用于列表项；列表显示该项的区间、裁剪区域和速度。普通转换对每项生成独立输出，合并按当前顺序连接各输入编辑后的时间轴。

合并/混流的文件“选项 / 剪辑”只编辑该输入；公共“输出配置”应用于组合后的输出。未编辑输入保持原始默认参数。混流第一个输入提供视频，第二个提供音频；关闭音频输入后输出仅保留视频，不按已关闭音轨的短时长截断视频。

混流中未处理的流直接映射，可以分别复制视频、处理音频，或处理视频、复制音频。某条流本身需要区间滤镜、裁剪、变速或其他处理时，该流须重新编码，提交前显示冲突原因。

确定前检查实际媒体信息、所选轨、每个输入区间和组合后区间。错误时保留草稿供修改；校验期间暂停列表及输出设置的修改，取消/关闭终止检查。整个批次有效后才分配输出；所有独立参数数量必须与文件数一致。

## 验证与平台

`tests/AvaMedia.ClipCropTests` 验证帧边界、可变帧率、时间戳偏移、移动与四角缩放、键盘操作、输入错误、区间播放、重复源片段、合并解码顺序、混流独立 copy 的包哈希、组合输出与源文件哈希。预览检查先解码真实帧，再故意延迟交付，验证新定位、输入区间与关闭操作不会被旧结果覆盖；另有短画面、长音轨样例验证播放终点。`tests/AvaMedia.BatchCropTests` 验证比例映射、多轨尺寸、队列入口与真实输出。`tests/AvaMedia.QuickClipTests` 验证文件隔离、分割、流复制和公共配置。

这些流程共用跨平台核心与 Avalonia 控件，后续发布目标为 Windows x64、macOS Apple Silicon（ARM64）。当前媒体输出与控件验证在 Windows 运行；Mac 真机操作、播放和输出仍需验证。最新报告与剩余核对项以根目录 TASK.md 为准。
