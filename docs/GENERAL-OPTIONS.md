# 普通选项

本页记录保存位置、任务完成动作、托盘与系统入口。当前设置采用九类侧栏，默认打开通用页：保存位置、任务完成动作、托盘与系统菜单在“通用”，声音和动效在“外观与声音”，软件更新在“关于”。完整分类与转换参数见 [选项设置](SETTINGS.md)。

| 配置 | 默认 | 实际行为 |
|---|---|---|
| 输出文件夹 | 用户视频目录下的 AvaMedia 文件夹 | 新任务的默认保存位置，支持改变路径 |
| 输出至源文件目录 | 关闭 | 每个文件分别保存到自己的目录；合并任务使用第一个本地输入的目录 |
| 添加设置名称 | 关闭 | 新转换、剪辑、批量裁剪与旋转输出名附加格式或 FastCopy 等名称；重名时仍分配新名字 |
| 关闭电脑 | 关闭 | 本次任务全部成功后进入 30 秒倒计时，可取消；失败、停止或仍有等待任务时不执行 |
| 打开输出文件夹 | 关闭 | 本次结束后打开成功输出所在的目录，去重；源目录输出时使用实际目录 |
| 普通操作 | 关闭 | 主窗口与设置窗口的按钮、主菜单操作使用短提示音 |
| 完成通知音效 | 开启 | 本次任务全部成功时播放完成音；与完成摘要开关独立 |
| 错误通知音效 | 开启 | 本次转换失败、应用设置出错时播放错误音 |
| 显示完成摘要 | 开启 | 运行结束后显示本次成功、失败数量及输出目录 |
| 添加到系统上下文菜单 | 关闭 | Windows 注册当前用户的“用 AvaMedia 转换”；macOS 安装 Finder 快速操作 |
| 最小化到系统托盘 | 关闭 | 点击最小化时隐藏窗口到托盘，后台任务继续运行 |
| 关闭窗口时缩小到托盘 | 开启 | 点击主窗口关闭时转入后台；托盘可恢复窗口、控制任务与查看结果；菜单“退出”真正结束应用 |
| 软件更新方式 | 启动时检查并提示 | 关于页可改为仅手动检查或自动下载、退出时安装；“立即检查”显示实际结果 |

转换、快速剪辑导出、批量裁剪和旋转窗口继承输出目录与设置名称默认值，也允许在任务窗口改选。更改全局设置不移动已有输出，不重写已加入队列的任务参数。源目录输出继续保留源文件；输出分配遵循原有防覆盖规则。下载等没有本地输入的任务使用所选输出文件夹。

“应用”保存并立即同步主窗口及系统入口，保留对话框；“确定”应用后关闭；“取消”丢弃上次应用后的草稿；关于页的“恢复默认…”只修改窗口内显示的偏好草稿，保留专属工具激活状态及上次检查时间。输入或系统入口注册失败时显示错误并恢复已应用设置，保留未保存草稿。数值输入出错时自动切到对应页并聚焦字段。主窗口底部通知勾选与设置页的完成摘要勾选使用同一配置。

完成后动作使用任务结束时已应用的设置，只统计这次开始的任务，历史失败不阻止新一批成功后的动作。运行过程中取消勾选关机并应用，可阻止这次完成后关机。关机倒计时期间尚未向操作系统发出关机请求；取消、真正退出应用或开始下一批会取消本次等待。后台完成时不会自动恢复主窗口，结果保留在托盘；开启完成通知时通过应用内气泡显示摘要。后台生命周期与托盘动作见 [后台任务与托盘](BACKGROUND-TASKS.md)。

Windows 系统菜单写入 `HKCU\Software\Classes\*\shell\AvaMedia.Convert`，取消勾选删除本应用的菜单项；Windows 11 可能放在“显示更多选项”中。Finder 服务位于当前用户的 `~/Library/Services/AvaMedia Convert.workflow`，使用 `open` 启动应用包，将文件参数送入 `--convert` 入口；取消时仅移除本应用生成的服务文件，保留意外出现的用户文件。菜单入口打开转换配置窗口。工作流结构参考原作者的 [Finder 快速操作生成脚本](https://github.com/ImageArm/ImageArm/blob/main/install-finder-action.sh)，本项目仅生成启动应用的动作。

托盘使用 Avalonia 的原生托盘及原生菜单；框架提供 Windows 与 macOS 入口，macOS 点击图标显示菜单。[Avalonia TrayIcon](https://docs.avaloniaui.net/controls/navigation/trayicon)

软件更新状态常驻“设置 → 关于 → 软件更新”，帮助菜单及 macOS 应用菜单也提供入口；关闭设置或移除通知不停止下载。准备完成后可选择“重启并更新”，正常保存、退出并安装成功后重新打开应用；普通退出安装不自动重开。队列运行或任务编辑时禁用重启，托盘隐藏不触发安装。静默模式只隐藏常规提醒，失败仍可见并可重试。检查、重试与校验规则统一见 [应用内更新](RELEASE.md#应用内更新) 和 [更新网络](UPDATE-NETWORK.md)。

关机、系统菜单和托盘的设备行为以对应平台的实际操作为准；关机遵循操作系统对未保存应用和权限的处理。旧 Windows 编译及运行记录不代表当前 macOS 的 Finder 注册、音效或关机权限已验收。
