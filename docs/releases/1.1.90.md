# AvaMedia v1.1.90

MCP 原生接口补齐设置、供应商和模型管理：按字段修改偏好、默认供应商、文本/视觉模型、密钥、超时及响应格式；支持模型列表刷新、配置/文本/单帧视觉诊断，以及本地模型导入、校验、释放和卸载。密钥只写，沿用独立凭据存储；配置更新支持 revision 并发检查。

新增全类别参数说明、任务参数读取/未启动任务编辑、独立输入参数、排序、AI 阶段进度、分类人工确认、总结证据、PDF 页码、下载解析/选择和自定义词库接口。修复部分 options 覆盖功能默认值的问题；任务参数返回实际存储路径及内部结果标记。原生目录与共享队列仍是唯一执行入口，不模拟界面操作。当前共有 60 个公开 MCP 工具，另有 2 个仅在已激活内部工具的工作区注册。

同时包含上次发布后的已有改进：VL 命名分析进入共享后台队列，支持线上供应商；本地总结模型调整为 Qwen 4B Q4 并增加 Huihui Qwen3.5 9B 档位；工具窗口在邻接空间不足时居中；网页字幕边距与草稿保存错误处理修复。

本次本地检查限于 Desktop 及其 Core/MCP 依赖编译、版本 XML、工具命名和修改块静态检查，未运行全功能回归、线上模型推理、媒体输出或性能测试。跨平台安装包由 Release 工作流在后台构建，tag 推送仅表示启动发布。
