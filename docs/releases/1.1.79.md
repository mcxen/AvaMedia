# AvaMedia 1.1.79

- 侧栏改为 macOS 风格工具树：视频、音频、图片、文档、工具集 5 个分类手风琴展开，显示工具数量与展开箭头；光盘工具并入「工具集」，音频 / 图片格式转换以「转换为」格式按钮组呈现；打开过的工具保持选中高亮。
- 任务列表重新设计（浅色 / 深色皮肤）：标题「任务」与进行中 / 等待 / 失败摘要，文件路由、输出文件夹、选项、WiFi 传文件的胶囊工具组，编辑 / 移除 / 清理与停止 / 开始分组；任务行显示真实缩略图、「工具 → 输出」、细进度条与带图标的状态（如「转换中 62.0% · 剩余 01:20」），编码细节移入悬停提示。
- 按平台区分窗口框架：macOS 使用原生红绿灯并让出侧栏顶部空间；Windows / Linux 使用自绘最小化 / 最大化 / 关闭，标题区可拖动、双击最大化。`AVAMEDIA_CHROME=system` 可回退系统装饰。
- 移除任务区的拖放提示框，任务列表占满空间；拖入文件仍由「文件路由」识别并列出可用工具。
- Mac OS 9（Platinum）皮肤：工具树使用 Platinum 彩色图标、凸起分类条、实心展开三角、淡紫选中色与方形 BETA 标记，任务行更紧凑；补齐「视频瘦身」图标。
- 新增 Linux x64 版本：自包含 `tar.gz`，需要系统安装 FFmpeg / FFprobe 9（见 docs/LINUX.md）。
- 修复：经典皮肤运行中任务的进度区与状态文字重叠；状态栏任务摘要被截断；侧栏底色被面板默认背景覆盖。
- 本地验证：Desktop 构建 0 错误，InterfaceTests、BatchUiTests 通过；`dotnet publish -r linux-x64` 成功且在 X11 下启动；工作流经 actionlint 检查。SkinTests 的图标检查已通过，但随后在原有的 Platinum 复选框模板检查处失败（与本次改动无关，v1.1.78 已存在同类失败）。

源码以 [v1.1.79 tag](https://github.com/mcxen/AvaMedia/tree/v1.1.79) 为准。[Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml) 在 tag 推送后生成 macOS DMG、Windows portable ZIP / setup EXE 和 Linux tar.gz。
