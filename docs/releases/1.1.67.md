# AvaMedia v1.1.67

- 设置收拢为软件通用、转换、本地模型、在线 AI、工具五类；版本更新并入软件通用，本地模型内分为模型库与加载预热，MCP 并入工具。
- 统一设置导航、字段、按钮和底部操作栏；提供设置搜索与匹配项定位，保存后保留当前页面和滚动位置，修复未访问预热页面时首次保存及数值草稿误判。
- 模型库提供搜索、筛选及更多操作菜单；加载与预热采用 CPU / GPU 双列配置，联动初始与选择素材后的预热比例。在线 AI 检查取消立即反馈并避免旧结果覆盖新状态。
- 整理九类输出配置，合并单页选项并统一侧栏和预览布局；修复轨道选择控件未显示的问题。底栏 AI 状态块配色与 Light、Dark、Windows XP 皮肤一致。
- 设置与输出配置已完成限定范围的本地界面走读；相关 Desktop、SettingsTests、UiChecks 编译通过，0 警告、0 错误，测试项目仅编译。范围与记录见[设置界面走读](../acceptance/SETTINGS-WALKTHROUGH-20261010.md)。本次发布版本源码另行完成 Desktop Release 编译；未新增运行模型推理、媒体输出或安装包验收。
- [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)在标签推送后后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.67)。不等待或持续轮询 CI。
