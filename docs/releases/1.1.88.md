# AvaMedia v1.1.88

视频总结使用证据驱动的分层规划、画面工具和结构化修复，保留部分结果与代理执行轨迹，区分本地模型与线上供应商的验证记录。

网页支持读取字幕校对草稿、调整文字与时间、预览样式，并通过共享队列导出已校对的字幕或烧录视频，源版本变化时拒绝复用旧草稿。

视频压缩、瘦身、图片压缩、图片导出、剪辑与字幕工作流默认沿用支持的源格式，批量任务逐文件解析容器与扩展名；明确选择的输出格式保持生效。

设置界面完善信息行与布局，文件选择器恢复简洁列表与常用位置。保留已发布的拖动节流、小尺寸缩略图、模型阶段状态及内部工具权限逻辑。

本地检查范围为受影响 Desktop、Browser 编译、网页脚本语法、JSON 与修改块静态检查；没有新增或重跑功能、媒体、截图和性能测试。已清理项目测试媒体与构建缓存，少量文本证据归档到项目外。跨平台安装包由 Release 工作流在后台构建；tag 推送只表示启动发布。
