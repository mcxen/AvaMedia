# AvaMedia v1.1.68

- 视频分类封面增加窗口内解码缓存，重复封面共用图像，缩略图提取与解码在后台执行；分类筐和详情只更新变化内容，减少滚动时重复解码和控件重建。
- 分类任务详情分批载入文件与结果，打开窗口不等待模型推理；服装分组按新增结果更新，并复用已保存的视频采样与人工确认。
- 快速剪辑加入逆向删除片段，保留逆向模式的导出参数；任务行支持双击打开，合并重复任务菜单。
- 整理自动字幕配置及结果布局，AI 画面预览靠近进度和模型状态，移除桌面工具中重复的悬停说明。
- 相关 Desktop Release 编译通过，0 警告、0 错误。本轮未运行滚动性能测量、媒体输出、模型功能回归或安装包验收。
