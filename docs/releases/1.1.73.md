# AvaMedia v1.1.73

- 删除已无生产入口的旧快速剪辑窗口，统一使用当前编辑器、多视频工作区与导出页。保留等分、定时和时间点分割，移除旧窗口专属检查及重复转发代码。
- 剪辑草稿减少重复校验，合并导出在整批校验后只分配一次最终输出名；同源同轨片段在单次执行内复用媒体信息，批量命名复用保留路径集合。
- 多宫格截图的预览与导出共用内存绘制，移除逐格临时 PNG 和独立 FFmpeg 拼图进程。预览时间戳统一为右下角，JPG 改由 Skia 以质量 95 编码；不保证与旧输出字节或像素一致。
- 本版本同时包含前序提交的视频像素宽高比处理、瘦身尺寸候选优化、摘要证据保留及分类处理与预览简化。
- 剪辑改动完成相关 Release 编译，覆盖 Core、MCP、Desktop 和剪辑检查项目，0 警告、0 错误。此任务未运行测试程序、截图、消融实验、真实媒体或性能验收；源码消融清单见 [视频工具消融记录](../VIDEO-TOOLS-ABLATION.md)。
- 自已发布的 v1.1.72 起累计有效变更已超过 1200 行。推送本标签后由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.73)。本次仅发起发布，不等待 CI 或确认安装包完成。
