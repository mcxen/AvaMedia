# AvaMedia 1.1.85

- 所有任务可进入独立任务详情窗口，按“结果 / 文件与参数 / 处理日志”查看；失败原因和完整日志不再依赖通知历史，日志支持选择和复制。
- 视频瘦身在预计或实际节省不足 5%、没有满足当前画质要求的缩小方案时，显示“无需瘦身”，完成任务并保留原视频；编码、文件和输出完整性错误仍显示失败。
- 没有新产出时隐藏播放、打开和拖拽产出操作，通知与 MCP 返回保留原文件的结果；预估与实际体积分别展示，没有评分时不显示虚假指标。
- 画质不合格候选提前结束余下采样，优先检查复杂和限制画质的样本；有效分析以及实际收益不足的结果可复用，避免相同源文件和配置重复完整编码。合格候选仍完成全部采样，保留画质与收益门槛。
- 本地验证范围为独立源码快照中的 Desktop Release 编译及相关静态检查；未运行功能回归、界面截图、媒体输出或性能测试，实际加速幅度尚未测量。

源码以 [v1.1.85 tag](https://github.com/mcxen/AvaMedia/tree/v1.1.85) 为准；安装包由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml) 在后台构建。完整差异见 [版本比较](https://github.com/mcxen/AvaMedia/compare/v1.1.84...v1.1.85)。
