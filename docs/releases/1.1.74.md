# AvaMedia v1.1.74

- 共用媒体探测、预览和 AI 模型资源，后台工具按执行阶段交错处理，移除固定的后台任务并发数量限制。
- 已完成任务的输出封面支持拖入工具及媒体路由，多个工具窗口收拢主要选项，减少不必要的换行和滚动。
- 启动流程复用本次入口已读取的设置，并让历史任务读取与窗口初始化重叠；所有任务在队列服务初始化前恢复，后台 MCP 和专用存储目录继续读取各自配置。播放器的新窗口读取当前设置。
- Windows 安装版将播放器关联注册移到窗口打开后的后台执行，已有命令和扩展名配置一致时跳过重复写入。
