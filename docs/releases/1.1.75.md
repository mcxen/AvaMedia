# AvaMedia v1.1.75

- 工具箱共用自制文件浏览窗口和导入组件，支持常用位置、目录导航、搜索、隐藏文件、类型筛选及多选；桌面保留系统文件选择入口与原生保存权限处理。
- MCP 增加服务器常用文件位置和分页目录元数据接口，供远程文件选择使用。
- 新增随应用打包的网页工具箱。启用 MCP 后打开服务器端口的根地址，即可浏览服务器文件，选择工具及输出目录，下发转换任务，查看共享队列进度、分页结果与日志，并暂停、恢复、停止或重试任务。
- 网页提交保存 UUID 和完整参数，响应丢失或页面刷新后可恢复同一批提交；远程媒体在服务器处理，浏览器只传递路径与任务参数。桌面设置页新增打开网页工具箱及复制网页地址入口。
- Desktop Release 编译及其 Core、FileUi、MCP 依赖通过，0 警告、0 错误；网页 JavaScript 语法、HTML 元素引用、本地化 JSON 和差异静态检查通过。未运行浏览器、跨设备媒体转换、截图或安装包验收。
- 自已发布 v1.1.74 起累计有效源码与界面变更超过 1200 行。推送本标签后由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.75)。本次仅发起发布，不等待 CI 或确认安装包完成。
