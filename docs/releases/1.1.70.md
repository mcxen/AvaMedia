# AvaMedia v1.1.70

- 视频瘦身和视频压缩改为左侧完整高度的视频预览、右侧文件列表与配置。取消预览的固定高度，保存位置、分析停止与执行操作固定在右下方；瘦身文件行集中显示体积、节省比例和状态。
- 自动媒体整理按服装、背景场景与拍摄时间聚合同次拍摄，补充图片拍摄时间读取，并修复服装推理的 Core ML 加速。
- 媒体处理与 AI 推理统一保留 CPU 余量；修复审查发现的文件安全、任务结果与界面动作问题，补充当前架构和界面源码审查记录。
- Desktop 及其 Core、MCP 依赖的 Release 编译通过。本轮界面修改只执行编译与必要静态检查，未运行 UI 截图、功能回归或媒体输出验证；历史功能验证以对应记录为准。
- 自 v1.1.69 起累计有效代码变更超过 1200 行。标签推送后由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.70)。不等待或持续轮询 CI，安装包生成与发布结果以工作流为准。
