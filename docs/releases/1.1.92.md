# AvaMedia v1.1.92

修复主窗口关闭隐藏到托盘的操作：按关闭设置保留后台运行，并在需要时重新启用托盘；托盘不可用时最小化窗口，保留恢复入口。菜单中的退出操作仍执行正常退出。

修复 Mac OS 9 皮肤的重复标题控制栏，统一主窗口、设置、工具窗口、编辑器及文件选择器的经典标题栏、控件和字体样式。经典皮肤使用 12px 像素字体，修正弹出菜单文字渲染、字号、边框、圆角和选中状态，并保留原生窗口阴影。

设置、帮助、词库、硬件检测等工具再次打开时复用已有窗口，并恢复和激活最小化窗口。统一标准按钮的可见 1px 边框及对应交互状态。

本地 Desktop 及其依赖编译通过，0 警告、0 错误；修改的 AXAML、版本 XML 和修改块静态检查通过。未运行真机点击、界面截图、功能、媒体或性能测试。跨平台安装包由 Release 工作流在后台构建，tag 推送表示启动发布。
