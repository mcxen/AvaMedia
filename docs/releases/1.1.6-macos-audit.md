# macOS ARM64 检查：1.1.6 开发版

日期：2026-10-06。检查环境为 Windows；下列结果区分交叉构建、二进制元数据与 Mac 原生运行。

## 发现与修改

1. [v1.1.5 Release](https://github.com/mcxen/AvaMedia/actions/runs/37412918525) 的 Windows 功能测试按中文文字查找按钮，在英文系统下失败，随后跳过整个 macOS job。现有功能与皮肤测试改为按当前语言查找；macOS 独立读取 tag 版本，与 Windows 并行检查。最终发布仍要求两者通过。
2. [ARM64 FFmpeg 原生构建](https://github.com/mcxen/AvaMedia/actions/runs/37405399464) 在 Savannah 下载 FreeType 时连接超时。改用官方 SourceForge 发行镜像，Savannah 作为备用；保留相同 SHA256，并限制连接、下载与重试时间。新镜像在本地成功下载并核对 `36bc4f1cc413335368ee656c42afca65c5a3987e8768cc28cf11ba775e785a5f`。
3. ONNX Runtime 1.23.2 的 ARM64 原生库要求 macOS 13.4，应用未声明最低系统版本。Info.plist 补齐 13.4；归档检查读取 Mach-O 部署版本，拒绝高于应用声明的原生库与下载工具。
4. 官方 QuickJS-NG 0.17.0 ARM64 运行器的 `LC_BUILD_VERSION` 要求 macOS 26.0。临时交叉组装包被归档检查拒绝，不作为合格产物交付。Mac 运行器改为从相同版本固定源码构建，指定 13.4 部署目标、使用 MinSizeRel、关闭额外分配器并去除调试符号；只打包 qjs。构建过程核对架构、部署版本、系统动态库、签名、版本和实际 Promise 执行。

## 本地证据

- macOS ARM64 自包含客户端交叉发布成功；相关功能与皮肤测试项目编译均为 0 警告、0 错误，仅编译，没有在 Windows 运行 Mac 功能回归。
- FFmpeg 及 14 个依赖的源码 SHA256 / Git 提交校验通过。
- QuickJS 0.17.0 源码 SHA256 校验通过：`559bc4c420475e55c7ab4510adbc562f55d7524d75e8e89d79ce4bb02f5687d9`。构建配方及工作流完成语法与静态检查。
- apphost、.NET、Avalonia Native、Skia、HarfBuzz 的 ARM64 部署版本为 11.0；ONNX Runtime 为 13.4；yt-dlp ARM64 外层可执行文件为 11.0。QuickJS 官方运行器为 26.0，已停止打包该文件。
- 新增视频压缩的 VideoToolbox 参数已对照 [FFmpeg 8.1.3 源码](https://github.com/FFmpeg/FFmpeg/blob/n8.1.3/libavcodec/videotoolboxenc.c)：Apple Silicon 支持 `-q:v` 质量模式，码率模式使用 `-b:v` / `-maxrate`；`allow_sw`、`realtime` 与 `prio_speed` 均存在。客户端已有独立的软件编码回退。该核对不代表 GPU 实际执行成功。

本地材料位于忽略目录 `artifacts/macos-audit-v1.1.6/`，包含下载源码、元数据与被拒绝的临时归档。跨平台检查不能生成合格的 Mac QuickJS 运行器；发布须在 ARM64 Mac 上构建。

## 尚待原生验证

修正后的 QuickJS 与定制 FFmpeg 原生构建、完整应用 ZIP / PKG / DMG、实际应用启动及客户端媒体处理由后台 Mac 工作流执行；本记录不将这些项目记为通过。macOS 13.4 实机上的 GPU、设备声音、录屏权限和 Finder 交互仍需设备验收。

本次推送 main 修复代码，暂不创建 1.1.6 发布标签：替代运行器与最终 Mac 归档还未通过原生验收，不将被拒绝的临时包计为完整验收。
