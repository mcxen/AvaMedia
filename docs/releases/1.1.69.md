# AvaMedia v1.1.69

- AI 识别任务增加直接可选的「画面分析与总结」，保留标签识别；逐帧观察与总结使用同一个本地 Qwen3.5 4B 视觉模型，总结请求附原始采样缩略图供模型核对。
- 结果面板显示总结及带时间的画面观察，可点击观察时间定位预览。任务中断后保留已完成的观察；TXT、JSON 和 MCP 结果保存模型、后端及观察记录。
- 本地 AI 推理优先使用 GPU，启动或推理失败时尝试 CPU；独立视频总结的文本模型改为 Huihui Qwen3.5 0.8B abliterated Q8。
- AI 任务保留并展示中断时的部分分析结果，完成状态与可用结果分别保存。
- Core、MCP、Desktop 的 Release 编译及语言资源语法检查通过；本轮未运行新识别总结流程的模型推理、准确性、UI 或安装包验收。
- 累计有效代码变更达到仓库发布门槛。[Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)在标签推送后后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.69)。不等待或持续轮询 CI。
