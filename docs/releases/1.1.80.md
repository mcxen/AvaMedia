# AvaMedia 1.1.80

- 远程管理网页按 macOS 26 浅色风格重新设计：任务、新建任务、剪辑 / 裁剪 / 去水印 / 合并编辑器与服务器页面统一布局，内置 Noto 字体，支持中 / 英文界面。
- 远程 API 扩展：任务状态计数、帧条缩略图、多区域分时段去水印、客户端日志，以及片段边界帧读取与逐帧微调（nudge）；帧条数量做上限保护。
- 设置新增「远程管理与 MCP」页：实时显示服务状态、网页与 MCP 地址及已连接客户端列表；补充 Lucide 图标。
- 桌面快速剪辑编辑器重做：共享窗口标题栏与模式切换、可缩放胶片时间轴卡片与把手标注、起止帧卡片与逐帧微调、卡片式检查器、带强调条的片段列表、导出摘要与「下一个视频 / 导出」操作、短时间码。
- Core 新增 FrameStripCache：共享 LRU 与异步帧条提取，供桌面编辑器与远程 API 复用。
- AI 媒体整理 v3：后端加入分阶段进度模型、重新分组差异、直方图、文件可视化、整理前后摘要、带拼图的缩略图缓存与待定项处理，并提供网页整理 API；界面新增桌面运行 / 结果详情窗口、精简提交窗口，以及网页运行 / 结果页和移动端运行视图。
- 文件选择界面改为紧凑复选框浏览器并带常用位置；裁剪覆盖层增加标签、网格与次要区域。
- 新增 UISPEC.MD（macOS 26 浅色设计规范）与 docs/ui 参考图，AGENTS.md 要求界面工作前先阅读。
- 本地验证：解决方案构建中全部客户端项目（含 Browser / WebAssembly）0 错误；InterfaceTests、BatchUiTests、McpTests（20 项）、ClassificationTests（96 项）通过。QuickClipTests 在固定时长输出首帧像素检查处失败，v1.1.79 在同一环境下有相同失败，与本次改动无关；UiChecks、ClipCropTests、ThemeResourceTests、BatchCropTests 四个测试项目引用已变更的类型，暂无法编译（此前已存在）。

源码以 [v1.1.80 tag](https://github.com/mcxen/AvaMedia/tree/v1.1.80) 为准。[Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml) 在 tag 推送后生成 macOS DMG、Windows portable ZIP / setup EXE 和 Linux tar.gz。
