# v1.1.62

- 版本：1.1.62；标签：`v1.1.62`。
- 左侧一级分类依次为视频、音频、图片、文档、工具集、光盘。分类内部按播放与下载、转换与体积、剪辑与画面、提取与截图、字幕与分析、格式转换、媒体整理等用途分组；光盘标题简化。
- 浅色与深色皮肤采用分类 20 DIP、格式 32 DIP、工具 40 DIP 图标；Mac OS 9 采用 16 / 28 / 32 DIP，Windows XP 采用 16 / 32 / 40 DIP。统一单格入口、居中图标与名称，保留皮肤各自的按钮外观。
- 左侧普通宽度调整为 360 DIP，最低 280 DIP；XP 保持 336 / 300 DIP。列数随侧栏宽度调整，格式入口采用更紧凑的布局；方向键按实际网格位置跨组移动，保留滚动位置、焦点与拖拽入口。
- 发布门槛：相对已发布 `v1.1.61` 累计有效代码变更 1246 行，排除文档、许可证、语言资源与生成文件。
- 本地检查：Core / Mcp / Desktop Release 构建通过，0 警告、0 错误；补丁静态检查与语言资源 JSON 语法检查通过。此次检查范围为编译、语法与静态诊断。
- [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)由标签推送触发，后台生成 macOS 与 Windows 安装包；[Release 页面](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.62)的产物尚未验收，不等待或持续轮询 CI。
