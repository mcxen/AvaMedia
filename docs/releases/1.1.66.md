# AvaMedia v1.1.66

- CPU / GPU 利用率改为车站式逐位翻牌，只翻变化的数字，上下半片沿中缝折叠；增大向上、减少向下，百分号与数值区域宽度固定。配色跟随各皮肤，减少动效时直接显示最新值。
- 本地大模型 CPU / GPU 初始预热比例提高至 30%，选择素材后在 5 秒内逐步增加到 60%；修复 Metal 后端被误标为 CPU。比例控制后台工作节奏，不表示原生推理的硬占用上限。
- 底栏模型状态使用双排方块显示真实校验阶段进度、加载与预热等待、使用及成功/失败状态；模型使用期间自动切换动效，配色与 Mac OS 9 阴影跟随皮肤，状态显隐保留固定占位。
- 保存本机大模型预热实测记录；仅测两个默认生成模型的准备、复用及单次请求速度，数据与限制见[预热速度实测](../acceptance/MODEL-WARMUP-SPEED-20261010.md)。30% 新默认值尚未另行计时。
- 发布提交的 Desktop / Core Release 编译通过，0 警告、0 错误；本次发布未运行功能回归、截图/像素检查、媒体输出、性能或安装包验收。
- [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)在标签推送后后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.66)。不等待或持续轮询 CI。
