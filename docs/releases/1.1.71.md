# AvaMedia v1.1.71

- 天池看图和封面快速预览统一采用本地 Lucide 图标工具栏，常用操作按用途分组，低频操作收进菜单。保留悬停提示、无障碍名称、收藏和播放状态，使用深色媒体画布。
- 正常打开先显示请求的图片，再后台扫描文件夹。点击列表切图时，正图优先于排队中的缩略图；静态图片直接显示处理过方向和颜色的完整像素，省去显示前的中间 PNG 编码和再次解码。切换期间保留上一帧，双页先显示选中页。
- 快速剪辑的起点和终点预览放在左右侧，参数集中在中间；剪辑、片段列表和媒体预览封面可双击打开单图快速预览，复用已有位图，不扫描文件夹。
- 完善服装描述证据和多视角拍摄分组。Desktop 与其 Core、MCP 依赖的 Release 编译通过；本机 20,001 项目录中的 12 次实际列表切图为 74～123 ms、中位数 77 ms。首次打开与封面双击证据见[看图验收记录](../acceptance/IMAGE-VIEWER-SPEED-20261011.md)，结论限定于记录中的真实样本和本机环境。
- 自 v1.1.70 起累计有效代码变更超过 1200 行。推送标签后由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)在后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.71)。不等待或持续轮询 CI，安装包生成与发布结果以工作流为准。
