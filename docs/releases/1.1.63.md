# v1.1.63

- 版本：1.1.63；标签：`v1.1.63`；本次功能提交：[`052f306d4ee52c1961dd9b11829c2070c6b346dd`](https://github.com/mcxen/AvaMedia/commit/052f306d4ee52c1961dd9b11829c2070c6b346dd)。
- 任务封面与精简媒体摘要持久化到本地，封面复用内置图片压缩；源文件状态、选轨与剪辑区间参与缓存标识，重新打开软件可复用未变化的结果。
- 看图、普通图片压缩、效果、导出与图片缩略图共用 `ImageCodec`。普通静态图片读取及压缩无需 FFprobe / FFmpeg；HEIF 与高位深 PNG 保留专门处理。任务摘要和派生图片共用有容量限制、完整性校验及原子写入的缓存。
- 剪辑器、天池播放器和片段缩略图共用请求取消与位图释放。剪辑器移除旧音频准备流程，复用 10 Hz 时间显示与最小化画面交付控制；编辑页和导出页共用片段缩略图加载及并发限制。
- 逐帧定位和排他终点预览共用真实帧时间戳查询。整秒窗口复用时间戳，原始 PNG 与时间戳复用本地缓存，单项上限 8 MB，总体仍限制为 16 MB 内存 / 128 MB 磁盘；视频预览最多两个并发生成请求。
- 已完成任务默认折叠，任务列表支持按范围清理。
- 发布门槛：相对已发布 `v1.1.62` 累计有效代码变更 1388 行，排除文档、许可证、语言资源、图片资源与生成文件。
- 本地检查：Core / Mcp / Desktop Debug 构建通过，0 警告、0 错误；相关补丁静态检查通过。没有执行功能、媒体输出、截图或性能测试。
- [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)在标签推送后后台构建 macOS ARM64 与 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.63)的安装包尚未验收，不等待或持续轮询 CI。
