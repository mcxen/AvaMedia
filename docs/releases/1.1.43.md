# v1.1.43 发布记录

- 版本：1.1.43；标签：v1.1.43。
- 线上视频总结与设置修改提交：`b739841`。
- 自已发布 v1.1.42 起，源码、界面模板及构建配置累计有效变更 1304 行，排除文档、资源和生成文件。
- [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)由新标签触发，统一构建 macOS ARM64 DMG、Windows x64 portable ZIP 和 setup EXE。
- [Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.43)：安装包交由后台流程发布，本地没有确认公共成品。

视频总结增加可配置的线上 Chat Completions 接口，支持文本、单帧和有序多帧输入，以及结构化结果与原资料复核。默认继续使用本地模型。API Key 单独保存于用户数据目录，不进入任务、预设或报告。

macOS 与 Windows 首次引导增加默认勾选的 Beta 开关，导入客户端设置；客户端开关移到“选项 → 系统”。人物片段检测提供按模型定位的下载按钮，返回后重新读取安装状态。

本轮只执行受影响客户端／Core 的独立源码快照 Release 编译、macOS 原生启动器编译、语言 JSON 与 AXAML 语法及 diff 检查。Windows 原生编译交由 CI。没有提供线上服务凭据，未调用线上 AI，也没有执行界面、媒体输出、性能或安装包验收。编译与源码快照记录在本机 `artifacts/online-ai-settings/`。
