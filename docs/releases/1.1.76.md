# AvaMedia 1.1.76

- 网页管理界面改为 Avalonia Browser，复用桌面文件树和文件选择组件，可浏览服务器目录、下发媒体任务、查看任务进度、日志与结果。
- 客户端支持 `--server` 常驻服务模式；设置页集中管理远程服务、局域网访问与控制台入口。
- 网页支持文件夹分类、复制预览、NSFW 分数与时间点、文件预览和下载，以及中断提交恢复。
- 目录地址、分类目标及结果路径默认显示末两级名称；点击编辑完整地址，悬停查看完整路径。修复失败导航显示错误地址的问题，支持 Esc 撤销路径编辑。
- 完成 Browser 发布与 Desktop Release 编译，按用户要求完成真实浏览器中的分类、NSFW 推理、视频转换、播放下载与任务恢复验收。详细范围见 [网页验收记录](../acceptance/WEB-CONSOLE.md)。未验证跨机访问或全部工具回归。
