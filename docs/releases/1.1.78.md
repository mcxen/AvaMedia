# AvaMedia 1.1.78

- 更新下载并校验后立即启动独立安装守护，确认就绪再显示“退出并安装”；应用崩溃或强退也能等待所有实例退出后替换，取消原来的 5 分钟等待上限。
- 待安装信息落盘保存，重新启动后恢复；守护意外退出时自动重新接手，启动失败保留已下载文件，提供“重试安装”。同一安装目录的替换使用独占锁，避免重复安装或降级；保留详细安装日志和失败回滚。
- 开启自动更新立即开始检查，独立于“启动时检查新版本”开关；关闭自动更新会通知守护取消自动准备的更新，保留用户手动下载的更新。
- 修复退出后本地总结／视觉模型服务继续驻留：正常退出统一停止，macOS / Linux 使用管道守护，Windows 使用关闭时终止成员的 Job Object，并阻止退出期间重新启动模型。
- 网页批量视频操作先生成可审阅的处理计划，预览联系表限制生成范围；修正多人视频中清晰人脸的方向评分。
- 本地验证为 Desktop 及其依赖的 Release 编译、Shell 和 PowerShell 语法检查；未执行实际更新替换、跨平台安装、功能或媒体回归，不把编译通过视为安装验收。

源码以 [v1.1.78 tag](https://github.com/mcxen/AvaMedia/tree/v1.1.78) 为准。[Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml) 在 tag 推送后后台生成 macOS DMG、Windows portable ZIP 和 setup EXE；[发布页](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.78) 的安装包在工作流完成后才可用。推送 tag 不代表安装包已构建完成。
