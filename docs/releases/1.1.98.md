# AvaMedia v1.1.98

修复发布准备流程：补齐 v1.1.93–97 的版本说明，普通 CI 在编译前核对源码版本及对应说明，Release 工作流在构建安装包前检查说明文件存在且非空，避免构建全部完成后才因缺少说明而发布失败。

本版包含此前尚未正式发布的播放器启动与单实例修复：系统打开媒体时直接进入天池播放器，重复启动交互客户端转交请求；应用内外共用唯一播放器。

现代皮肤的普通窗口使用 Avalonia 标准窗口和系统标题栏，移除自绘外框、窗口按钮及红绿灯重定位；清理重复标题与原标题栏留白。Windows 托盘菜单宿主排除应用框架和工具窗口定位，保留框架自身位置。Mac OS 9、Windows XP 保留经典皮肤。

统一人物片段、方向检测、自动字幕、视频总结和媒体分类的多阶段任务窗口及持久会话，任务列表按状态分组并展示阶段进度。新增共享计算能力探测、GPU / CPU 路由及实际执行后端反馈，保存吞吐量先验以改善编码 ETA，并完善失败重试与帧解码降级。

本次发布准备通过版本 XML、版本说明及工作流语法检查，未另行运行功能、媒体或界面回归。前一源码版本 v1.1.97 的普通 CI 与三平台安装包构建已通过；本版本安装包由 Release 工作流在后台构建，tag 推送表示启动发布，不代表成品已发布。
