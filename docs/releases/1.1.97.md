# AvaMedia v1.1.97

统一人物片段、方向检测、自动字幕、视频总结和媒体分类的多阶段任务会话与独立任务窗口，持久化阶段、结果和重试检查点。队列展示分段阶段进度及悬停详情，任务列表按状态分组，支持只复制文件的拖出操作。

新增共享计算能力探测、缓存和路由配置，统一 ONNX、Whisper、llama 与 FFmpeg 的实际执行后端反馈；保存吞吐量先验以改善编码 ETA，并完善 GPU 失败后的 CPU 重试和帧解码降级。

修正多阶段内容溢出、过长运行说明、预览文件名称与动作裁切；滚动条常驻规则只作用于多阶段任务窗口。

此版本的普通 CI、Windows / macOS / Linux 安装包构建和工作流中的 macOS / Linux 启动检查均已通过。发布步骤因本说明文件缺失而失败，尚不能据此宣称正式 Release 或安装包已发布。本说明随后补录，原 tag 保持不变；本次未另行运行功能、媒体或界面回归。
