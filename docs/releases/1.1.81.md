# AvaMedia 1.1.81

- 字幕与语音任务更新桌面和远程网页的提交、进度与详情界面，补充语音片段、声音区间、波形、队列摘要及共享进度 API。
- 快速剪辑编辑器调整模式页面、媒体信息与输出配置布局；未编辑的视频增加提示，时间轴保持可见。
- 联系表窗口支持增量预览；媒体文件选择器加入虚拟化预览、缩略图缓存及持久化浏览记录。
- 媒体预览统一阴影，并根据缓存的边缘颜色生成环境光；整理、播放器、设置等界面统一主题资源与控件样式。
- 长视频摘要新增处理基础组件：提示词预算与打包、检查点与可恢复语音识别、语义分段、分段结果缓存及重试、分层归并与覆盖检查、章节核验和媒体处理策略。
- 修复 4 个测试项目中失效的类型或属性引用，使解决方案能够编译；未执行测试。
- 本地发布检查：`~/.dotnet/dotnet build -p:EnableWindowsTargeting=true` 编译通过，0 错误；不运行测试。

本版包含 v1.1.80 之后至 `9ad9097` 的 17 个开发提交，以及编译引用修复、版本号和发布说明提交，共 19 个提交。完整提交列表见 [版本比较](https://github.com/mcxen/AvaMedia/compare/v1.1.80...v1.1.81)。

源码以 [v1.1.81 tag](https://github.com/mcxen/AvaMedia/tree/v1.1.81) 为准；安装包由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml) 构建。
