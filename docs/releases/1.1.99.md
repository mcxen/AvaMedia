# AvaMedia v1.1.99

新增通用多页任务框架：一个窗口管理任务的完整生命周期，顶部页签按阶段自动切换整页（处理、需要用户操作的交互页、完成），已完成页可回看，交互页可修改后从其后重新处理；底部统一操作栏，任务列表把等待用户操作的任务排在进行中最前并提供“去处理”。保留有人片段接入“分析处理 / 调整片段 / 合并确认 / 完成”，自动字幕接入“识别处理 / 输出方式 / 生成 / 完成”，其余多阶段工具迁移到处理页与通用完成页。

新增“调整片段”编辑器（列表 + 检查器）：片段列表完整显示起止时间，支持增删、拆分、合并、起止点调整与检测边界吸附，预览保留片段，导出前确认。

修复代码审查发现的问题：编辑器打开期间原任务被替换时不再覆盖结果；关闭或导出前提交未保存的裁剪选区；准备导出时冻结编辑，避免使用旧版本；尊重检测最短片段长度，短片段不再导致编辑器无法打开；导出提交失败时保留编辑窗口。更新过期的播放器测试断言。

验证范围：整套解决方案编译通过（0 错误、0 警告），TaskLifecycle 与 PersonClipEdit 单元测试 26/26 通过，深色模式启动与合并确认页截图检查；真实视频端到端测试仍在进行，未包含在本版本验证中。tag 推送表示启动发布，安装包由 Release 工作流在后台构建。
