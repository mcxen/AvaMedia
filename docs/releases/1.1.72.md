# AvaMedia v1.1.72

- 主界面改为左侧分类栏和功能面板，任务列表使用更紧凑的封面、状态和进度布局；选项页的媒体设置改为顶部页签，并收紧字段间距。
- 快速剪辑保留左右两侧的起点和终点预览。开始设置靠左，结束设置靠右，淡入、淡出、精度和速度集中在下方两行。
- 图片查看器的工具栏、信息卡和文件列表改用当前主题的表面与文字样式，状态栏显示当前图片的尺寸、格式和大小。
- Desktop 与其 Core、MCP 依赖的 Release 编译通过。自 v1.1.71 起累计有效代码变更超过 1200 行。推送标签后由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)在后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.72)。不等待或持续轮询 CI，安装包生成与发布结果以工作流为准。
