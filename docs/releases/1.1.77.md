# AvaMedia 1.1.77

- 网页视频工具使用可视化参数表单、时间定位、框选裁剪/水印区域和旋转方向预览，保留文件树选择、任务恢复和共享队列。
- 桌面与网页共用裁剪框、区间条和片段时间线；网页快速剪辑支持按文件保存多个片段、复制、分割、排序、反选去除、分段或按源合并导出，复用客户端剪辑计划与源文件检查。
- 预览直接传输有尺寸上限的单帧图片，拖动时取消旧请求，切换页面暂停；服务端限制预览并发和处理时长，减少请求堆积。
- 轨道选择读取实际媒体信息；压缩体积预估共用客户端算法，参数随压缩/编码/字幕模式切换，质量模式不虚构输出大小。
- 本地检查范围为相关项目 Release 编译、Browser 发布和脚本语法；本次新增流程尚未完成浏览器交互与媒体输出验收。完整网页对齐仍在开发，缺口见 [对齐清单](../WEB-VIDEO-PARITY.md)。历史单区间剪辑/裁剪验收不能替代多片段流程验收。
