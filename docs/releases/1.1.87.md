# AvaMedia 1.1.87

- 桌面文件选择器恢复简洁列表：左侧常用位置，右侧名称、大小和修改时间；完整地址可直接输入，双击打开文件夹，保留标准多选和系统选择入口。窗口回到 880 × 600，不再为普通选择加载媒体网格、缩略图或检查器。
- 正确记忆文件夹选择位置；修复目录尾部斜杠导致内部重命名工具导入失败，以及随机下载编号被误判为拍摄代号的问题。
- 已解锁工作区可通过 MCP 完成内部 VL 命名预览与事务撤销，未解锁工作区不展示内部接口。
- 限制媒体预览解码尺寸，合并拖动期间的重复预览请求；统一共享控件背景与圆角裁剪，改善模型加载提示和阶段过渡。
- 本次候选通过 Desktop 编译和静态检查，0 错误、0 警告。文件选择器未执行功能回归、截图或性能验收；前序内部命名工具曾用两份真实媒体副本验证本地 VL、改名和撤销，该结果不等同于整片动作识别准确率或安装包验收。

源码以 [v1.1.87 tag](https://github.com/mcxen/AvaMedia/tree/v1.1.87) 为准；安装包由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml) 在后台构建。完整差异见 [版本比较](https://github.com/mcxen/AvaMedia/compare/v1.1.86...v1.1.87)。
