# AvaMedia v1.1.100

AI 工具入口直达多页任务窗口：点击保留有人片段等工具后直接打开文件选择器，选完媒体立即创建任务并打开该任务的多页任务窗口，处理前的参数也在窗口内配置；移除旧的提交窗口和不可达的旧入口。

保留有人片段处理完成后可回看：处理过程中保存检测帧、检测框和得分，回到“分析处理”页可逐帧浏览；旧任务没有存档时显示说明。

字幕输出方式更易理解：输出方式（烧录到视频 / 导出字幕文件）放在右侧样式区上方，导出文件时选择 SRT、ASS 或 VTT 并说明区别；导出 SRT/VTT 时样式区收起并说明原因，可一键改为烧录；主按钮文字随输出方式变化，并记住上次选择。

修复播放器暂停后关闭窗口卡死：播放资源改在后台释放，窗口立即关闭。修复设置页点击更新时滚动条和页面跳动：滚动条改为叠加显示，状态与按钮预留固定位置。UISPEC 新增布局稳定性和禁用控件就近说明的规则。

验证范围：桌面项目与播放器测试项目编译通过（0 错误），播放器测试 151/151 通过；未做全量解决方案编译和真实视频端到端测试。tag 推送表示启动发布，安装包由 Release 工作流在后台构建。
