# AvaMedia v1.1.65

- 视频总结移除 JoyTag 年龄判断前置检查及额外采样，直接进入字幕、画面和内容分析。
- 本地画面理解、文本生成大模型支持打开工具后后台预热，选择素材后初始化视觉部分；已安装模型及校验结果可直接复用。标签、人物检测、语音等轻量模型按需加载。
- 模型管理可设置初始与选择素材后的 CPU / GPU 预热比例，以及逐步增加用时；默认 10% 在 5 秒内增加到 60%。比例控制后台工作节奏，实际利用率由系统和原生运行时决定。
- 正式任务接管正在进行的加载并撤掉预热限速；停止预热立即反馈，不阻止其他工具操作。空闲大模型默认 5 分钟后释放，支持手动释放，首次 GPU 请求失败保留 CPU 回退。
- 总结取消重复初稿生成、复用当前任务内相同引用的审核结果，单帧预算跳过全片变化扫描，联合视觉只分析时间接近的画面。
- 同步此前下载解析、浏览器视频定位及动态布局稳定性改进。
- 提交源码的 Core / Mcp / Desktop Release 编译和现有总结测试项目编译通过，0 警告、0 错误；未运行功能回归、媒体输出、预热利用率、性能或安装包验收。
- [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml)在标签推送后后台构建 macOS ARM64 和 Windows x64 安装包；[Release 入口](https://github.com/mcxen/AvaMedia/releases/tag/v1.1.65)。不等待或持续轮询 CI。
