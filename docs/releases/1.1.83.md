# AvaMedia 1.1.83

- 完善通用控件、菜单、列表、通知与媒体预览组件，接入转换、剪辑、分类、字幕和人物任务窗口；重做设置分类与主题色选择。
- 统一原生窗口边框与平台尺寸令牌，工具窗口采用独立任务栏入口；内置 Inter 与思源黑体字体，补充 Linux 界面缩放配置。
- 修复文件选择器的逻辑父节点、虚拟列表样式与控件对齐，选择文件时保持主队列可操作，补全数量提示的本地化。
- 长视频总结接入分段编排、检查点恢复、增量结果与进度展示，桌面和远程网页可查看章节与分段证据。
- 移除独立“导出帧”工具入口与执行分支；单帧图片通过天池播放器的“截取当前帧”按钮、菜单或 Ctrl+E / Cmd+E 保存。
- 合入图片与 SVG 编码优化，保留现有字体许可说明。
- 本地检查：隔离工作区的 Desktop Release 编译通过，0 错误、0 警告；Browser Release 编译通过，0 错误，保留两条既有 `_next` 字段警告。相关 Python 脚本、项目 XML、最新 SVG 的语法和代码差异静态检查通过；未运行功能回归、截图、模型或媒体输出验证。

源码以 [v1.1.83 tag](https://github.com/mcxen/AvaMedia/tree/v1.1.83) 为准；安装包由 [Release 工作流](https://github.com/mcxen/AvaMedia/actions/workflows/release.yml) 在后台构建。完整差异见 [版本比较](https://github.com/mcxen/AvaMedia/compare/v1.1.82...v1.1.83)。
