# PDF 工作区

文档组包含合并、拆分、文本提取、TXT 排版、做旧和压缩。图片组的图片 → PDF 使用同一工作区；ZIP 压缩 / 解压归入工具集。

页面区显示真实缩略图，勾选输出页；拖动或前后移动调整顺序，旋转改变输出方向，撤销恢复页面操作。每组显示 24 页，避免大文档一次解码所有预览。右侧查看当前页。导入、缩略图和效果预览在后台执行，取消过时工作；关闭窗口释放位图和临时 PDF。任务进入已有队列，双击可重新调整页面及参数。

- 合并按所选页面的顺序组合，使用 PDFsharp 页面导入保留向量与文字。
- 拆分可在页面后添加拆分点、按固定页数组合、每页一个文件，或把所选页面合为一个文件。结果存入独立输出目录。
- PDF → TXT / DOCX / XLSX 可选择、排列输出页，并预览提取文字。扫描页没有可提取的文字；未实现 OCR、表格结构识别或原排版恢复。
- 图片 → PDF 支持 A4、Letter、原图尺寸、横向、页边距、选页、排序与旋转；图像按比例居中。TXT → PDF 支持纸张、方向、页边距和字号，参数变化重新分页并更新真实预览，选页操作重新开始。
- 做旧提供暖色纸张、黑白复印、泛黄旧纸，控制边缘阴影 / 纸色、颗粒与轻微倾斜。预览与导出共用算法和参数；JPEG 图像页面替代原页面，移除可搜索文字、表单和链接。
- 默认压缩重编码独立 JPEG 图片并压缩内容流，保留文字、向量及页面结构；带蒙版、特殊色彩空间或其他编码的图片保留原样。右侧显示原页预览。整页压缩按指定最长边与 JPEG 质量重新渲染，预览对应栅格化效果，移除可搜索文字、表单和链接。若没有变小，输出原文档副本，队列显示结果。

PDF 拆分、压缩与 TXT 排版一次处理一个文件；合并、做旧、文本提取及图片排版可导入多个文件。所有操作保存新输出，不覆盖源文件；修改 PDF 会影响已有数字签名。加密文档需先解除密码保护。普通页面导入不承诺合并多文档的交互表单、文档书签或签名。

渲染使用 PDFium 157.0.8086（macOS ARM64 / Windows x64 原生资产），页面导入和输出使用现有 PDFsharp，文字读取使用 PdfPig，图像处理使用现有 SkiaSharp。组件许可及版本见 THIRD-PARTY-NOTICES.md、licenses/pdfium/。

交互参考 [iLovePDF 合并](https://www.ilovepdf.com/merge_pdf) 和 [拆分](https://www.ilovepdf.com/split_pdf)；效果及压缩设计参考 [Stirling-PDF](https://github.com/Stirling-Tools/Stirling-PDF)。未复制这些项目的界面资产或实现代码。
