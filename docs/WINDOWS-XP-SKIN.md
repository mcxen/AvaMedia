# Windows XP · Luna

从“显示 → 皮肤 → Windows XP · Luna”启用。选择保存到 `AppSettings.Theme`，重启恢复；已打开的窗口和后续工具窗口共享主题。启动参数 `--winxp` 可临时选择 XP 外观，不覆盖已保存的选择。

采用 Luna 蓝色外观：蓝色渐变标题栏、白色标题及阴影、红色关闭按钮、米白色面板、彩色立体图标、蓝色滚动条和绿色分段进度条。面板使用 `#ECE9D8`，输入边框使用 `#7F9DB9`，选中使用 `#316AC5`。颜色参考 [XP.css](https://github.com/botoxparty/XP.css)，窗口与控件使用本项目的 Avalonia 绘制实现。

| 部分 | 实现 |
| --- | --- |
| 窗口 | 活动 / 非活动标题栏、21 px 标题按钮、窗口边缘缩放、右下角尺寸抓手、最大化后平直外框 |
| 窗口操作 | 双击标题栏最大化 / 还原；图标或标题栏右键打开窗口菜单；Alt+Space 打开菜单；Alt+F4 沿用窗口关闭行为 |
| 移动 / 大小 | 窗口菜单选择后使用方向键调整；Ctrl+方向键微调，Enter 确认，Esc 恢复 |
| 按钮 | 米白渐变面、深蓝描边、默认按钮蓝色内圈、悬停金色内圈、按下位移、键盘虚线焦点、禁用状态 |
| 输入 | 白底蓝灰边框、蓝色文字选择、白色选中文字、数字微调箭头、下拉箭头及白色弹出列表 |
| 选择 | 13 px 复选框、绿色勾选、混合状态、圆形单选框、键盘焦点 |
| 标签 / 折叠 | 米白标签页、选中白底与橙色顶边、加减号折叠框 |
| 菜单 | 米白菜单栏、白色浮层、蓝色选中描边、子菜单箭头、勾选 / 单选项、灰白分隔线 |
| 列表 | 白色内容区、蓝色反白选择；任务辅助文字与状态在选中时同步反白 |
| 进度 / 滑块 | 绿色分段进度和不定进度、蓝色滚动条、双高光抓手、绿色滑块边缘、剪辑区间手柄 |
| 主窗口 | Explorer 风格蓝色分类区、32 px 功能图标、渐变表头、米白状态栏 |
| 播放器 / 编辑器 | 共享 XP 外框、紧凑工具栏和输入；播放器全屏移除外框，保留 XP 控件 |
| 图标 | 原创彩色渐变、纸张折角、金色文件夹、媒体胶片、齿轮、剪刀与操作图标；按用途绘制 |

字体优先采用系统 Tahoma，中文回退到 SimSun / 宋体，macOS 回退到 Songti SC；标题优先使用 Trebuchet MS。没有捆绑 Microsoft 字体、图标或系统位图。缺少对应字体的系统使用字体回退。

`WindowsXP.axaml` 提供主题资源和角色样式，`WindowsXPControls.axaml`、`WindowsXPFields.axaml`、`WindowsXPMenus.axaml` 提供控件模板；`WindowsXPFace`、`WindowsXPArtwork` 和 `WindowsXPWindowFrame` 绘制外观。通用控件通过动态主题资源切换，弹出列表、滚动条和提示也使用相同的主题资源。编辑、选择、菜单、滚动与不定进度行为继承已有的 Avalonia SimpleTheme（MIT）。

切换皮肤保留业务内容对象，恢复普通主题时移除 XP 外框并还原系统装饰。XP 主题停用现代按钮缩放和窗口淡入，使用即时状态反馈。系统文件选择器、任务栏、Dock 和系统托盘由当前操作系统提供。

验证范围按 `AGENTS.md`：桌面项目 Release 编译及相关静态检查；未执行截图、像素比对或功能回归，因此不将本实现描述为逐像素验收结果。
