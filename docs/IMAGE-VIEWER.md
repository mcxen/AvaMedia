# 天池看图

入口在主界面「图片 → 天池看图」。分类窗口的「打开图片」和 AI 标签预览双击也会进入看图器。打开单张图片会同时列出同文件夹图片；拖入文件夹、图片组或压缩包也可浏览。

| HoneyView 功能 | 当前实现 |
|---|---|
| 浏览与缩放 | 缩略图、搜索、自然数字排序、上一张/下一张、适应窗口、仅缩小、适应宽度、原始尺寸、滚轮缩放、拖动平移 |
| 阅读与显示 | 双页、左右阅读方向、旋转、镜像、全屏、保持缩放比例、反色、柔化、锐化、伽马预览 |
| 动画与多页图片 | GIF、WebP、APNG 动画按帧延时和循环次数播放，可暂停；TIFF / ICO 用 Alt+Page Up/Down 翻页 |
| 图片信息 | EXIF、拍摄设备和参数、GPS 地图、EXIF 方向校正、嵌入 ICC 转换至 sRGB |
| 幻灯片与收藏 | 可调间隔、随机/循环播放、持久化收藏与最近打开记录 |
| 图片整理 | 复制、移动、系统回收站、文件夹定位、外部编辑器、原图/当前视图/路径/EXIF 复制、打印、桌面背景 |
| 批量转换 | PNG / JPEG / WebP / TIFF / BMP / AVIF，质量、最长边、旋转/镜像、去除 EXIF/GPS；动画导出首帧 |
| 压缩包看图 | ZIP / RAR / 7Z / LZH / TAR / CBR / CBZ / CB7 / CBT，成员在内存读取，不将路径解压到磁盘 |

图片解码随应用提供，支持 HEIC / HEIF、JPEG、PNG、BMP、TIFF、WebP、AVIF、PSD、DDS、JPEG 2000、TGA、PCX、PNM 系列以及 libraw 支持的相机 RAW。HEIC 显示主图，按 EXIF 方向显示。压缩包由内置 libarchive 读取。

看图、压缩预览、图片缩略图及导出共用 Core 的 `ImageCodec`。列表缩略图和任务封面共用本地缓存存储：内存上限 16 MB / 256 项，磁盘按 128 MB / 2048 项清理；文件大小、修改时间、压缩包成员与预览尺寸参与缓存标识。重新打开看图窗口可复用未变化的缩略图，缓存校验失败时重新生成。图片读取在解码并发限制内进行，避免多个等待请求同时持有完整原图数据。

HoneyView 的 BPG 和 JPEG-XR/JXR 仍没有随应用提供独立解码器，不能宣称所有旧格式完全等价。系统打印、桌面背景和回收站面向 macOS / Windows；Linux 的打印入口调用系统关联程序，桌面背景与回收站尚未接入。

为避免一次打开动画耗尽内存，单个图片文件或压缩包成员上限 256 MB，图像上限 1 亿像素，动画/多页图片展开的像素内存上限 384 MB。超出范围会显示错误。文件切换取消旧请求，离屏缩略图停止加载；转换先写临时文件，再移动到新文件名，不覆盖原图。批量转换支持停止、逐文件错误反馈和已完成数量。

分类界面仅在勾选的视频存在时显示视频采样设置；选中图片时没有视频播放和时间选择控件。文件扩展名与常见图像文件头共同参与媒体类型识别。任务进度可以收起，小窗口自动收起详情；展开时标签/进度在左、预览在右，避免侵占文件列表。
