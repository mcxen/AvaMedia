# 视频剪辑处理工具消融记录

2026-10-11，基线为本次修改前的工作区。按 `Catalog`、主窗口路由、编辑器、任务构造与执行器梳理；本记录是源码消融决策，不是运行消融实验或性能验收。

## 工具清单与决策

| 工具 / 处理能力 | 当前路径 | 决策 |
| --- | --- | --- |
| 快速剪辑、多视频草稿、保留 / 去除片段 | `EditorWindow`、`QuickClipWorkspaceWindow`、`QuickClipWorkflow` | 保留当前工作流；移除没有生产路由的 `QuickClipWindow` 及其行模型、专属 UI 测试和图标分派。 |
| 等分、定时、时间点分割 | `ClipSplitWindow` → `ClipSplit` | 保留统一分割实现；删除仅转发等分调用的 `QuickClipBatch.Split`。 |
| 裁剪、缩放、旋转、镜像、变速、淡入淡出、去水印 | `EditorWindow` / `ConvertWindow` → `MediaFilters` | 已共用滤镜构造，不再另建执行器；移除片段确认时紧邻 `ValidateEdits` 的重复 `Validate`。 |
| 批量裁剪 | `BatchCropWindow` → `BatchCrop` → `MediaEngine` | 保留像素 / 比例裁剪、不同源尺寸校验；受益于公共输出名分配优化。 |
| 批量旋转与人脸方向 | `BatchRotateWindow`、`OrientationTaskService`、`BatchRotate` | 保留人工选择与检测结果确认；方向标记流复制和实际画面旋转用途不同。 |
| 保留有人片段 | `PersonClipService` → 剪辑 / 合并任务 | 保留检测、排除区间与分组导出；同源多段导出复用本次执行内的媒体探测。 |
| 视频合并、DVD / VOB 合并 | `ConversionBatch` → `MediaEngine.BuildArguments` | 保留不同源的画面、帧率、音轨归一化；不替换为仅适用于同源片段的流复制合并。 |
| 视频 / 音频混流、提取音频、提取视频流 | `ConvertWindow` → `MediaEngine` | 保留轨道与时长规则；共享输出名分配优化，不复制各工具的执行链。 |
| 格式转换、修复 / 重新封装 | `ConversionBatch` → `MediaEngine` | 保留重新编码与封装复制区别；音频格式判断不再每次分配临时数组。 |
| 视频压缩、视频瘦身 | `VideoCompression`、`VideoSlimming` | 保留两种能力：指定码率 / 体积和采样画质约束搜索并不等价，不能作为冗余删除。 |
| 导出帧 | `ConvertWindow` → `Operation.Frames` | 保留按间隔连续导帧；与多宫格抽样排版是不同输出。 |
| 多宫格截图 | `BatchVideoTools` | 预览和正式输出使用同一抽样、绘制、时间戳路径；删除逐格临时 PNG、加字后的再次编码和独立 FFmpeg 拼图进程。 |
| 字幕、音量 / 降噪 / 人声增强等剪辑附加处理 | `SubtitleOptions`、`MediaFilters`、`SpeechSubtitleService` | 保留字幕时间轴、轨道复制限制与音频处理；不合并转录推理和媒体滤镜的职责。 |

播放、下载、信息查询、视频总结是相邻入口，不视为可删除的剪辑实现。已有未提交的界面、总结、分类等工作由原任务维护，本次没有将其混入提交。

## 独立消融项

| 项目 | 修改前 | 单项修改后的结构影响 | 保留边界 |
| --- | --- | --- | --- |
| A：旧剪辑窗口 | 现行工作流之外，仍编译 351 行无生产入口的旧窗口代码及模板。 | 删除旧窗口和专属测试；不再维护重复列表、预览加载、选项及分割入口。 | 保留现行工作流测试；核心流复制、分割、草稿独立性、尺寸与源文件保护检查仍在原测试项目。 |
| B：剪辑任务准备 | `PrepareExports` 和编辑确认先 `Validate` 再 `ValidateEdits`；普通任务创建两轮校验；合并先分配通用输出名再改名。 | 删除同一调用内的重复校验和中间输出名；合并任务先验证整批草稿，再分配最终名称。 | `ValidateEdits` 自身调用 `Validate`；导出入口和执行入口各自的有效性检查仍保留；输出名避开源文件和保留路径。 |
| C：媒体探测 | 同一个执行任务中的每个输入片段各启动一次源媒体探测。 | 同一规范化路径及视频 / 音频轨组合只探测一次；N 个同源同轨片段的源探测调用由 N 次降为 1 次。 | 仅在当前执行内复用；不同轨道分别读取，不引入跨任务缓存；流复制产物的包时间戳检查保留。 |
| D：批量输出名 | 每次分配都复制整个保留路径集合；每个文件名字符重新获取非法字符表。 | 已有且比较器一致的 `HashSet` 直接用于查询；每个文件名只获取一次非法字符表。 | 不修改调用方集合；保留磁盘冲突、重名后缀和平台大小写规则。重复同名候选的扫描仍存在。 |
| E：多宫格渲染 | 预览与导出两套绘制；导出逐格落盘、重读加字、重新编码，再启动拼图进程。 | 复用 `Thumbnail` 与同一内存绘制器，每张拼图只编码一次最终文件；删除专用帧临时目录和每张一遍的拼图进程。 | 保留显示比例、所选视频轨、末帧保护、4000 万像素限制、取消、唯一输出名与临时文件完成后移动发布。 |

组合后的链路为“现行编辑工作流 → 独立片段草稿 → 整批校验与最终命名 → 单次执行内探测复用 → 原有编码 / 流复制器”。多宫格预览和导出共享绘制器。各项无需新增兼容分支、配置开关或历史迁移。

多宫格 JPG 由 Skia 以质量 95 编码；预览时间戳改用正式输出的右下角样式。编码字节、JPG 体积及部分像素可能不同于原 FFmpeg 输出，不声明逐像素一致。删除旧窗口测试也移除了依赖旧列表的 UI 分割场景，未新增替代测试；现行工作流检查和核心分割检查保留。
