# 视频总结

视频分类中的“视频总结”支持批量导入视频，独立选择摘要、视频内容总结、字幕提取和内容分析。任务加入现有队列，可编辑、停止、重试；已完成任务直接点击“查看结果”，或右键选择“查看视频总结结果…”打开独立阅读窗口。查看结果不受其他任务正在执行的限制。

结果页左侧保留视频封面、文件名、时长、字幕及采样数量和页面目录；右侧按“概览 / 章节 / 内容分析 / 字幕与逐字稿 / 关键画面 / 分段笔记 / 结果信息”阅读。只展示实际存在的内容。

- 概览将摘要、关键词标签和编号要点分开排版；正文支持可选择文字、标题、粗体、列表、引用和表格，不显示 Markdown 标记。
- 关键词、要点和章节由同一个本地模型以受 JSON Schema 约束的格式生成，独立存入报告。章节导航只接受原资料中的时间戳，未知时间保留文字概括。
- 字幕按时间与正文分列，虚拟列表支持长逐字稿；搜索在后台过滤，`Ctrl/Cmd+F` 定位搜索框。读取输出目录中的 `subtitles.srt`，未导出字幕时读取报告保存的逐字稿。
- 章节、字幕和关键画面的时间按钮调用现有天池播放器，复用一个播放窗口定位原视频；源视频不存在时禁用回看，文字结果仍可阅读。
- 关键画面展示实际保存的采样帧与识别描述，结果页按需加载缓存图片，不重新解码视频或运行模型。
- 工具栏复制当前页，导出当前页、完整 Markdown 总结或 SRT 字幕。另存完整 Markdown 保留画面观察文字，不引用无法随单文件携带的图片；输出目录的原始 `summary.md` 仍引用相邻 `frames/` 图片。
- 使用共享浅色、深色和经典皮肤资源；模型信息和结论范围收在结果信息页，概览中的范围说明默认折叠。

默认在本机推理，不需要 API Key，也不上传视频、语音、字幕或采样画面。以下模型与 llama.cpp b11476 推理工具都超过 10 MB，**不打进发布安装包**。首次执行任务时按需从 Hugging Face / GitHub Release CDN 下载，支持续传、进度和 SHA256 校验；下载完成后缓存在用户数据目录 `AvaMedia/models/`，后续可离线使用。只有小于 10 MB 的辅助资源继续随包提供。模型可在选项的模型管理页下载、校验、修复和删除。

| 模型 | 用途 | 文件体积 |
| --- | --- | --- |
| Qwen3 1.7B Q4_K_M | 中文摘要、分段总结与内容分析 | 1,282,439,264 字节，约 1.28 GB |
| SmolVLM2 500M Q8_0 + Q8 投影 | 抽样画面描述 | 545,593,888 字节，约 546 MB |
| Whisper Small Q5_1（默认） / Base、Tiny（可选） | 语音转录 | 190,085,487 / 59,707,625 / 32,152,673 字节，约 190 / 60 / 32 MB |
| llama.cpp b11476 | 本地推理工具 | 下载归档 Mac 约 12 MB、Windows 约 33 MB；下载后在缓存中解压 |

默认完整模型约 2.02 GB，不含推理工具，占用下载缓存而不增加安装包体积。关闭画面分析后不需要下载约 546 MB 的视觉模型；使用视频或外部字幕也不需要语音模型。画面模型主要支持英语，因此先用英语描述采样帧，再由 Qwen3 结合字幕生成所选语言的总结。两个模型依次加载，任务结束后释放；GPU 启动失败时尝试 CPU。视觉描述使用贪心解码，文本总结使用低温采样，两者不使用额外重复惩罚；总结优先保留字幕或语音中的主题、否定表述和建议语气，画面描述作为未经核实的视觉资料，与语音一起参与章节、要点及摘要。每条生成表述需要原资料编号，并按所引用的原资料进行模型复核；复核仍可能误判。长资料通过选择已有表述缩减上下文，不反复改写事实和引用。

字幕来源可选自动、视频字幕轨、语音识别或外部 SRT / VTT / ASS / SSA。自动模式优先使用可转为文本的字幕轨，否则使用 Whisper。位图字幕和已烧录字幕不能直接提取为文本，使用语音识别。字幕、音轨索引从 0 开始；字幕 -1 表示自动选择。外部字幕只用于单个视频，时间轴按源视频保留。

画面分析默认最多保留 12 帧，可调整至 1–48 帧。先以最多 2 fps、最多 2048 帧的 64×64 RGB 低分辨率扫描寻找全局和局部画面变化；保留均匀覆盖候选，再加入变化前后画面并补充均匀候选。候选缩略图与全部已选画面进行保守比较，跳过近似重复图，因此实际数量可能小于上限。局部变化可以帮助采到人物或物体的位置变化，但不执行人物身份识别，也不保证捕获每次人物出现或离开。长视频扫描间隔会增大，短事件仍可能遗漏。像素变化仅用于选帧，不作为切镜证据。

保存的采样图最长边最多 768 像素，不添加黑边。除了单帧描述，还把按源时间排序的相邻 2–3 帧以重叠窗口联合传入视觉模型，图像之间插入帧编号和时间标签；多帧输入最长边最多 384 像素，适配现有视觉上下文预算。记录实际帧间隔，不把间隔中的事件当作连续观察；任一相邻间隔超过 5 秒的窗口标为静态比较，不能证明中间的动作。无音轨或无语音的视频可按采样画面生成总结。字幕提取可以单独执行，不加载总结和视觉模型。长字幕按字符预算处理全部片段，再逐级合并笔记；不会通过截断尾部来适应上下文。

语音片段使用 `T` 编号，单帧使用 `F` 编号，多帧观察使用 `V` 编号。章节标题、正文、关键词、要点、摘要和分析都需要有效引用；未知编号使整条表述失效，不仅删除编号。生成后用引用的原资料审核支持程度，不确定或扩大范围的内容被过滤。章节时间由引用资料的起点计算，模型不生成导航时间。引用只能证明资料来源，不能保证视觉描述或模型审核本身正确。

结果页的摘要、要点、章节和分析提供证据时间按钮；“证据”页保留原语音及视觉观察，多帧观察可回看其中的各帧。报告保存 `Evidence`、`Sequences`、`Sampling`、`RejectedClaims` 和各条结论的 `EvidenceIds`。摘要、章节、分析的独立 Markdown 和完整 Markdown 附原资料编号及证据正文，便于脱离结果页复核。

每个视频输出到独立目录，不覆盖源文件或已有结果：

- `abstract.md`：摘要。
- `content-summary.md`：主要内容、章节及结论。
- `analysis.md`：有依据的作者观点、可见画面、建议与限制。
- `summary.md`：合并报告、分段笔记及采样画面。
- `subtitles.srt`、`transcript.txt`：选中字幕提取且存在字幕或语音时生成。
- `frames/`：启用画面分析时的原始采样帧。
- `report.json`：结构化摘要、关键词、要点、章节、逐字稿、使用的模型及结果范围。

只生成选中的独立文件；报告保存识别逐字稿以便回看，摘要或分析任务同时整理关键词与要点。没有语音或字幕时报告标明原因，不制造空字幕；字幕提取单独执行时会明确提示没有可提取内容。输出目录在成功后一次性保存，取消或失败会清除临时报告，模型下载进度保留。

极小模型可能遗漏细节或产生错误，画面采样也无法覆盖所有事件。结果会标明字幕来源、采样数和结论范围；语音识别、内容分析及时间戳应按需要复核。它不执行事实核验，也不进行人物身份识别。

总结和视觉模型文件来源、固定 revision、大小和 SHA256 位于 `src/AvaMedia.Core/Assets/SummaryModels.json`；语音模型和推理工具沿用现有固定来源清单。任务通过共享 `ModelStore` 下载和管理，运行时只监听带临时认证的本机回环地址。许可证与归属说明保存在 `licenses/local-summary/` 和 `licenses/speech/`。

2026-10-08 在本机实际下载并校验以上模型，通过生产视频总结流程处理 32 秒样片：OpenCV `vtest.avi` 的真实行人画面配本机合成中文旁白，没有内嵌或外部字幕。最终运行耗时约 27 秒，完整保留 6 条语音转录、12 帧观察、摘要和要点，源视频 SHA256 不变。

内容核对结论为部分通过：摘要和关键要点保留了行人活动、保留有人片段与删除空白片段的建议，以及“不统计行人数量、不识别个人身份”的限制。章节仍可能把画面边缘进出误写成进出建筑，内容分析也可能把抽样帧误写成镜头切换；部分转录仍有错字。因此没有将完整内容质量判为验收通过。结果与逐项核对记录保存在本地 `artifacts/video-summary-sample/`。
