# 视频总结

## 线上 AI

视频总结默认使用本地模型，也可选择“线上 AI”及具体供应商。通过“配置供应商…”进入“选项 → AI 供应商”，添加、编辑、停用或删除独立配置，并设置默认供应商。预设包含 OpenAI、OpenRouter、硅基流动、Ollama 和自定义供应商；每家独立保存地址、API Key、文本模型和视觉模型。视觉模型留空时沿用文本模型，此时该模型须支持图像输入。接口地址支持基础地址（例如 `https://api.openai.com/v1`）或完整的 `/chat/completions` 地址，远程接口须使用 HTTPS，本机接口可使用 HTTP。

请求遵循 [Chat Completions 格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，支持 Bearer 认证、文本及 `image_url` 多图输入。“高级”可选择输出长度参数 `max_completion_tokens` 或 `max_tokens`、提示词约束 / JSON 对象 / 严格 JSON Schema，以及 10–600 秒的超时。预设按服务的接口文档填写地址与输出长度参数，模型 ID 由用户选择，服务和模型必须支持所选参数；失败请求不自动重发。

“连接并获取模型”手动请求 `/models`，最多等待 30 秒，可以取消。模型 ID 可搜索或手动输入；没有模型列表接口时仍可保存和使用手填模型。获取列表不自动修改已填模型，也不证明模型支持图像或结构化输出。编辑连接、切换供应商或关闭设置会取消进行中的请求，避免旧响应覆盖新配置；打开、保存设置和运行本地任务不会调用供应商。

线上模式发送转录资料、采样画面及总结指令，并继续执行相同的引用复核和内容约束。语音识别仍使用本地 Whisper；没有内嵌或外部字幕时，需下载语音模型。线上模式不下载 Qwen、SmolVLM 或 llama.cpp。

排队时保存本地／线上选择和具体供应商标识，默认供应商也在排队时解析为具体标识。执行时读取该供应商的当前配置；配置删除或停用后明确报错，不切换到其他服务。报告记录实际供应商名称及模型 ID。API Key 默认遮罩，不进入任务、预设、报告和 `settings.json`，按供应商标识及地址单独保存在用户数据目录的 `online-ai-key.json`，macOS/Linux 文件权限为仅当前用户读写；该文件是明文凭据。清空密钥或删除供应商并应用会移除对应凭据，全部清空后删除凭据文件。

设置结构参考 [Cherry Studio 的供应商与模型管理](https://github.com/CherryHQ/cherry-studio-docs/blob/main/pre-basic/settings/providers.md)、[供应商注册表](https://github.com/CherryHQ/cherry-studio/blob/main/docs/references/provider-model/provider-registry.md)，接口获取及手填模型参考 [Open WebUI](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible/)。预设参数按 [OpenAI](https://developers.openai.com/api/reference/resources/models/methods/list)、[Ollama](https://docs.ollama.com/api/openai-compatibility)、[OpenRouter](https://openrouter.ai/docs/quickstart)、[硅基流动](https://docs.siliconflow.cn/docs/api/chat-completions-post)官方接口文档核对。

人物片段检测中，未下载的模型显示“下载模型…”按钮，点击后打开模型管理并定位对应模型；返回检测窗口时刷新下载状态。

此次接口与设置改动只进行相关编译和静态检查，未提供线上服务凭据，因此没有执行线上请求或将本地样片结果作为线上验证结果。

视频分类中的“视频总结”支持批量导入视频，独立选择摘要、视频内容总结、字幕提取和内容分析。任务加入现有队列，可编辑、停止、重试；已完成任务直接点击“查看结果”，或右键选择“查看视频总结结果…”打开独立阅读窗口。查看结果不受其他任务正在执行的限制。

执行流程依次为读取视频、字幕与语音、可选画面分析、内容总结和保存结果。已移除 JoyTag 年龄判断前置流程及额外的 16 帧检查；视频总结不再依赖 JoyTag。仅在启用画面分析时采样并调用视觉模型，纯字幕／语音总结不抽取画面。文本模型直接生成选中的带引用摘要、章节或分析，最终总结复用其中一项，不先生成另一份字幕初稿；没有可用资料时不加载文本模型。视觉或总结模型自身拒绝回答时仍保留对应结果状态。

结果页左侧保留视频封面、文件名、时长、字幕及采样数量和页面目录；右侧按“概览 / 章节 / 内容分析 / 字幕与逐字稿 / 关键画面 / 分段笔记 / 结果信息”阅读。只展示实际存在的内容。

- 概览将摘要、关键词标签和编号要点分开排版；正文支持可选择文字、标题、粗体、列表、引用和表格，不显示 Markdown 标记。
- 关键词、要点和章节由同一个本地模型以受 JSON Schema 约束的格式生成，独立存入报告。章节导航只接受原资料中的时间戳，未知时间保留文字概括。
- 字幕按时间与正文分列，虚拟列表支持长逐字稿；搜索在后台过滤，`Ctrl/Cmd+F` 定位搜索框。读取输出目录中的 `subtitles.srt`，未导出字幕时读取报告保存的逐字稿。
- 章节、字幕和关键画面的时间按钮调用现有天池播放器，复用一个播放窗口定位原视频；源视频不存在时禁用回看，文字结果仍可阅读。
- 关键画面展示实际保存的采样帧与识别描述，结果页按需加载缓存图片，不重新解码视频或运行模型。
- 工具栏复制当前页，导出当前页、完整 Markdown 总结或 SRT 字幕。另存完整 Markdown 保留画面观察文字，不引用无法随单文件携带的图片；输出目录的原始 `summary.md` 仍引用相邻 `frames/` 图片。
- 使用共享浅色、深色和经典皮肤资源；模型信息和结论范围收在结果信息页，概览中的范围说明默认折叠。

默认在本机推理，不需要 API Key，也不上传视频、语音、字幕或采样画面。以下模型与 llama.cpp b11476 推理工具都超过 10 MB，**不打进发布安装包**。首次执行任务时按需从 Hugging Face / GitHub Release CDN 下载，支持续传、进度和 SHA256 校验；下载完成后缓存在用户数据目录 `AvaMedia/models/`，后续可离线使用。只有小于 10 MB 的辅助资源继续随包提供。模型可在选项的模型管理页下载、校验、修复和删除。

| 模型 | 用途 | 文件体积 |
| --- | --- | --- |
| Qwen3 1.7B Q4_K_M | 中文摘要、分段总结与内容分析 | 1,282,439,264 字节，约 1.28 GB |
| Qwen3.5 4B abliterated Q4 + 投影（默认视觉模型） | 抽样画面描述 | 3,379,938,240 字节，约 3.38 GB |
| SmolVLM2 500M Q8_0 + Q8 投影（可选） | 抽样画面描述 | 545,593,888 字节，约 546 MB |
| Whisper Small / Base / Tiny Q5_1 | 语音转录 | 190,085,487 / 59,707,625 / 32,152,673 字节，约 190 / 60 / 32 MB |
| llama.cpp b11476 | 本地推理工具 | 下载归档 Mac 约 12 MB、Windows 约 33 MB；下载后在缓存中解压 |

下载体积由选定模型决定，占用下载缓存而不增加安装包体积。关闭画面分析后不下载视觉模型；使用视频或外部字幕时不需要语音模型。Qwen3.5 用中文描述采样帧，可选 SmolVLM2 使用简短英语描述，再由 Qwen3 结合字幕生成所选语言的总结。视觉和文本模型按实际阶段租用已预热进程，任务结束后保留至空闲释放；GPU 启动或首次推理失败时尝试 CPU。SmolVLM2 描述使用贪心解码、1.1 重复惩罚和换行停止，最多保留单帧一句、多帧两句完整观察。达到输出长度上限时，有完整句子的视觉结果仍可使用；不完整视觉片段和被截断的结构化总结不作为有效结果。

模型取用复用进程内已验证且文件未变化的校验结果，避免反复读取整个权重；首次取用、文件改变、下载和手动校验仍完整检查。llama.cpp 关闭自带空跑，改由工具打开时初始化已安装的大模型解码器，选择素材后用一张画面初始化视觉编码；预热每次最多生成一个 token，正式任务直接复用进程。选项中的“本地大模型预热”可分别设置初始和选择素材后的 CPU / GPU 工作节奏及增加用时；默认 10% 逐步增加到 60%，实际利用率由原生运行时及系统调度。标签、人物检测和语音等模型不自动预热。语音识别沿用已经读取的媒体信息；总结中同一表述及同一引用的审核结果也复用，新增表述仍按自己的引用核对。

文本总结使用低温采样，分别处理语音、单帧和多帧资料。连续字幕先按上下文归纳为段落笔记，合并相邻对话，提炼主题、主要过程及已说明的结果，省略招呼、感叹与重复插话；原文完整保留在逐字稿和证据页。视觉复合描述拆成简短事实，减少不可靠推断连带删除可见内容的情况。长资料按时间顺序逐级合并全部段落笔记，保留主要进展、结尾及重要建议、否定和条件。语音与视觉同时存在时，语音优先承载叙事，视觉上下文最多占字符预算的三分之一，补充与主题有关的可见信息。

摘要、内容分析、关键要点及章节正文均综合改写，使用所选输出语言；摘要交代主题、主要经过和资料明确说明的结果，章节按时间与主题组织，每章归纳多条相关内容。每条表述可引用 1–8 条必要原资料，并只用自己的引用单独复核，避免借用其他候选的依据；建议、否定和条件须保留原意。关键词与章节标题也分别生成和审核。摘要、分析或所选章节全部未通过审核时明确报错，不再复制开头台词或第一条画面描述来填充成功结果。上述措施不保证模型保留所有重要内容或正确理解原资料。

字幕来源可选自动、视频字幕轨、语音识别或外部 SRT / VTT / ASS / SSA。自动模式优先使用可转为文本的字幕轨，否则使用 Whisper。位图字幕和已烧录字幕不能直接提取为文本，使用语音识别。字幕、音轨索引从 0 开始；字幕 -1 表示自动选择。外部字幕只用于单个视频，时间轴按源视频保留。

画面分析默认最多保留 12 帧，可调整至 1–48 帧。只有一帧预算时直接取均匀覆盖帧，不执行无用途的全片变化扫描。多帧预算先以最多 2 fps、最多 2048 帧的 64×64 RGB 低分辨率扫描寻找全局和局部画面变化；保留均匀覆盖候选，再加入变化前后画面并补充均匀候选。候选缩略图与全部已选画面进行保守比较，跳过近似重复图，因此实际数量可能小于上限。局部变化可以帮助采到人物或物体的位置变化，但不执行人物身份识别，也不保证捕获每次人物出现或离开。长视频扫描间隔会增大，短事件仍可能遗漏。像素变化仅用于选帧，不作为切镜证据。

保存的采样图最长边最多 768 像素，不添加黑边。除了单帧描述，还把按源时间排序且相邻间隔不超过 5 秒的 2–3 帧以重叠窗口联合传入视觉模型，图像之间插入帧编号和时间标签；较远画面保留单帧描述，不额外执行静态比较。多帧输入最长边最多 384 像素，按需缩小并复用，适配现有视觉上下文预算。记录实际帧间隔，不把间隔中的事件当作连续观察。无音轨或无语音的视频可按采样画面生成总结。字幕提取可以单独执行，不加载总结和视觉模型。长字幕按字符预算处理全部片段，再逐级合并笔记；不会通过截断尾部来适应上下文。

语音片段使用 `T` 编号，单帧使用 `F` 编号，多帧观察使用 `V` 编号。章节标题、正文、关键词、要点、摘要和分析都需要有效引用；未知编号使整条表述失效，不仅删除编号。生成后用引用的原资料审核支持程度，不确定或扩大范围的内容被过滤。另用中英日关键词约束未独立验证的标牌含义、地点用途、施工、交谈、身份、活动目的、镜头变化及社会意义等推断：引用的语音未明确涉及相应主题时，相关表述被拒绝。纯画面不能生成作者观点；部分采样或“不执行某事”的原文也不能证明全片“未提及某事”。这些词义约束可能漏判或过度过滤，不构成事实核验。章节时间由引用资料的起点计算，模型不生成导航时间。引用只能证明资料来源，不能保证视觉描述或模型审核本身正确。

结果页的摘要、要点、章节和分析提供证据时间按钮；“证据”页保留原语音及视觉观察，多帧观察可回看其中的各帧。报告保存 `Evidence`、`Sequences`、`Sampling`、`RejectedClaims` 和各条结论的 `EvidenceIds`。摘要、章节、分析的独立 Markdown 和完整 Markdown 附原资料编号及证据正文，便于脱离结果页复核。

每个视频输出到独立目录，不覆盖源文件或已有结果：

- `abstract.md`：摘要。
- `content-summary.md`：主要内容、章节及结论。
- `analysis.md`：有依据的作者观点、可见画面、建议与限制。
- `summary.md`：合并报告、分段笔记及采样画面。
- `subtitles.srt`、`transcript.txt`：选中字幕提取且存在字幕或语音时生成。
- `frames/`：启用画面分析时的原始采样帧。
- `report.json`：结构化摘要、关键词、要点、章节、逐字稿、使用的模型及结果范围。

只生成选中的独立文件；报告保存识别逐字稿以便回看，摘要或分析任务同时整理关键词与要点。没有语音或字幕时报告标明原因，不制造空字幕；字幕提取单独执行时会明确提示没有可提取内容。输出目录在成功后一次性保存，取消或失败会清除临时报告，模型下载进度保留。

极小模型可能遗漏细节或产生错误，画面采样也无法覆盖所有事件。结果会标明字幕来源、采样数和结论范围；语音识别、内容分析及时间戳应按需要复核。它不执行事实核验，也不进行人物身份识别。

总结和视觉模型文件来源、固定 revision、大小和 SHA256 位于 `src/AvaMedia.Core/Assets/SummaryModels.json`；语音模型和推理工具沿用现有固定来源清单。任务通过共享 `ModelStore` 下载和管理，运行时只监听带临时认证的本机回环地址。许可证与归属说明保存在 `licenses/local-summary/` 和 `licenses/speech/`。

2026-10-08 在本机实际下载并校验以上模型，通过生产视频总结流程处理 32 秒样片：OpenCV `vtest.avi` 的真实行人画面配本机合成中文旁白，没有内嵌或外部字幕。最终运行耗时约 27 秒，完整保留 6 条语音转录、12 帧观察、摘要和要点，源视频 SHA256 不变。

本次修改使用已提交源码加任务文件的独立快照编译 Core 与客户端，零警告、零错误；共享工作区中的播放器改动另行进行。此次未执行全量回归或安装包验收，发布成品以后台 Release 工作流为准。
