# 文件夹分类

入口：工具集 → 文件夹分类。也可把图片、视频拖到这个入口，或从媒体路由菜单选择。

1. 添加文件夹，选择是否扫描子文件夹。只导入图片和视频，跳过符号链接及当前分类目录；无法访问的路径显示在窗口底部。
2. 选择分类组。每组有 2–12 个命名类别，组内只选一类。默认“场景”包含森林、海边、山景、城市、室内、其他场景；还提供露点 / 非露点、房间 / 床上 / 浴室、空镜 / 有人物、外观年龄段。点击预设或使用已保存分类，会替换选中的分类组；“添加分类组”可创建独立的新组。
3. 点击自动标签与分类。JoyTag 负责标签，场景分类使用本地语义模型。首次使用显示模型下载进度，语义模型下载须在窗口中确认。可以停止、保留已完成结果并重试未完成文件。
4. 分类筐展示类别名、封面和文件数量。点击筐筛选文件，点击封面在右侧放大查看；视频可切换采样画面或打开播放。可以搜索文件名 / 标签、勾选待整理文件，并拖动封面到目标筐调整归属；右侧类别下拉框提供相同操作。不下载模型也可手动分类。
5. 核对右侧“将放入”的目录，点击预览分类目录，再执行复制或移动。默认复制，移动前确认且要求转换队列停止。

类别名直接用作目录名。例如使用室内场景并按类型分目录，输出为 `视频/房间/原文件.mp4`、`视频/床上/原文件.mp4` 或 `视频/浴室/原文件.mp4`，不确定结果进入 `视频/待确认/`。使用多组时按组顺序嵌套，例如 `视频/场景/室内/空镜/有人物/原文件.mp4`。封面与拖动操作只调整分类计划，执行整理后才写入文件。

自定义组只需填写分类名称、类别名和每类的画面描述，例如“床上”对应“床、枕头和被褥”。判断方式默认“自动”，使用应用内置参数，无需填写阈值。选择“手动调整”会展开“高级设置”，可调整最低匹配分数、与其他类别的最小差距和视频画面一致率；切回自动会恢复内置参数。判断方式随分类一起保存。点击保存后进入“已保存分类”，也可选中当前组点击“保存分类”。从当前列表移除组不会删除保存的分类，编辑同一组会更新保存内容。

“露点与否”按乳头是否裸露判断，使用 JoyTag 的 `nipples`、`puffy_nipples`、`nipple_slip` 标签。两类名称为“露点 / 非露点”或“漏点 / 非漏点”的自定义组也会自动采用这条识别路径；保存后记录两类的标识，重命名不会改变判断方式。只使用这组分类时无需语义模型。该组的画面描述可留空，保存时自动填入定义。

露点分类的自动模式：最高标签分数达到 0.40 即命中；低于 0.20 归入非露点；中间范围进入待确认。0.40 采用 [JoyTag 上游的标签阈值](https://github.com/fpgaminer/joytag#quick-info)，低分侧另留不确定范围，尚未对整库校准。胸部大小、乳沟、衣服下凸点及一般 NSFW 分数不作为露点条件。视频采样中一次命中即可归入露点；只有全部采样画面的完整标签分数都低于低分界线，才归入非露点。分数缺失或存在边缘画面时进入待确认，不把缺失的标签当成零。高级设置提供“露点判定分数”和“待确认分数范围”，该组不使用视频画面一致率。手动模式的低分界线为判定分数减去待确认范围，最低为零。“非露点”表示采样中未检出，有限采样仍可能遗漏短暂画面。

“设为默认”保存当前组的组合及顺序，下次打开自动载入；编辑窗口的“高级设置”中也可勾选“设为默认分类”。临时替换、添加或移除组不改变默认组合，点击“载入默认”即可恢复。删除已保存分类时，它也会从当前及默认组合中移除。配置保存在用户数据目录下的 `tool-folder-classification.json`。

图片比较同组各类的语义分数，最高分须达到阈值，并领先第二名指定分差。自动模式采用最低分数 0.50、最小差距 0.04、视频画面一致率 80%，目前不按文件自动校准参数。视频默认均匀采样 12 帧，可设为 1–32 帧；只有达到这些条件的采样画面才计为命中。手动模式的一致率可配置为 51%–100%。缺失分数、分差不足或场景分歧进入待确认，不强制塞入某类。

匹配分数为语义相似度，并非校准概率。外观年龄段只能粗略判断，无法确定真实年龄。视频采样可能遗漏短暂画面，分类结果需要人工核对。手动确认在重新分析和调整标签阈值时保留；停止或分析失败时也保留已确认的归属，未完成的分析仍可重试。点击“恢复自动分类”可重新采用该组的识别结果。源文件变化后重新分析会清除旧人工结论。

输出不转码，重名加数字后缀，不覆盖已有文件。可为每个媒体生成 `.tags.txt`，并导出包含组定义、标签、各类分数、采样证据、人工修订及目录预览的 JSON。移除所有组后仍可自动打标签并按视频 / 图片整理。

每次整理独立保存操作记录，支持撤销上次复制或移动。文件大小、修改时间或标签报告改变后不再撤销该项；停止整理时已完成副本仍保留在记录中。移动与撤销移动同步更新主窗口队列输入路径。

封面只在可见列表行和分类筐中解码，离开视图时释放位图和请求；并发解码上限为 2，编码封面缓存上限为 96 张 / 24 MiB。

本次交付验证限于 Core / Desktop 编译与相关静态诊断，未运行功能、媒体或界面回归。
