# 文件夹分类

入口：工具集 → 文件夹分类。也可把图片、视频拖到这个入口，或从媒体路由菜单选择文件夹分类。

1. 添加文件夹，选择是否扫描子文件夹。扫描只导入图片和视频，跳过符号链接及当前分类目录；无法访问的路径显示在窗口底部。
2. 选择分类规则。内置森林、空镜、海边、山景、城市、室内，默认选择森林与空镜。空镜指不含可见人物的场景。自定义规则填写“是”和“否”的具体画面描述。移除所有规则时仍可自动打标签并按视频 / 图片整理。
3. 点击自动标签与分类。JoyTag 负责标签，场景分类使用本地语义模型。首次使用显示模型下载进度，语义模型下载须在窗口中确认。可以停止、保留已完成结果并重试未完成文件。
4. 在右侧核对分数和采样时间，可以打开原文件，并逐条改为是、否或待确认。
5. 预览分类目录，再执行复制或移动。默认复制；移动前确认且要求转换队列已经停止。多条规则依次形成子目录，例如 `视频/森林_是/空镜_是/原文件.mp4`，不确定结果进入对应的待确认目录。

自定义分类点击保存后进入“已保存分类”，名称、两侧描述、命中阈值和最小分差均持久保存。也可选中当前规则后点击“保存分类”。从当前列表移除规则不会删除保存的分类，可以从“已保存分类”选择并点击使用，编辑后的同一分类会更新保存内容。

“设为默认”保存当前整组规则及顺序，下次打开自动载入；自定义分类编辑窗口也可勾选“同时将当前规则设为默认”。临时添加或移除规则不改变默认组合，点击“载入默认”即可恢复。删除已保存分类时，它也会从当前及默认组合中移除。配置保存在用户数据目录下的 `tool-folder-classification.json`。

输出不转码。重名文件加数字后缀，不覆盖已有文件。可为每个媒体生成 `.tags.txt`，并导出包含规则、标签、分数、采样证据、人工修订及目录预览的 JSON。

每次整理独立保存操作记录，支持撤销上次复制或移动；文件大小、修改时间或标签报告改变后不再撤销该项。停止整理时已完成副本仍保留在记录中。移动与撤销移动同步更新主窗口队列的输入路径。

视频默认均匀采样 12 帧，可设为 1–32 帧。场景规则要求所有采样画面在阈值与分差上支持同一侧；画面混合或分差不足进入待确认。视频采样可能遗漏短暂画面，分类结果需人工核对。

本次交付验证限于 Core / Desktop 编译与相关静态诊断，未运行功能、媒体或界面回归。
