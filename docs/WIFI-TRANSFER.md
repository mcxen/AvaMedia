# WiFi 传文件

顶部菜单和工具栏的 **WiFi 传文件** 会打开收发窗口，并在所选局域网 IPv4 地址上开启临时 HTTP 服务。电脑可以通过 WiFi 或有线连接路由器，手机须在同一局域网中。

1. 选择电脑连接路由器的网络地址，手机扫描二维码，在浏览器中打开。也可复制地址手动打开。
2. 手机选择相册或文件，点击 **开始上传**。支持多文件、上传进度、取消和失败重试，单个文件上限 50 GiB。传输时保持网页在前台。
3. 完成的文件出现在电脑 **接收到电脑** 列表中。多选或 **全选已接收** 后，点击 **导入转换**，通过现有文件路由选择转换工具。
4. 视频也可点击 **高画质视频压缩**：打开现有压缩窗口，默认 HEVC、手动质量 18、较慢编码、原分辨率和原帧率，再确认加入任务队列。参数仍可调整。
5. 电脑的 **发送到手机** 标签页可以添加任意文件，手机在 **从电脑下载** 区域下载。取消分享移除下载入口，保留电脑上的源文件。

## iPhone 的 MOV 与照片

相册选择器提供给网页的文件格式由 iOS 决定。需要原始 MOV / HEIC 时，先将原件从相册存储到“文件”，再通过网页 **从文件选择** 上传。传输服务原样保存浏览器提交的字节，不在上传阶段转码。

高画质压缩仍是有损编码，不能保证所有视频都压小或达到数学无损；已采用高效 HEVC 的视频可能没有明显体积收益。保留分辨率和帧率不代表保留全部色彩元数据。现有压缩流程会识别 HDR，并在压缩窗口说明到 SDR 的转换。完成任务后，按现有任务结果查看实际体积。

## 接收文件与连接

接收文件保存在本机用户应用数据目录的 `AvaMedia/WifiReceived` 中；每次上传使用独立目录，保留安全处理后的文件名，重名不会覆盖。只有完整接收并关闭写入流的文件才可导入；中断上传会尝试清理临时文件。重新打开窗口仍显示已接收的文件，可通过 **打开接收目录** 自行管理。

临时服务仅绑定选中的网络地址，使用随机会话地址；网页只可上传文件或下载电脑明确分享的文件。关闭窗口、退出应用或 **停止接收** 会取消传输并撤销当前地址，再次开启会生成新的二维码。会话地址允许持有者访问，HTTP 未加密，请只在可信局域网内使用。

无法连接时，检查两台设备是否在同一局域网、是否选中了 VPN / 虚拟网卡地址、系统防火墙是否允许应用的专用网络访问，以及路由器是否开启访客网络或设备隔离。服务无需管理员权限；应用不会自动修改防火墙或创建无线热点。
