# 模型管理与视频分析 Beta

AI 重命名的候选词在 **选项 → 词库管理** 中管理；各重命名界面提供选择入口。词库、导入格式和处理可视化见 [WORD-LIBRARIES.md](WORD-LIBRARIES.md)。

选项 → 常规 → 开启 Beta 功能，应用后在视频分类中显示“保留有人片段 · Beta”。默认关闭。关闭 Beta 会隐藏入口，已有普通剪辑与合并任务继续使用现有队列。

选项 → 模型管理提供下载、取消、继续下载、SHA-256 校验和删除。模型保存在用户数据目录 `AvaMedia/models/`，按模型分目录；下载写入独立暂存目录，校验完成后发布。分析持有模型使用锁，下载或使用期间不能删除同一模型。YuNet 为内置资源，只展示状态。

| 模型 | 用途 | 下载方式 |
| --- | --- | --- |
| YOLOX | 检测人物，自动剪辑必需 | 手动下载，约 34.2 MiB |
| JoyTag | 图片 / 视频多标签与关键词筛选 | 手动下载，约 349.2 MiB |
| EmbeddingGemma 2 Q8 | 可选本地语义辅助 | 手动下载，权重与投影约 824.6 MiB，另含匹配平台的 llama.cpp 工具 |
| LaMa | 图片修复 | 保留启动自动下载选项，可关闭后删除 |

Google 模型下载完成后不会自动启用。自动剪辑窗口中可勾选“使用 EmbeddingGemma 2 语义辅助”。未下载时此选项不可用，YOLOX 可独立完成分析。视频不上传到远程服务；语义辅助使用仅绑定 `127.0.0.1` 的临时本地进程，带随机访问密钥，结束或取消时关闭。

分析默认每秒采样 2 帧，以人体检测分数生成有人区间；对有人／无人变化边界进一步采样，细化至约 0.1 秒。默认前后各保留 0.5 秒、合并短间隔，并保留弱检测证据。可修改采样频率、阈值、前后余量、合并间隔、最短片段时长和不确定片段规则。语义辅助比较人物与空场景文本的嵌入相似度，辅助保留人体检测较弱的画面；相似度差值不是概率。

分析结果进入现有多片段编辑器，可以修改起止时间、删除和调整片段。输出可分别保存，或把每个源视频的保留片段合成一个文件。合并使用现有重新编码流程，最多 64 个片段；Fast Copy 只用于分别导出，边界受关键帧限制。没有可保留片段的源视频不生成任务；取消或分析失败不改动任务队列。

Beta 的采样可能漏掉极短出现的人物，小人物、遮挡、低光和画面中的人物海报也可能造成误判。已在一个约 23 秒的本地视频上实际运行人物检测，生成两个候选保留区间；不确定画面仍需人工确认，未执行裁剪导出或逐帧准确率校准。

## 关键词匹配重命名

开启 Beta 后，工具集 → 批量重命名显示“关键词匹配重命名 · Beta”。先在模型管理下载 EmbeddingGemma 2，再勾选此模式。输入关键词，以逗号、分号或换行分隔；可用 `海边=人在海边散步` 将短命名标签与较详细的匹配描述分开。最多 32 个关键词，命名标签须为有效文件名，最多 100 字符。

“匹配并预览”分析列表中的全部图片和视频；每张图片分析一帧，视频默认均匀采样 8 帧，相似画面可复用，独立画面每批最多 4 张。每个关键词的分数为采样画面与关键词描述的平均余弦相似度；选取最高分标签。达到最低相似度且领先第二个关键词达到指定分差时，自动勾选，否则显示“待确认”并保留原名。只有一个关键词时不应用关键词间分差。分数不是概率，默认阈值未经素材效果校准；短暂内容可能被采样遗漏，音频内容不参与此匹配。

默认模板为 `{keyword}_{index}`，保留扩展名；现有 `{name}`、`{parent}`、前后缀与文本替换仍可使用。序号按全部已勾选图片和视频的列表顺序排列。每行允许修改命名标签、手动勾选或排除；悬停查看全部关键词分数，修改后点击“预览新名称”。更改关键词或采样、匹配参数会清除旧匹配，需要重新分析。

分析支持停止并保留已完成候选结果，解码失败的文件不自动勾选。匹配过程中或匹配后源文件改变时，要求重新匹配。实际改名始终由“执行重命名”触发，复用原目录内改名、冲突检查、文件身份校验、回滚、撤销和队列路径更新。未开启 Beta 时语义入口与标签输入隐藏；普通重命名继续可用。模型由用户手动下载，分析在本地运行，不自动下载模型或上传素材。

## 图片 / 视频 AI 标签

开启 Beta 后，图片 → 图片 AI 标签，或工具集 → 媒体 AI 标签。图片与视频可混合添加；拖入主窗口时也可选择此工具。先在模型管理手动下载 JoyTag，不随启动下载，不自动启用。

JoyTag 固定支持 5813 个英文标签，包括人物外观、服装、场景和成人内容标签。图片按 4 张批处理，动图只分析首帧；视频默认均匀采样 8 帧，每批 4 帧，可复用相似画面。视频筛选使用各采样帧标签分数的平均值；它不是逐帧扫描，短暂出现的内容可能被遗漏。默认阈值 0.4，分数未经此素材库校准，需人工确认。

关键词用逗号或换行分隔，每个关键词独立匹配；组合标签用 `+` 表示同时满足，如 `黑长发=black_hair+long_hair`。支持黑发、长发、黑长发、眼镜等常用中文别名，其余可直接输入模型英文标签。未知标签会提示错误。所有达到阈值的匹配标签都参与文件名，不限制标签数量；关键词留空时使用全部达标模型标签。标签按分数排列，不因标签数量截取结果；名称过长时在预览中提示缩短名称。每行可手动调整标签与勾选。修改筛选条件后点击“筛选匹配”，再预览新名称。

分析只读素材，可导出标签 JSON。只有点击“执行重命名”才更新原目录文件名，使用现有冲突检查、源文件身份校验、回滚、撤销与队列路径更新。默认使用 CPU；GPU 可手动勾选，按平台尝试 Core ML / DirectML，编译或运行失败自动回退 CPU，每行显示实际后端。Core ML 可分派到 GPU、神经网络引擎和 CPU，不代表所有节点都在 GPU 上运行；首次编译较慢，需要磁盘空间保存缓存，后续分析复用缓存。本机 C# 路径已完成图片和视频的 Core ML 推理，但这批小样本没有稳定的整批提速收益。
