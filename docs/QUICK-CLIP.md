# 快速剪辑 · 1.0.1

布局参照用户补充的“快速剪辑 / Fast Copy”截图和已保存的原程序控件记录，图标为独立绘制的矢量。开发依据是截图中的结构和控件文字；原程序未实测的行为不作为已确认事实。以下是 AvaMedia 已实现的行为。

## 文件列表

- 默认输出格式 Fast Copy，另有 MP4、MKV。
- 每行展示缩略图、文件名、路径、时长、尺寸、编码、大小和剪辑区间。竖屏缩略图保持比例。
- 信息按钮展示 FFprobe 信息；文件夹按钮定位源文件；上下按钮改变顺序，首尾按钮禁用；减号移除单项。
- 点击缩略图或“选项”进入已有剪辑编辑器。确定写回这一行的草稿，取消丢弃本层改动。
- “分割”按 2–100 段等分当前剪辑区间，替换该行；每段保留独立选项并产生独立任务。
- 名称排序使用当前文化的忽略大小写比较。“清空列表”只清空本窗口草稿。文件夹导入当前目录的视频，不递归；文件选择与拖放忽略重复路径，非视频文件不加入。

## 格式与参数

Fast Copy 使用独立 FFmpeg 进程复制首个视频流和首个音轨，保留源文件扩展名与编码；默认不输出其他音轨、字幕或附件。MP4/MKV 使用已有转换引擎重新编码，默认 MPEG-4/AAC；外部构建及用户选择的编码器会影响兼容性。

流复制无法精确定位任意视频帧。输入定位会回到较早的可定位点，流复制保留这部分数据，因此实际起点/时长可能与填写的区间略有差异。这与 FFmpeg 的行为一致。[FFmpeg `-ss` 官方说明](https://ffmpeg.org/ffmpeg.html#Main-options)

需要精确剪辑或裁剪、调速、音量、淡入淡出等滤镜时，选择 MP4/MKV。编辑器接受滤镜后，如果当前为 Fast Copy，列表会自动切换为 MP4 并显示原因；手动再选 Fast Copy 时提交会校验并拒绝冲突参数。

每个文件的区间和裁剪区域独立保存。“输出配置”接受后对现有条目及后来导入的文件应用公共编码/尺寸/音频参数，同时保留已有条目的区间与裁剪/水印区域。顶层格式决定是否流复制；配置窗口将这一项显示为只读，并提示返回列表选择格式。

## 输出与提交

选择固定输出目录，或“输出至源文件目录”逐文件解析位置。“添加设置名称”生成 `文件名 [FastCopy].扩展名` 或对应 MP4/MKV 名称。目标与现有文件、源文件或队列目标重名时，自动追加 `(1)`、`(2)` 等名称。

外层“确定”只加入主窗口队列，主窗口“开始”才写出媒体；每个文件/片段的选项都克隆到独立任务。所有转换保持源文件原样。

## 验证

`tests/AvaMedia.QuickClipTests` 生成横屏/竖屏、双音轨、中文/空格/单引号路径的素材，实测 MP4/MOV/MKV/M4V 的流复制及 MKV 精确剪辑/裁剪。对流复制后的每个视频包比较 SHA-256，确认它来自源视频且没有重新编码；校验只保留首个音轨。

同时运行 Avalonia 控件操作：移动、取消配置、逐文件编辑、公共配置保留区间、自动选择编码、分割、排序、移除与清空。渲染浅色、深色及最小尺寸窗口并检查按钮没有溢出。报告与 PNG 位于 `artifacts/quick-clip-*/`。
