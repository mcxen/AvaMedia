# 快速剪辑

主窗口入口按以下顺序工作：**选择视频 → 直接编辑 → 选择导出选项 → 加入导出队列 → 主窗口开始执行**。选择一个或多个视频后直接打开编辑器，多选时按选择顺序逐个编辑。

## 编辑视频与多个片段

每个视频初始有一个片段。设置开始、结束时间，拖动时间轴或使用边界按钮；可播放所选区间、逐帧定位、设置速度和淡入淡出。

片段侧栏常驻显示缩略图、源时间范围、输出时长和已设置的画面编辑。单击片段立即回填参数并定位起点；点击每行播放按钮或双击片段，从起点预览到终点。中央播放按钮从当前片段内的播放头继续，超出区间时从片段起点开始；可暂停、继续和循环播放。

预览下方的片段轨按列表导出顺序显示，各段宽度考虑输出时长，并为短片段保留可点击的最小宽度。点击轨道切换片段并定位相应的源时间。侧栏“预览全部”从第一段顺序播放，末段结束后停止；手动定位、切换片段或修改参数会退出连续预览。预览不先生成临时导出文件，段与段切换需要重新开始解码，不能保证无缝衔接。

“新增片段”从播放头到视频结尾建立独立区间，插在当前片段之后并选中它。“复制片段”先保存当前片段，将副本插在当前片段之后并选中它。“在此分割”以当前播放头为切点，只替换当前片段。侧栏同时支持删除、上移和下移，至少保留一个片段；每个片段分别生成一个文件和队列任务。

“批量分割”支持等分段数、每段时长、指定时间点三种方式；先预览各段边界和输出时长，确定后以分割结果替换当前片段，其他片段保持原顺序。切点采用源视频时间，速度在分段后应用，各段继承裁剪、旋转及其他编辑参数。单次最多 100 段；固定时长保留最后不足一段的余数，指定切点须严格递增并位于当前区间内。取消分割保留原片段。

分割时间支持秒数、MM:SS、HH:MM:SS，小数秒使用小数点；切点可用逗号、中文逗号、分号或换行分隔。重复、逆序、边界/区间外切点、非整数段数或超过上限会显示原因并禁用确认。编辑器、片段摘要与分割预览统一显示总小时数，超过 24 小时不回绕，必要时保留六位小数秒。

各片段独立保存区间、速度、裁剪区域、旋转、镜像、音量、音频效果和字幕等编辑参数。切换片段及进入导出页前保存当前修改；无效的区间或裁剪会阻止切换和确认，并显示错误。

“画面裁剪”在源画面设置像素区域，可拖动、移动、缩放或填写坐标。视频裁剪要求偶数像素；不允许越界。输出时先裁剪、再缩放和旋转。裁剪页显示源画面供设置坐标，其他页预览完整源画面的旋转和镜像。区间播放使用当前片段的速度；裁剪、淡入淡出、音量和其他处理在输出时生效。起止缩略图可以点击定位，终点预览使用结束边界前的画面。

## 快捷键与撤销

- `Space`：播放 / 暂停当前片段。
- `I` / `O`：将播放头设为起点 / 终点。
- `S`：在播放头处分割。
- `Ctrl/Cmd+D`：复制片段。
- `Alt+↑` / `Alt+↓`：调整片段顺序。
- 侧栏内 `Enter` 播放当前片段，`Delete` 删除当前片段。
- `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` 重做。

片段参数及列表操作保存最多 40 步编辑历史，连续输入和拖动合并后保存。文本输入框和下拉框保留自己的键盘操作；无效输入不会写入片段。撤销 / 重做同时恢复片段参数、数量、顺序和选中项。侧栏缩略图只为当前实现的可见列表行加载，最多两个解码请求并行，列表行离开视图即取消请求并释放图像。

## 人脸方向与手动旋转

“方向 / 人脸识别”支持保持原方向、顺时针 90°、180°、逆时针 90°以及水平镜像，作用于当前片段。

“识别视频人脸方向”在本地采样源视频的多个画面，通过内置 YuNet / ONNX Runtime 判断建议的纠正角度。它分析整个源视频，不跟踪人物身份，也不自动裁剪人脸。先展示建议和证据，点击“应用建议方向”才写入当前片段。检测不到清晰人脸、有效帧不足或方向证据不一致时返回“无法确定”，保留手动设置；识别可以取消，关闭编辑器也会取消分析。

## 导出选项与队列

全部视频编辑完成后进入导出页，查看各片段的起始帧封面，再选择输出格式，以及固定保存目录或各视频所在文件夹。默认“原格式 / 原码率”（Fast Copy）：保留源容器和原始编码包，视频与音频不重新编码。“编码与质量”只提供公共输出设置，不修改各片段的编辑参数。

MP4 / MKV / TS 按选定区间精确剪辑并应用画面、音频效果。“原格式 / 原码率”不能同时进行裁剪、旋转、调速、淡入淡出等滤镜处理；冲突设置会在导出页显示错误并禁用提交，须明确选择重新编码格式。流复制的边界受关键帧及帧重排限制，实际起点或时长可能与填写区间存在偏差。剪辑后统计的平均码率可能变化，保留下来的编码包不变。[FFmpeg `-ss` 官方说明](https://ffmpeg.org/ffmpeg.html#Main-options)

AI 保留有人片段默认勾选“将每个视频的保留片段合并为一个文件”。检测时先连接满足合并间隔或前后余量相接的候选，直接裁剪得到的大片段。最终只有一个保留区间时直接导出，不生成拆分文件或执行合并；有多个不连续区间时，原格式合并先复制各保留区间，再按源编码连接，最多 64 段；每个任务只连接同一源视频。连接时保留编码包表示，并按实际视频包的显示终点对齐接缝，避免音频预滚和 B 帧造成接缝空隙或重复时间戳。取消勾选则分别导出。

“返回编辑”保留每个视频的全部片段草稿，同时保留已选的导出格式、编码参数和保存位置。“取消”丢弃本次编辑，不增加队列任务。“加入导出队列”校验完整批次后一次性创建等待任务；主窗口“开始”才写出媒体。

输出发生重名时生成独立新名字，不覆盖源文件、现有文件或其他队列输出。每个任务持有独立选项副本。
