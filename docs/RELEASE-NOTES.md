## v1.1.8

图片支持静态 HEIC / HEIF 输入，可拖入工具路由、压缩并前后对比、转换、缩放 / 旋转与合成 PDF。FFmpeg 按完整主图处理分块照片，单块派生图按实际裁剪与方向处理；压缩导出 JPEG / WebP / PNG，继续只保存实际变小的结果。高于 8 位的输入可导出 16 位 PNG，不能作为无损 8 位 WebP 保存。

macOS 照片信息和不填边预览接入系统 ImageIO，按主图与目标尺寸后台解码；压缩参数变化复用原图位图，路由中视频帧的位图解码也移至后台。实现与范围见 [HEIC](HEIC.md)。本次完成 Windows Release 编译与静态检查，尚未执行 HEIC 媒体输出或 macOS 性能实测。

包含同版本新增的 WiFi 局域网文件传输：手机浏览器扫码收发文件，已接收视频可进入压缩入口，窗口关闭停止服务并保留本机文件。见 [WiFi 传文件](WIFI-TRANSFER.md)。

自 v1.1.7 起累计有效代码变更 1202 行（发布版本号调整前），达到 1200 行的 tag 门槛；安装包由既有 Release 工作流生成。

## v1.1.7

天池播放器接入 Windows 开始菜单、独立桌面快捷方式和视频 / 音频“打开方式”；便携版可在选项系统页注册。安装器自动注册，卸载移除自身入口，默认应用通过系统设置选择。

播放器采用池化 BGRA 缓冲与整帧连续复制，隐藏 / 最小化时停止像素交付并继续音频，恢复保持原会话；时间控件节流、列表避免重复绑定、暂停帧后台解码。浅色 / 深色启动延迟加载经典皮肤，语言属性观察集合复用。

任务行的文件大小读取、队列保存及进程启动移至后台；旧队列保存不能覆盖新编辑，退出等待保存。媒体探测保留大章节 JSON，SHA256 工具采用流式缓冲、真实进度与取消。已完成本地 5.23 GB 视频、两小时音频、1080p60、5000 项队列检查；详细测量与限制见 [播放器性能](PLAYER-PERFORMANCE.md)。

## v1.1.6

拖入文件后新增工具路由：单文件大预览、多文件缩略图列表、类型勾选、混合批次的接收数量；可见工具默认虚线连接，悬停 / 聚焦渐变为实线，圆点匀速流动并带轻微拖尾，移开后淡回虚线。点击卡片直接进入对应编辑窗口。规则通过 `IMediaFileRouter` 与界面分离，预览后台按可见项加载，Light / Dark / Mac OS 9 共用布局及动效偏好，空闲时停止动画。

视频压缩补齐苹果 MOV / M4V / MP4、HEVC（含 10 位）及 ProRes 输入，新增 MOV / M4V 输出与 HEVC `hvc1` 标记。iPhone HLG / Dolby Vision 压缩为 SDR；界面明确显示色彩转换，macOS 配方增加 zimg。苹果源视频尚未实际编码验证。

移除屏幕录制入口、配置、队列执行、Windows / Mac 采集后端和相关图标；播放器截图和导出视频帧功能继续使用。

视频转换入口合并，新增批量视频压缩：自动高 / 中 / 低档、画质优先、体积优先、手动质量与码率，以及比例和目标大小。图片支持批量压缩与前后对比；下载工具内置 yt-dlp 与 QuickJS-NG。

macOS ARM64 应用补齐最低系统版本 13.4，并核对原生依赖部署版本；QuickJS 改为同版本源码构建，避免官方 Mac 运行器要求 macOS 26。修正英文系统下的界面测试查找，以及 FFmpeg 构建的 FreeType 下载超时问题。两个平台的发布验证并行运行，最终仍须全部通过才生成 Release。本地 Mac 交叉构建和归档检查不能替代原生运行；GPU 和声音以 Mac 实机结果为准。

## v1.1.3

整合本次工作区全部开发代码：中英文切换与应用名称统一、Mac OS 9 像素字体及独立图标、Platinum 控件与菜单布局、自动 GPU 编解码和软件回退、播放器截图，以及 macOS ARM64 FFmpeg 构建和发布工具链。设置窗口采用常规 / 转换 / 系统 / 工具四页，移除 BrightData 与重复重置入口；主窗口支持关闭到托盘并保留后台任务。

本次发布前本地执行源码编译和脚本 / 配置静态检查。安装包由 tag 触发的 Release 工作流生成，包含对应源码与第三方许可证。

独立实现的 Avalonia + C# 客户端，包含多片段编辑与导出、共享裁剪、本地方向识别、Light / Dark / Mac OS 9 三套皮肤，以及统一的编辑器组件和精确帧时间。

普通选项补齐源目录输出、设置名称、完成后打开目录与可取消的关机倒计时、操作/完成/错误提示音、系统菜单、托盘和正式版本检查。转换与剪辑、批量裁剪和旋转共用默认配置；完成后动作只针对本次任务。Windows 与 macOS 各自接入系统入口，Mac 原生运行仍需真机验收。设置说明见 [普通选项](GENERAL-OPTIONS.md)。

Windows 外部工具安装改用共享 DLL 构建，FFmpeg / FFprobe 运行文件约 153.71 MiB，相比原静态组合减少 41.7%；不再安装未使用的 ffplay，并清理临时下载与解压文件。编码器、解码器、滤镜、格式、协议与设备列表一致，完整 18 套客户端测试通过。

成品包括 Windows x64 安装程序与便携 ZIP，macOS Apple Silicon（ARM64）的应用 ZIP、PKG 和 DMG，对应源码及 SHA256 清单。后续 macOS 仅发布 ARM64。客户端包含 .NET 运行时；FFmpeg / FFprobe / yt-dlp 需通过附带脚本或设置独立配置。

原创代码采用 AGPL-3.0-only，安装包保留第三方许可证。macOS 应用采用 ad-hoc 签名，尚未进行 Developer ID 签名和公证。
