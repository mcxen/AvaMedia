# 字幕与轨道选择

维护日期：2026-10-05。本页记录 AvaMedia 已实现行为，原格式工厂字幕分页尚未现场核对。

输出配置的视频、音频页可指定各自类型内的轨道索引：0 为第一条，1 为第二条。转换、流复制、提取、混流、合并输入、编辑器声音与画面预览均使用所选轨道。保留全部音轨时输出全部轨道；预览仍显示所选单轨。FFmpeg 显式映射规则见[官方说明](https://ffmpeg.org/ffmpeg.html#Advanced-options)。

| 模式 | 行为 |
|---|---|
| 关闭 | 不输出独立字幕，也不烧录；旧预设只有外部文件路径时仍按烧录处理 |
| 烧录到画面 | 外部路径留空时读取源字幕；-1 选第一条，非负索引选指定条；需要重新编码视频 |
| 保留源字幕轨 | -1 保留全部，非负索引保留一条；MKV 复制字幕，MP4/MOV/M4V 转 mov_text，WebM 转 WebVTT |
| 附加外部字幕轨 | 使用外部文件中的字幕轨，替换输出的源字幕轨；可以与音视频流复制一起使用 |

烧录可指定已安装字体、字号、#RRGGBB 颜色、九种位置及垂直边距。字幕在源时间上渲染，再与画面一起变速，剪辑开始时间也计入字幕时钟。样式使用 FFmpeg/libass 的 [subtitles 与 force_style](https://ffmpeg.org/ffmpeg-filters.html#subtitles)。中文显示取决于所在系统或字幕提供的字体。

独立字幕轨目前只支持正常速度；变速时会提前拒绝并提示烧录，避免输出不同步字幕。多文件合并可在各输入选项中独立烧录；独立字幕轨拼接仍待实现。文本烧录不接受 PGS/DVD/DVB 位图字幕，位图轨可保留到 MKV。外部文件不存在、索引越界、无字幕来源及不支持的容器均在输出前报错。

专项测试为 `tests/AvaMedia.SubtitleTests`，生成含两条视频、两条声音、两条字幕的独立素材。32 项检查通过：包哈希、PCM 内容、字幕文本/语言/编码、软字幕剪辑时间、烧录像素/颜色/位置、剪辑变速同步、逐输入合并、预览选轨、预设、界面草稿隔离以及不适用参数提前拒绝。浅/深色渲染已查看。
