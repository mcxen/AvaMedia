# 媒体处理消融

采用固定源媒体和固定编码器，先执行完整配置，再每次仅关闭一个处理环节。通过 `MediaEngine.Execute` 生成媒体，使用 ffprobe、解码后的 RGB 和 PCM 测量结果；生产功能保持启用。

视频完整配置包含剪辑、裁剪、缩放、旋转、翻转、变速、淡入淡出、区域模糊和字幕烧录。音频完整配置包含剪辑、变速、音量、倒放、回声、降噪、淡入淡出、采样率转换与声道转换。共 18 组消融、20 个实际输出、35 项检查。
