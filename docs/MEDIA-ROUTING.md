# 文件路由

把视频、图片、音频、PDF 或其他文件拖进主窗口，即可选择处理工具。支持混合批次和继续拖入，同一路径自动去重；仅接收本地文件。

左侧使用紧凑来源列，单文件保留预览，多文件使用 64×48 缩略图列表。图片原生解码，必要时调用媒体引擎取得预览；视频读取实际媒体信息和实际画面。可逐项勾选，也可按类型快速勾选。可见项的预览最多并发两项，不等待所有文件读取就能进入工具；失败时使用图标和状态提示。

右侧为工具卡片：视频提供压缩、瘦身、剪辑、旋转、裁剪、转换、合并、音频 / 视频流提取、导出帧、多宫格截图、自动字幕、视频总结、人声增强、水印区域插值修复与重新封装；VOB 文件另有 DVD / VOB 转换。图片提供压缩、缩放 / 旋转、转换与 PDF；音频提供转换、剪辑、人声增强、语音转字幕、合并与混合。PDF 提供合并、拆分、做旧、压缩和文字提取；TXT 可转 PDF，ZIP 可解压。媒体可进入播放器或信息工具，所有文件可打包 ZIP。

设置中开启 Beta 功能后，视频可进入「保留有人片段 · Beta」，图片和视频可进入「媒体 AI 标签 · Beta」。Beta 开关和文件接收规则与工具箱直接拖入共用 `Accepts`。音频格式、图片格式分别合并到格式转换卡片，「图片 AI 标签」共用媒体 AI 入口；视频下载和光盘 → ISO 使用链接或设备入口，不参与本地文件路由。

混合批次中，卡片和底部显示实际接收数量及未进入该工具的数量。例如拖入三个视频与两张图片，视频压缩卡片接收三个视频并注明跳过两项；用户也可先快速勾选图片。自动字幕接收同一批次中的视频和音频，仅显示一张卡片。合并 / 混合至少两项，独立视频与音频混流须恰好一个视频加一个音频，交付给工具时始终视频在前、音频在后。图片压缩接收 JPEG、PNG、WebP、BMP、HEIC、HEIF，其他图片仍可选择格式转换；动画是否适合压缩由图片压缩窗口的实际探测判断。

工具按用途分组，按主要文件类型排序；默认窗口每行 4 个工具，最小窗口每行 3 个，放大后继续增加列数。卡片使用 24 DIP 图标和至少 72 DIP 高度，不通过缩小文字提高密度。同质批次删除重复接收数量；混合批次显示各工具实际接收 / 跳过的数量，文件不足时直接显示要求。顶部可搜索工具名、功能摘要或分组，Ctrl/Cmd+F 聚焦搜索，↓ 进入结果，方向键按网格导航，Home / End 到首尾，Escape 先清空搜索再取消。

关系按“来源行 → 公共连线 → 用途分组 → 当前工具”呈现，连线全部限制在独立通道内，不穿过工具卡片。悬停或聚焦时，实际匹配的来源行显示强调边框和“带入”，不匹配的已勾选文件显示“跳过”；底部显示例如“视频 × 3 → 视频压缩”，附功能摘要及跳过的文件类型。来源匹配按路径计算，不根据数量高亮列表前几项；左右独立滚动和工具筛选后同步更新可见端点。

选定分支保持实线；只有指针反馈期间运行流动点，键盘切换立即更新。Mac OS 9 或减少动效使用相同静态关系；空闲、关闭、隐藏或最小化时停止计时器。点击卡片直接进入现有编辑 / 配置窗口，匹配文件自动带入；没有搜索结果时禁用进入动作。

`IMediaFileRouter` / `MediaFileRouter` 负责扩展名分类、可用工具、匹配文件、数量要求与混流顺序。`MediaRouteWindow` 负责选择和预览；`MainWindow.RouteFilesAsync` 取得请求后调用现有 `Configure`，不另写一套导出逻辑。类型识别不是对内容有效性的保证，实际格式和编码能力仍由对应工具校验。

窗口拖放处理监听 `RoutingStrategies.Bubble`，并设置 `handledEventsToo: true`，接收拖入子控件的文件。[Avalonia 的 `DragOver` 与 `Drop` 事件仅注册了冒泡路由](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/src/Avalonia.Base/Input/DragDrop.cs)，不能用 `Tunnel` 监听；该约定也用于视频压缩与格式转换窗口的文件追加。
