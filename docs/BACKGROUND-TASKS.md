# 后台任务与托盘

主窗口默认启用“关闭窗口时缩小到托盘”。点击关闭按钮或 Alt+F4 隐藏主窗口并移除任务栏入口，转换、下载和录屏继续执行。托盘保存恢复入口，恢复沿用原窗口及最大化状态。独立播放器和编辑对话框沿用自己的关闭行为。

在“选项 → 系统”分别设置：

| 设置 | 默认 | 行为 |
| --- | --- | --- |
| 最小化到系统托盘 | 关闭 | 点击最小化时也隐藏窗口到托盘 |
| 关闭窗口时缩小到托盘 | 开启 | 点击主窗口关闭时转入后台，保留运行任务 |

任一选项开启时建立托盘；两项全部关闭时移除托盘，并恢复隐藏的主窗口。设置支持应用、取消和恢复默认值；没有可用托盘时保留正常的窗口关闭与最小化行为。

托盘菜单提供当前任务摘要、显示窗口、转入后台、开始等待任务、停止当前任务、打开输出文件夹、查看上次结果和退出。摘要与悬停提示显示运行数量、平均进度和等待数量，空闲时显示等待、完成和失败数量。开始 / 停止按钮跟随实际队列状态；查看结果包含本次成功、失败、停止 / 未执行数量及实际输出目录。

后台运行不会因完成提示自动恢复窗口。完成音效与打开目录继续按已应用的设置执行；结果保留在托盘中，用户主动查看时恢复窗口。前台仍可显示完成弹窗。已配置的完成后关机仍显示可取消倒计时，但存在等待或运行任务时不会触发。

“任务 → 退出”和托盘的“退出”执行真正退出：停止当前任务、等待媒体进程结束、保存队列、释放托盘，再结束应用。等待任务保持等待状态，已停止任务按停止状态保存。连续点击退出不会重复启动关闭流程；操作系统要求关闭应用时也不会转为托盘隐藏。截图启动入口不启用托盘驻留。

后台模式复用原来的队列与并发设置。解码器的进度回调合并为一次待处理 UI 更新；隐藏窗口每秒同步托盘与必要的持久化，不更新任务列表布局和耗时文本。恢复窗口立即同步当前任务状态，不重新启动任务。

`IBackgroundTaskTray` 定义任务状态与托盘动作，`AppOptionsServices.Background` 实现原生菜单，`MainWindow.Background` 管理窗口与队列的生命周期。使用 Avalonia 11.3.22 的原生 TrayIcon / NativeMenu，窗口关闭原因参考 [Avalonia WindowClosingEventArgs](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/src/Avalonia.Controls/WindowClosingEventArgs.cs)。Windows 的图标点击恢复窗口；macOS 通过菜单中的显示动作恢复。
