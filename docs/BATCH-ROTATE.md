# 视频批量旋转

支持根据人脸自动判断每个视频的纠正方向，也可统一旋转或逐个调整。支持无需旋转、顺时针 90°、逆时针 90°和 180°；手动统一模式默认顺时针 90°。

## 使用

1. 点击视频分类里的 **批量旋转**，或菜单 **批量 → 视频批量旋转…**。
2. 点击 **添加视频…** 多选视频，或把多个视频拖进窗口。
3. 点击 **自动检测方向**，或选择处理方式与旋转方向。左侧复选框决定哪些视频参与处理，点击行切换预览。右侧并排显示原画面与旋转后的效果；时间滑块可查看其他帧。
4. 选择输出格式、文件夹，点击 **批量加入队列**，再在主窗口点击 **开始**。

主窗口先选中多个已有任务再打开菜单入口，可以直接带入这些任务的源视频。批量旋转会创建新任务；已有任务的参数保持原样。

## 方向与输出

| 选择 | 处理 | 画面尺寸 | 输出名后缀 |
|---|---|---|---|
| 无需旋转 | 跳过，不生成输出任务 | 宽高保持 | 无 |
| 顺时针 90° | 向右旋转一个直角 | 宽高交换 | `_rotate90` |
| 逆时针 90° | 向左旋转一个直角，编码参数为 270° | 宽高交换 | `_rotate270` |
| 旋转 180° | 上下倒转 | 宽高保持 | `_rotate180` |

方向以**视频当前显示的画面**为基准。带旋转标记的手机视频先按标记显示，再应用所选方向。预览和转码遵循相同顺序。

**统一旋转**沿用整批共用一个方向的操作。**逐个调整**允许点击每个视频，再为当前视频指定独立方向，切换文件或拖动预览时间不会改动其他视频的设置。横屏与竖屏可以混合加入；每行显示各自的目标宽高。只需处理部分视频时取消其他行的勾选。**全选**勾选所有文件；**移除选中**删除当前列表选中的行。

## 自动检测方向

1. 添加并勾选视频，点击 **自动检测方向**。窗口切换到 **逐个调整**，在后台分别检测各视频。
2. 列表显示独立纠正角度、可靠度和有效帧数量。点击文件，对比原画面与旋转后预览。
3. **无需旋转**的文件会跳过；**无法确定**的文件须手动选择方向或取消勾选，然后才能加入队列。
4. 点击 **停止检测**会保留已完成的结果，未完成文件保持待检查状态。检测中也可以切换预览；关闭窗口会取消检测和抽帧。
5. 检测完成后新添加的文件保持“尚未检测”，不会自动继承其他视频的纠正角度。

自动判断基于视频**当前显示方向**，包括原有手机旋转元数据；只将剩余纠正角度应用到输出。默认跳过无需旋转的文件，避免重新编码。手动修改一个文件只覆盖该文件的检测结果。

检测使用随程序内嵌的 YuNet 模型与 ONNX Runtime CPU 推理，可离线运行，不上传视频、不建立身份库。FFmpeg / FFprobe 仍需按现有方式配置。

人脸朝向只是画面方向的线索。无人脸、脸太小、遮挡、人物躺卧、多人朝向冲突或视频中途转向时，可能无法判断或产生错误建议；请检查预览。功能面向整段保持固定方向的视频，当前不自动分段纠正。

## 检测实现

- 在时长的 5%～95% 之间均匀抽取最多 8 个不同时间点；短视频按帧率减少抽样数量。
- 首先分析 320×320 等比缩放并补黑的画面；有效证据不足或候选接近时，可用同一时间点的 640×640 画面补充证据。重复分辨率分析不会增加独立时间点数量。
- 每帧依次尝试四个直角旋转，解析人脸框和双眼、鼻尖、嘴角五个关键点，去除重叠人脸框。
- 综合检测分数、眼线水平程度、眼睛到嘴巴的朝下方向及有上限的面积权重；较弱的人脸检测被排除。每个时间点仅贡献一次方向投票，避免多人场景主导结果。
- 至少 3 帧有效，主方向至少占有效帧的 80%，且不能有 2 帧或更多明确的相反方向证据。候选分数过近时不投票。“高 / 中可靠度”表示规则下的证据一致性，不是经过校准的正确概率。

入口为 `VideoOrientationDetector` / `VideoOrientationPolicy`。`BatchRotateInput.Rotation` 可覆盖批次角度；0° 只参与整批验证，不创建任务。模型以资源内嵌到 `AvaMedia.Core.dll`，加载时检查 SHA256，适用于 Windows / macOS 发布布局。模型来源及许可见 `licenses/yunet/`。

输出支持 MP4、MKV、WebM、MOV、AVI，旋转通过重新编码写入画面。默认保留完整时长和首个音轨；没有音轨的视频正常输出。当前入口处理首个视频流及首个音频流，多音轨与高级编码设置可通过现有任务编辑调整。

源文件保持原样。输出名遇到已有文件、队列输出或其他源文件重名时追加序号。无效或损坏的视频会显示读取失败，并阻止整批确认；移除或取消勾选即可继续。每个视频作为独立任务执行，沿用进度、停止、重试和任务保存。

## 验证

```powershell
& .\.tools\dotnet\dotnet.exe run --project tests/AvaMedia.BatchRotateTests
```

专项测试生成 15 个实际输出，覆盖横/竖屏、有/无音轨、四方向真实人脸检测、手机旋转标记正确 / 错误两种情况、混合方向与无人脸、源文件哈希、重名防覆盖、损坏文件、勾选与移除、预览定位、逐视频修改与正向跳过、单文件检测失败、停止 / 关闭时取消、主窗口菜单与按钮、队列保存和开始按钮。最终像素与正向基准比较，预览截图像素也与预期旋转位置比较。

本机专项通过 212 项检查。发布包可使用现有截图入口复查模型加载与方向结果：`AvaMedia.Desktop.exe --capture <截图目录> --batch-rotate <视频路径> --detect-orientation`，生成 `batch-rotate.png` 与 `orientation-verification.json` 后退出。

浅色、深色、940×600 最小窗口、真实人脸自动摆正和手动检查的 PNG、媒体输出及 JSON 报告保存在 `artifacts/batch-rotate-*/`。专项测试已加入 `scripts/Verify.ps1` 的统一回归。真实人脸用例使用公共领域测试照片生成的视频，属于功能回归，不代表真实视频数据集的准确率。

预览使用 Avalonia [LayoutTransformControl](https://docs.avaloniaui.net/controls/layout/layouttransformcontrol) 与等比缩放；输出使用 FFmpeg [transpose](https://ffmpeg.org/ffmpeg-filters.html#transpose)、[hflip](https://ffmpeg.org/ffmpeg-filters.html#hflip) / [vflip](https://ffmpeg.org/ffmpeg-filters.html#vflip) 滤镜。具体控件行为已在当前锁定的 Avalonia 11.3.22 包中编译、渲染和验证。
