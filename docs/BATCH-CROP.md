# 视频批量裁剪

多个视频可共用一个画面选区，每个视频生成一个独立输出文件。

## 使用

1. 点击视频分类里的 **画面裁剪**，或菜单 **批量 → 视频批量裁剪…**。
2. 点击 **添加视频…**，在文件选择框里多选视频，也可以直接拖入多个视频。左侧复选框决定哪些视频参与处理；点击行切换预览，**移除选中**删除当前选中的行。
3. 在预览画面上按住鼠标拖出选区，或输入 X、Y、宽度、高度。时间滑块可查看其他帧，选区保持不变。
4. 选择应用方式，点击列表检查各视频的实际选区。
5. 选择输出格式、文件夹，点击 **批量加入队列**，再在主窗口点击 **开始**。

主窗口先选中多个已有任务，再打开菜单入口，可以直接带入这些任务的源视频。批量裁剪加入的是新任务。

## 两种应用方式

| 方式 | 含义 | 示例 |
|---|---|---|
| 同一像素区域（默认） | 所有视频采用同一组 X、Y、宽度、高度 | 参考视频 320×180，选区 `(32,20,128,100)`；640×360 视频仍裁剪 `(32,20,128,100)` |
| 按画面比例 | 依据参考视频宽高，将选区的左右、上下边界按比例映射到每个视频 | 上述选区应用于 640×360 视频时为 `(64,40,256,200)` |

选区坐标相对于页面上注明的**参考视频**。切换预览不会改变参考与选区；在另一视频上重新拖动选区，或点击 **重置为当前全画面**，才会更新参考。

比例模式独立映射横向和纵向比例，适合不同分辨率、横竖屏混合的视频；不同宽高比可能产生不同形状的选区和输出尺寸。需要相同输出尺寸时，可在 **输出配置…** 设置画面宽高。

## 校验与输出

- 所有参与处理的视频都必须成功读取。读取失败或选区越界会在对应行显示原因，并禁用确认按钮；调整选区、改用比例模式或取消勾选即可恢复。
- X、Y、宽度、高度使用偶数像素，宽高至少 2 像素。拖动和比例映射向下对齐到偶数边界；数值输入不合法时提示错误。极小选区在低分辨率视频上可能无法满足最小尺寸。
- 裁剪保留选区内的画面，使用重新编码；输出配置选择视频 `copy` 时会提示不兼容。音频默认保留，时长默认不变，其他输出配置会应用于每个视频。
- 输出支持 MP4、MKV、WebM、MOV、AVI。文件名追加 `_crop`，遇到已有文件、队列输出或其他源文件重名时追加序号。源文件保持原样。
- 显示的预览是源画面和选区框；输出时应用裁剪及其他已配置的滤镜。输出配置改变视频轨时，会重新读取对应画面并重置参考选区；仅切换音频轨保留选区。
- 每个视频独立排队，支持现有进度、停止、重试和任务保存。具体编码器是否可用取决于配置的 FFmpeg 和本机硬件。

## 开发验证

```powershell
& .\.tools\dotnet\dotnet.exe run --project tests/AvaMedia.BatchCropTests
```

专项测试生成自己的素材，验证横/竖屏、两种选区映射、真实鼠标拖动、预览定位、勾选、错误阻断、重名防覆盖、源文件哈希、多视频轨、主窗口菜单、提交队列和开始按钮。实际导出检查尺寸、时长、音轨，并解码颜色区域确认裁剪位置。浅色、深色及 940×640 最小窗口 PNG 和 JSON 报告保存在 `artifacts/batch-crop-*/`。

裁剪滤镜参数与色度采样对齐依据 [FFmpeg crop 官方文档](https://ffmpeg.org/ffmpeg-filters.html#crop)；界面实际坐标由当前视频元数据和预览容器的等比缩放映射，并通过实际输出验证。
