# 视频操作界面重构

2026-10-09。本轮按 `Catalog.All` 检查视频入口及其关联工具，修改实际窗口、任务创建与结果处理。保留当前皮肤与现有媒体引擎。

| 操作 | Before | After | Why |
| --- | --- | --- | --- |
| AI 标签 | 首屏参数多，结果不能直接修改 | 首屏添加文件并分析；标签可编辑、恢复、复制；分析其他文件时可编辑完成的标签；点击视频标签查看采样时间并回放 | 先看到结果，再处理不准确的标签 |
| 词库 | 重复选择，零候选也占用提示区域 | 延续已保存的词库选择；AI 标签默认使用全部标签；语义重命名可直接输入关键词 | 词库成为可选输入 |
| 人物剪辑 | 检测和导出连在队列里，无法确认保留范围 | 分析后显示保留区间，支持删除、播放与编辑，再导出；模型自动准备 | 在写出视频前确认范围 |
| 连续人物区间 | 候选碎片多，容易误以为会逐段写出再拼接 | 延续检测阶段连接区间；最终按确认区间裁剪，默认复制源音视频流 | 减少重复处理，保留原格式和码率 |
| 人物检测参数 | 模型与采样参数始终出现 | 首屏检测档位；其他参数集中到高级设置；排除区间名称明确 | 主要操作不依赖理解模型参数 |
| 自动字幕 | 识别后直接输出，没有校对步骤 | 识别页选文件和语言；校对页统一配置输出；按文件处理失败，文字和时间草稿随输入保存，切换保留，导出时统一检查 | 修正识别错误后再保存或烧录 |
| 字幕导出 | 重新执行任务会重新识别 | 保存校对结果和源文件信息；SRT、ASS、烧录视频共用校对结果 | 导出与校对保持一致 |
| 视频总结 | 输出、转录和模型参数混在首屏 | 默认摘要和内容总结；语言、关注点与供应商直接可选；识别设置和额外输出可展开 | 常用流程更短 |
| 关键词重命名 | 必须先到模型管理下载，相似度参数密集 | 开始匹配时自动准备模型；记住关键词和设置；参数及模型管理收进高级设置；调整候选和参数保留手工命名及勾选 | 减少前置步骤 |
| 人声增强 | 只能直接输出 | 默认中等强度；增加 10 秒原声与增强试听；视频继续使用原视频编码 | 在批量处理前比较效果 |
| 自动转正 | 待确认结果混在全部文件里 | 与剪辑中的方向工具使用相同名称；批量窗口可只查看待确认结果 | 快速找到需要人工选择的文件 |
| 格式转换 | 依赖编码配置窗口 | 增加保持尺寸、1080p MP4、720p、无损转封装选择；具体编码显示常用名称 | 从输出用途开始选择 |
| 视频压缩 | 一个无效文件阻止整批执行 | 界面显示可处理与跳过数量，提交仅包含可处理文件；记住压缩目标 | 有效文件可以继续 |
| 视频瘦身 | 不值得处理的文件阻止整批执行 | 跳过无效或预估无收益的文件，显示数量；未预估文件仍按现有执行流程自动分析 | 不要求手动清理整个列表 |
| 快速剪辑 | 多文件必须逐个经过编辑器，返回时重新走全部文件 | 批量工作区保留各文件的编辑结果，可直接继续编辑指定视频、取消勾选或移除 | 减少重复操作 |
| 画面裁剪 | 精确坐标与应用方式混在一起 | 应用方式始终可见，坐标可展开；保留拖拽选区与比例 | 优先使用画面操作 |
| 去除水印 | 容易在没有选区时提交 | 编辑动作改为框选水印区域；未设置区域的文件不能提交 | 避免生成没有变化的视频 |
| 视频合并 | 合并与混流在同一入口选择 | 视频合并使用独立名称；混流界面明确视频、音频来源，并分别选择文件 | 分清文件角色 |
| 提取音频／视频 | 轨道需要填写从零开始的索引 | 轨道选择显示序号、编码、语言和标题；音频入口改为提取音频 | 选择可读的媒体轨道 |
| 导出帧 | 间隔藏在输出配置中 | 主界面设置间隔，读取媒体后显示预计帧数 | 导出数量更容易判断 |
| 多宫格截图 | 尺寸、区间和零值含义占据首屏 | 宫格预设优先；尺寸、区间等收进更多选项；结束可留空表示视频结尾；记住布局设置 | 常用截图直接生成 |
| 视频下载 | 浏览器功能名称不明确 | 改为网页视频识别；保留粘贴链接自动解析和逐项错误状态；支持直接开始下载 | 操作名称对应目的 |
| 媒体信息 | 加入队列后导出 JSON | 直接显示大小、时长、画面、码率与轨道，JSON 作为导出动作 | 查看信息无需启动任务 |
| 播放器 | 设置按钮打开全部播放菜单 | 设置菜单集中速度、轨道、比例、VR、原生播放与色彩选项；轨道名称可读 | 减少菜单搜索 |

共同执行方式：新任务默认直接执行；勾选“仅加入队列”则等待手动启动。只启动本次新建的任务，编辑已有任务仍保存修改。支持的工具分别保存默认设置；源文件区间、裁剪选区、字幕校对内容不作为下一次新文件的默认值。

结果确认与导出检查源文件信息。停止人物分析或字幕识别保留已完成文件；失败的文件显示原因并可重试。

后续根据用户明确要求完成定向交互消融：对比同一基线、四项独立修改及组合版本，覆盖字幕草稿、逐文件识别、高级设置关闭、手工命名与标签编辑。结果和复现方法见 [视频操作消融](VIDEO-USABILITY-ABLATION.md)。受影响项目编译通过；未运行原生截图校验、模型推理、媒体输出或全量测试。
