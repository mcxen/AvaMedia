# 应用内通知

通知入口位于主界面底部 GPU 占用率右侧，显示记录数量，有未读时加粗。点击入口展开或收起右下角的应用内面板，列表中可选择记录，也可用上一条／下一条切换。标题与时间同行，管理按钮位于底部，只有多条记录时显示详情切换和序号。正文可选择和复制，长内容在最多 144 像素高的区域滚动显示；空正文、与标题完全重复的正文及无操作时的按钮区不占空间。进度条与百分比同行，操作按钮紧凑排列并自动换行。历史列表显示标题、时间和一行正文摘要，选择记录后可查看完整内容。通知始终位于应用窗口内，随窗口移动、最小化和隐藏；独立启动播放器时使用播放器内的同一面板。

列表和详情均支持移除单条通知，底部“清空”一键移除全部通知并关闭面板，包括正在更新进度的通知。移除最后一条记录也会关闭面板。移除记录后，同一操作的后续进度和结束状态不会重新出现；用户主动重新检查更新等显式操作可以重新打开通知。移除下载通知不会停止下载，停止下载仍使用相应操作按钮；关机通知的移除或清空会取消倒计时。

自动弹出的普通通知和下载进度在 8 秒后收起，错误与警告在 12 秒后收起，记录保留在通知中心。鼠标悬停、通知内有键盘焦点、操作按钮执行期间及窗口隐藏或最小化时暂停计时，恢复后重新计时。连续进度更新不会延长显示时间或重新弹出；完成或失败时再次提示。手动打开的列表和详情保持显示，关机倒计时保持显示直到结束或取消。新提示更新自动弹出的面板，不打断手动查看的记录。

关闭按钮关闭面板并保留记录，不再接着显示另一条通知，在列表中关闭也收起面板。主窗口的“显示 → 通知中心…”及播放器菜单中的“通知中心…”可重新打开列表。通知仅保留本次运行的最近 50 条记录；自动历史清理保留仍在处理的操作。新通知不抢占输入焦点，查看结果或任务时才按用户操作恢复相关窗口。

| 来源 | 内容 | 可配置操作 |
| --- | --- | --- |
| 视频总结完成 | 视频文件名 | 查看结果、打开目录、重新处理 |
| 队列结束 | 成功、失败、停止数量 | 查看任务、打开输出目录、重试失败任务 |
| 任务失败 | 文件名及实际错误 | 重试任务、查看任务；字幕和总结任务可打开模型管理 |
| 媒体 AI 标签 | 成功／失败数量或实际错误 | 查看结果、导出 JSON、重新分析、重试失败文件、模型管理 |
| 模型下载／管理 | 阶段、进度、大小或实际错误 | 停止下载、重试、模型管理 |
| 版本更新 | 检查结果、下载进度、准备结果或实际错误 | 下载／重试、停止下载、退出并安装、打开发布页 |
| 完成后关机 | 30 秒倒计时 | 取消关机；关闭当前通知也取消关机 |
| 通用消息 | 原标题及正文 | 关闭、移除、复制正文 |

同一次下载用同一标识更新通知，进度不会堆积成多条。关闭下载提示继续后台工作，之后的进度和结果更新原记录；移除则隐藏该操作的后续通知。按钮执行时禁用重复操作，错误留在通知中心。重试任务沿用原任务参数并生成新的输出路径，不覆盖已存在的输出。

完成通知由“选项 → 常规 → 显示完成通知”控制，隐藏或最小化时保留记录，不主动恢复主窗口。更新沿用启动检查、自动更新和静默更新设置；静默模式隐藏自动提示，手动检查显示结果。更新准备完成后提供“退出并安装”，队列运行或任务编辑时不可用。安装仍在整个应用正常退出时执行，缩到托盘不会安装，不自动重启应用。

`Notifications/NotificationCenter` 统一管理记录、关闭、移除和动作；`NotificationPanel` 直接嵌入应用窗口，使用当前皮肤的语义颜色和凸边。通知通过 `NotificationMessage` 配置标题、正文、类型、进度和多个 `NotificationAction`；关闭或移除时取消业务必须显式配置 `OnDismiss`。普通通知不创建独立窗口，参数表单和确认对话框继续承担输入与确认。
