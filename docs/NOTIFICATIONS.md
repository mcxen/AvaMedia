# 统一气泡通知

应用通知集中到屏幕右下角的复古对话气泡。引号入口显示未读数量；没有未读时显示记录数量。点击引号展开通知列表或收起气泡，列表中可选择记录，也可用上一条／下一条切换。气泡正文可选择和复制，长内容滚动显示，操作按钮自动换行。

关闭按钮关闭当前通知，保留记录；右键引号可隐藏全部气泡或清除已结束的通知。主窗口的“显示 → 通知中心…”及播放器菜单中的“通知中心…”可重新打开入口。通知仅保留本次运行的最近 50 条记录；仍在处理的操作不会被历史清理移除。新通知不抢占输入焦点，查看结果或任务时才按用户操作恢复相关窗口。

| 来源 | 内容 | 可配置操作 |
| --- | --- | --- |
| 视频总结完成 | 视频文件名 | 查看结果、打开目录、重新处理 |
| 队列结束 | 成功、失败、停止数量和输出目录 | 查看任务、打开输出目录、重试失败任务 |
| 任务失败 | 文件名及实际错误 | 重试任务、查看任务；字幕和总结任务可打开模型管理 |
| 媒体 AI 标签 | 成功／失败数量或实际错误 | 查看结果、导出 JSON、重新分析、重试失败文件、模型管理 |
| 模型下载／管理 | 阶段、进度、大小或实际错误 | 停止下载、重试、模型管理 |
| 版本更新 | 检查结果、下载进度、准备结果或实际错误 | 下载／重试、停止下载、退出并安装、打开发布页 |
| 完成后关机 | 30 秒倒计时 | 取消关机；关闭当前通知也取消关机 |
| 通用消息 | 原标题及正文 | 关闭、复制正文 |

同一次下载用同一标识更新通知，进度不会堆积成多条。关闭下载气泡继续后台工作，之后的进度和结果更新原记录；用户主动重新检查更新会重新打开通知。按钮执行时禁用重复操作，错误留在通知中心。重试任务沿用原任务参数并生成新的输出路径，不覆盖已存在的输出。

完成通知由“选项 → 常规 → 显示完成气泡通知”控制，前台和后台行为一致，不主动恢复主窗口。更新沿用启动检查、自动更新和静默更新设置；静默模式隐藏自动提示，手动检查显示结果。更新准备完成后提供“退出并安装”，队列运行或任务编辑时不可用。安装仍在整个应用正常退出时执行，缩到托盘不会安装，不自动重启应用。

`Notifications/NotificationCenter` 统一管理记录、关闭和动作；`NotificationBubbleWindow` 使用当前皮肤的语义颜色、凸边和引号尾巴。通知通过 `NotificationMessage` 配置标题、正文、类型、进度和多个 `NotificationAction`；关闭时取消业务必须显式配置 `OnDismiss`。普通通知不再创建模态消息窗口，参数表单和确认对话框继续承担输入与确认。

本次只进行桌面项目编译及必要静态检查，未运行原生气泡交互、模型下载或安装回归。
