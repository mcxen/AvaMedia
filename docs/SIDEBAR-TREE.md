# 侧栏工具树与精简决策

左侧由「分类竖轨 + 工具网格」改为单开手风琴工具树（实现：`MainWindow.Categories.cs`、`FeatureNavigation.cs`、`Controls/CategoryHeader.cs`），右侧只保留任务区。工具实现、`Catalog` 的 Id 与分类均未改动，路由、任务存储和 MCP 不受影响。

## 精简决策
| # | 决策 | 原因 | 功能影响 |
|---|---|---|---|
| 1 | 一级分类 6 → 5：「光驱设备\DVD\CD\ISO」并入工具集，作为「光盘」分组 | 光盘只有 2 个入口，却单独占一个一级位置 | 无；`Catalog.Categories` 不变，只在侧栏映射（`FeatureNavigation.TreeCategory`） |
| 2 | 音频 10 个、图片 8 个格式目标收为「转换为」标签组 | 18 行「→ MP3」类条目占用大量高度 | 无；每个标签仍打开原来的 `audio-*` / `image-*` 工具 |
| 3 | 同名「人声增强」在侧栏显示为「视频人声增强」/「音频人声增强」 | 两个工具不同（视频保留画面并输出 MP4，音频输出 WAV），不是重复工具 | 无；只改侧栏标签，沿用已有本地化条目 |
| 4 | 「保留有人片段 · Beta」去掉名称后缀，改用独立 BETA 角标 | 名称过长，状态信息与名称混在一起 | 无；仍由 Beta 开关控制显示 |
| 5 | 后台任务（整理分类结果、下载 AI 模型）不显示 | 内部任务，不是用户入口 | 无（原来也隐藏） |
| 6 | 二级分组不再可折叠，只保留一级手风琴 | 每组 2–5 项，两级折叠需要多点一次，也容易让人以为工具丢了 | 无 |
| 7 | 右侧不放工具入口；去掉「拖到侧栏工具」提示 | 任务区只管任务；拖放统一进入文件路由 | 拖到侧栏工具上直接添加的旧行为保留，只是不再提示 |

## 评估后保留（不合并）
- 图片「裁剪 / 缩放 / 旋转」与工具集「批量裁剪 / 批量旋转」：前者处理图片，后者处理视频（MP4），不是重复。
- 「视频压缩」与「视频瘦身」：一个按质量 / 体积预算，一个按画面分析，各自独立。
- 「格式转换」与「修复 / 重新封装」：一个重新编码，一个复制流。
- 「提取音频」「提取视频流」「视频 / 音频混流」：操作不同。
