2026-10-08 按 `Catalog.All` 的 53 个入口逐项核对窗口路由、布局、文案、控件状态、输出操作及英文资源。入口共用界面时检查共用实现，同时核对各工具的格式、顺序与参数差异。此次只做源码审查、Desktop / Core 编译和相关静态检查；未运行界面截图、功能回归或媒体输出验证。

## 统一规则

- 系统标题栏承担窗口标题；正文保留内容分组，不重复工具名称、操作流程或站点说明。
- 输出动作按内容确定宽度，以共享角色规定最小宽度、高度和间距；编辑器不再覆盖同一套按钮尺寸。
- 保存位置、浏览动作、取消与主要确认使用相同标签和角色；确认在右、取消在前，主要确认支持默认动作。
- 只有顺序影响结果的合并 / 混流 / 混音显示上移和下移；编辑、移除及执行根据真实输入和选中状态启用。重复导入同一路径去重。
- 不适用的字段隐藏；关闭字幕不显示来源和样式，烧录、保留、附加按当前模式显示对应字段。未显示的字段不读取新输入。
- 计数只在一处汇总；错误和运行状态就地保留。格式损失、原始文件变化、关键帧和字幕选择规则属于影响决策的信息。
- 行选择用于切换预览，处理勾选用于决定是否输出；这两种作用不同的窗口保留两种状态。没有预览切换需要的下载列表只用勾选。
- 中英文资源同步；文件名、路径和用户输入不翻译。浅色、深色及 Mac OS 9 使用相同语义资源和布局。

源码与编译证据不能代替实际窗口在不同缩放、语言、皮肤下的视觉验收。此次没有运行这些验收，也没有验证媒体转换输出。
