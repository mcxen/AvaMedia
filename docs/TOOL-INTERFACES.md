## 内部 VL 重命名工具

该桌面内部工具默认隐藏，普通设置不展示激活区域。“关于”中的隐藏手势可打开独立口令弹窗，验证成功后保存 `AppSettings.ExclusiveToolUnlocked`，视频侧栏才显示内部工具入口。公开文档不提供口令，网页公共工具目录保持不变。已解锁工作区的 MCP 可调用 `avamedia_preview_vl_rename`（本地 VL / 规则）、`avamedia_apply_rename`（执行已确认计划）和 `avamedia_undo_vl_rename`（按任务恢复）；未解锁时不注册内部接口。

`ExclusiveRenamerWindow` 支持拖入一个或多个文件夹、浏览选择文件夹、递归扫描图片与视频，以及勾选、移除和逐项编辑名称。分析方式包括共享模型管理中的本地 Qwen3.5 VL、已配置供应商的线上视觉模型，以及纯文件夹 / 文件名规则。首次使用本地模型可下载模型与推理工具；线上模式明确显示将发送名称资料和采样画面。图片读取一帧，视频按时长采样三帧；生成、扫描可以停止，关闭窗口取消分析，已完成的预览保留。

命名包含六个语义字段与原标识，共七段：`前缀_场景_视角_装扮_动作_评级_原标识.ext`。`VlMediaNaming` 归一化前缀和标签、剔除杂词、保留原扩展名与编号 / 人物标签 / 尾部数字或哈希；没有标识时使用稳定路径哈希。文件标签优先于文件夹标签，明确评级优先于画面质量判断，缺省评级为 SSR。VL 仅补充可确认的场景、视角、装扮和动作，未知字段使用对应“未知”标签。不会从画面推断人物身份或拍摄意图。

生成预览时为重名追加数字，保持七段格式与文件名长度限制。人工编辑保留原标识及扩展名，非法名称就地显示原因；全部勾选项就绪才可执行。提交前检查源文件是否变化及目标冲突，通过 `QueueService.ReserveFiles` 保留具体文件，再调用 `BatchRename` 的暂存、失败回滚和撤销记录。成功后同步主窗口中的文件路径；窗口内提供“撤销上次重命名”。本次验收范围为桌面项目编译，未执行 UI 或模型 / 媒体功能回归。

## 统一界面规则

- 转换、视频压缩、图片压缩、视频瘦身、PDF、下载、批量裁剪与旋转共用 `TaskSubmissionShell`：正文保留工具自己的列表、预览和参数，输出与底栏固定；右下角统一“取消 / 立即开始或仅加入队列 / 开始任务或加入队列”，编辑任务只显示“保存修改”。执行方式沿用共享队列的 `StartImmediately`，各窗口继续负责校验、任务创建和错误恢复。

- 系统标题栏承担工具名称，正文保留内容分组、参数、真实状态与影响输出的限制，不重复操作流程。
- 来源 / 列表、预览 / 结果、设置各自占明确区域；长正文滚动，输出和主要操作固定。最小窗口仍有可用内容空间，不能让固定列占完宽度。
- 字体、表面、辅助文字、边界、状态与动作尺寸复用动态资源及角色。浅 / 深色主按钮有独立状态色；Mac OS 9 / XP 保留各自默认按钮面。
- 保存位置、浏览、取消、确认使用同一角色；取消在前，安全的主要确认明确设默认键。编辑器、浏览器、多行输入和危险确认按各自上下文处理键盘。
- 合并、混流、混音、PDF 排页和片段顺序影响输出时保留排序；其他工具不显示无关排序。编辑、移除与执行依据实际选择和有效参数启用。
- 不适用字段隐藏；隐藏字段不读取新输入。字幕模式、图片格式、自动压缩档和当前输出类型决定实际字段。
- 行选择切换预览，复选框决定参与处理；两种用途分别呈现。只需勾选的下载和导出列表不叠加另一层选择含义。
- 动态状态、计数、速度和操作文字预留尺寸；进度不伪造，错误保留原因。文字 Tooltip 只补全实际省略的内容，额外路径与错误证据可以保留。
- 数值、下拉框、文本输入和派生滑条有字段名称；图标有动作名称，列表复选框有对应项目名称。中英文显示使用完整资源键，文件名、路径与用户输入不翻译。
- 源文件变化、格式损失、HDR 转 SDR、关键帧、字幕规则、动画首帧和模型域限制直接保留；重复说明、未命中结果和无意义空面板删除。

## 操作图标

全部工具共用 [ButtonIcons.axaml](../src/AvaMedia.Desktop/Styles/ButtonIcons.axaml) 的按钮内容模板：只有[完整动作映射](../src/AvaMedia.Desktop/Assets/ToolbarIcons/ActionButtonIcons.json)内的文字添加 Lucide SVG；始终保留文字，按钮的原始 Content、语言切换、无障碍名称及点击行为继续由原控件处理。映射不按关键词、前后缀或子串推断；没有明确图形的动作保留纯文字，含义冲突的英文译文也不匹配。用户文件名、路径、缩略图、工具入口卡片、已有图标按钮和自定义内容模板不重复添加图标。

添加、浏览、移除、删除、复制、粘贴、保存、导入 / 导出、撤销 / 重做、队列操作、播放 / 暂停 / 停止和预览使用对应图标。自动转正、体积预估、AI 分析、分类策略、格式、编码、质量、参数模式和确认范围保留必要文字；不能用齿轮、星星或装饰图形代替这些说明。动态按钮切换动作时由完整文案重新选择图标，固定状态宽度同时预留图标空间。

普通动作和浅 / 深主题的媒体操作图标共用本地 `LucideIcon`；Mac OS 9 与 Windows XP 的已有原生操作图标继续使用各自绘制。工具入口沿用已有功能图标及格式标签。

## 配置、执行与结果

工具配置使用独立非模态窗口，提交后由既有队列持有任务。`ToolExecution.Configure` 的“仅加入队列”决定暂存等待还是立即执行；编辑任务保留原任务语义。窗口返回确定请求，主窗口调用业务计划与校验，不创建第二份输出逻辑。

自动标签、自动媒体整理、人物检测、方向检测、自动字幕、视频总结、人声增强和 AI 去水印的任务状态、进度、停止、重试与持久化共用主队列。关闭配置或结果窗口不停止已提交任务；结果可从任务列表重新进入，运行及暂停中的部分结果明确标记。

| 流程 | 分析结果与后续操作 |
| --- | --- |
| 自动标签 | 展示命中标签与实际资料；应用内保存，未选择自动 TXT 时不自动写报告，可主动导出 |
| 自动媒体整理 | 分类筐、人工调整、文件计划；复制 / 移动留有记录与撤销，待分析项保持真实状态 |
| 人物与方向检测 | 片段或方向证据先保存，复核源文件与人工选择后再加入导出队列 |
| 自动字幕 | 后台识别，完成或部分结果可校对；再选择字幕文件或带字幕视频导出，重新识别创建任务 |
| 视频总结 | 配置与结果阅读分开；正文、字幕、画面描述、证据和章节按实际结果呈现 |
| 增强、去水印与导出 | 参数快照入队，实际输出由执行器处理；结束时的部分输出遵循有效收尾规则 |

每工具并发、模型锁、文件占用与暂停细节以 [异步任务架构](ASYNC-TASK-ARCHITECTURE.md) 为准。预览、设置和通知的生命周期不能代替任务控制。
