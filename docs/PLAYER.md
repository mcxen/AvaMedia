# 播放器

4K、HDR、原盘与原生播放引擎说明见 [高分辨率与原盘播放](PLAYER-NATIVE.md)。

VR 视频支持 180° / 360° 模式、双眼布局、拖动视角和空间旋转，操作与格式说明见 [天池播放器 VR 视频](PLAYER-VR.md)。

“天池播放器”（英文 Tianchi Player）打开独立播放窗口，功能入口、窗口标题和空白提示使用统一名称。启动参数 `AvaMedia.Desktop.exe --play "视频.mp4"` 或直接传入文件路径，也直接进入播放器；多文件按输入顺序连续播放。打开多个文件或拖入文件可替换播放列表。

主窗口任务列表右键“用天池播放器播放输出视频”打开任务的实际输出文件，支持转换、裁剪、旋转和下载得到的视频。多选时按任务列表顺序播放已完成且仍存在的输出视频，重复路径去重；未完成、失败、已移走或非视频输出不加入列表，没有可用视频时菜单禁用。点击时再次检查文件，播放不会修改任务参数或状态，也不重新导出。“编辑源文件 / 任务详情”保留源文件编辑和详情入口；“打开输出文件”使用系统默认程序。

首帧播放后，后台异步加载当前文件夹的全部视频，按文件名自然排序（第 2 集在第 10 集之前），不递归扫描子目录。单文件打开后选中当前文件；显式打开多个文件时保留输入顺序，再补入同目录视频并去重。扫描不探测每个文件、不重启当前解码器，也不改变播放位置或暂停状态。同目录切换复用列表，切换目录或关闭窗口取消旧扫描，迟到结果不会覆盖新列表。加载状态显示在播放列表底部。

布局参考 [PotPlayer 官方界面](https://potplayer.tv/)：顶部紧凑标题栏，中间等比画面，底部时间轴与单行控制栏。播放、停止、上一项、下一项和打开位于左侧，随后是当前位置 / 总时长；右侧为音量、速度、设置、播放列表和全屏。右键打开功能菜单，播放列表在画面右侧展开。全屏闲置两秒隐藏控制栏，移动指针或按键恢复；键盘焦点在控制栏内，或快捷键说明、播放列表、菜单展开时保持显示。

从主界面、任务输出、视频总结、媒体 AI、字幕校对和试听入口打开播放器时，统一使用独立顶层窗口，在入口所在屏幕的工作区居中并限制初始尺寸。播放窗口不绑定父窗口，避免 Avalonia 在 macOS 上将其设为全屏辅助窗口而无法进入独立全屏空间；该限制影响内置播放器，与 720p 源视频分辨率无关。实现依据 [Avalonia 11.3.22 的 macOS 父窗口处理](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/native/Avalonia.Native/src/OSX/WindowBaseImpl.mm#L457-L485)。本次只检查桌面项目编译及必要静态诊断，未运行实际全屏播放回归。

Light、Dark、Mac OS 9 使用相同布局和组件角色；Mac OS 9 使用现有 Platinum 标题栏与紧凑指标。菜单可选择真实音视频轨、播放速度和画面比例，也可查看媒体信息。紧凑窗口收起音量滑块，音量快捷键和静音仍可用。没有复用 PotPlayer 的图标、皮肤文件或代码。

Windows 新安装器建立“天池播放器”开始菜单入口，可选创建独立桌面快捷方式，并把视频与音频加入“打开方式”。便携版可在“选项 → 系统 → 注册天池播放器”执行同样注册；“选择默认播放器”打开系统设置，由用户选定默认应用。调用命令为 `AvaMedia.Desktop.exe --play "%1"`，路径完整引用；注册使用当前用户权限，卸载只移除自己的入口。此处的桌面接入指快捷方式及文件激活。

| 快捷键 | 操作 |
| --- | --- |
| Space | 播放 / 暂停 |
| Enter / Alt+Enter / F11；Esc | 切换全屏；依次关闭快捷键说明、播放列表、退出全屏 |
| ← / → | 后退 / 前进 5 秒 |
| Shift+← / →；Ctrl+← / →（Mac 可用 Cmd+← / →） | 跳转 30 秒；60 秒 |
| ↑ / ↓；M | 音量加减 5%；静音 |
| X / C；Z | 减速 / 加速 0.1×；正常速度与上次速度切换 |
| D / F | 暂停并定位前 / 后一个真实源帧 |
| Ctrl+E（Mac 可用 Cmd+E） | 截取当前帧为 PNG，保存到视频源文件目录 |
| Backspace / Home；F4 | 回到起点；停止并回到起点 |
| Page Up / Page Down | 上一 / 下一文件 |
| F3 / Ctrl+O（Mac 可用 Cmd+O） | 打开媒体文件 |
| F5；F6；F1 | 播放设置菜单；播放列表；快捷键说明 |
| Delete | 删除当前原始文件到系统回收站 / 废纸篓 |
| Tab / Shift+Tab | 向后 / 向前切换键盘焦点 |

以上是本客户端支持的常用 PotPlayer 式键位。打开窗口、点击画面或在列表中按 Enter 播放后，焦点回到播放画面。文本输入、下拉框和菜单保留自身按键；调整文本或数值、选择下拉选项时仍可用 Ctrl+E / Cmd+E 截图和 F11 全屏。按钮获得焦点时，Space / Enter 激活该按钮，Alt+Enter 仍切换全屏。Esc 关闭面板后回到画面；没有展开面板时退出全屏，窗口模式下回到画面。

原生 GPU / HDR 播放窗口也支持截图、播放、定位、音量、倍速、逐帧和文件切换键位，完整列表见 [原生播放](PLAYER-NATIVE.md)。

F6 展开播放列表并移入焦点；↑ / ↓、Home / End、Page Up / Down 选择文件，Enter 播放所选文件，Esc 收起列表。列表内的导航键、空格、字母及 Delete 不执行播放器命令，避免选择文件时跳转播放位置或删除正在播放的文件。时间轴获得焦点时，方向键移动 5 秒、Page Up / Down 移动 30 秒；音量滑块分别调整 5% 和 10%，Home / End 到滑块两端。

按住快进 / 快退、音量和加减速快捷键可连续调整；播放暂停、全屏、静音、逐帧、切换文件、截图和删除等每次按下只执行一次。逐帧请求会被新的定位、播放状态或文件切换取消，迟到结果不覆盖后续操作。双击画面切换全屏，普通画面的滚轮调节音量，VR 画面的滚轮缩放视角。

底部相机按钮、右键菜单“截取当前帧（保存到视频目录）”与 Ctrl+E 执行同一操作。播放中、暂停或逐帧定位后均可截取当前显示的画面，以 PNG 保存到当前视频所在目录，例如“视频名_截图_00-00-03.125.png”；重复截取同一时刻自动追加序号，不覆盖已有文件。普通模式截图保留播放器解码画面的尺寸和比例；VR 模式截图保存当前透视画面，不包含窗口、控件、提示文字或播放器补出的黑边。保存后显示文件名和目录；无法写入时显示实际错误，未加载视频、仅有音频或正在定位时禁用截图。

右键菜单“删除原始文件到回收站”与 Delete 执行同一操作。默认直接移入系统回收站；勾选“删除到回收站前确认”可恢复确认窗口，偏好会保存到客户端设置。确认窗口也可勾选“以后直接进回收站，不再确认”。操作先释放当前文件的解码占用，成功后移除列表项并播放下一项，删除末项时播放前一项；最后一个文件删除后回到空播放器。失败保留原列表并恢复原播放位置和状态，显示实际错误。

`IRecycleBin` 隔离系统文件操作：Windows 使用 Shell `IFileOperation` 的 `FOFX_RECYCLEONDELETE`，macOS 使用 Foundation `NSFileManager.trashItemAtURL`。没有永久删除菜单或永久删除的回退。接口参考：[Microsoft Shell 标志](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)、[Apple 废纸篓接口](https://developer.apple.com/documentation/foundation/filemanager/trashitem(at:resultingitemurl:))。

## 启动与播放

`IPlaybackSession` 分离播放窗口与解码实现；播放器和剪辑器共用 `Playback`。视频直接经 FFmpeg 管道输出 BGRA，音频直接输出 48 kHz 双声道 PCM；音频缓冲上限半秒，不创建整条音轨的 WAV 缓存。两条管道同时启动，首帧发布后启动媒体时钟；音频启动异常会显示原因并保留视频播放。

暂停保留解码进程、当前位置和音频缓冲，恢复播放不重新启动 FFmpeg。定位和换轨替换旧会话；连续拖动只交付最后请求，暂停可取消尚在进行的定位。音画使用同一播放时钟；倍速通过视频调度与 FFmpeg `atempo` 同步改变，保留声音音高。视频先结束时保留最后画面，到媒体或所选区间结束后停止。

帧缓冲通过 `ArrayPool` 复用；连续行跨度一次复制整帧，其他跨度按行复制。隐藏 / 最小化独立播放器停止后续像素交付，音频和时钟继续，恢复不重启解码器。时间文字与滑块最多 10 Hz 更新，暂停、定位和恢复控制栏立即显示当前位置；画面保持实际帧调度。播放列表仅在文件集合变化时重新绑定，目录自然排序预先缓存文件名；暂停定位直接使用解码器输出的帧，与播放画面采用相同的色彩转换，不经过 PNG 编码和读取。

默认浅色及深色启动不解析 Mac OS 9 样式；首次选经典皮肤时加载并缓存该样式，仍支持实时切换。语言属性观察集合按控件缓存，避免每帧更新反复创建枚举器。

Windows 发布启用 ReadyToRun，减少应用冷启动的即时编译；普通开发构建仍可直接运行。本地测量入口：

```powershell
./scripts/Measure-PlayerStartup.ps1 -Application artifacts/release/1.1.0/win-x64/AvaMedia.Desktop.exe -Media '视频.mp4' -Runs 5 -Skin Dark
```

每次启动独立应用进程，记录从进程创建到窗口打开、到首帧发布的延迟，输出各次结果、中位数和 P95；默认不生成截图。保留操作系统文件缓存，不把这组测量描述为重启系统或清空磁盘缓存后的结果。媒体编码、磁盘、CPU 与音频设备会影响数值。大文件准备、可复现命令与 2026-10-06 的前后数据见 [性能记录](acceptance/PLAYER-PERFORMANCE.md)。

`tests/AvaMedia.PlayerTests` 检查真实解码 PCM、首帧源时间、缓冲上限、暂停复用、倍速边界、长音频启动、定位取消、连续播放、键盘操作和三套皮肤的默认 / 最小布局；音频专项使用可读取实际 PCM 的测试输出设备。Windows 原生窗口与实际 WaveOut 通过启动测量另外检查。已加入 `scripts/Verify.ps1`。

实现参考：[FFmpeg 命令文档](https://ffmpeg.org/ffmpeg.html)、[音频速度滤镜](https://ffmpeg.org/ffmpeg-filters.html#atempo)、[NAudio 2.2.1 缓冲实现](https://github.com/naudio/NAudio/blob/v2.2.1/NAudio.Core/Wave/WaveProviders/BufferedWaveProvider.cs)。客户端维持 AGPL-3.0-only，外部 FFmpeg 和 NAudio 沿用现有许可处理。
