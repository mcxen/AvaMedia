# 天池播放器 VR 视频

打开视频后，点击底部 **VR**，或按 **V** 展开右侧原生设置面板。也可从右键菜单 **VR 视频** 直接选择模式。设置面板与播放列表共用右侧空间，全屏也可使用；Esc 收起面板。

## 视频格式

| 设置 | 内容 |
| --- | --- |
| 普通视频 | 原有平面画面，可保持比例或拉伸 |
| 180° 半球 | 正面半球，等距柱状投影或 180° 圆形等距鱼眼 |
| 360° 全景 | 完整球面，等距柱状投影；水平方向可连续旋转 |
| 单眼画面 | 使用整帧 |
| 左右双眼（SBS） | 从左、右半幅选择一个眼别观看 |
| 上下双眼（TB） | 从上、下半幅选择一个眼别观看 |

视频模式由用户明确选择，不凭文件宽高自动推断。双眼视频在桌面上显示选定眼别的透视画面；左右压缩和上下压缩的等距柱状画面均按对应半幅的归一化坐标恢复。鱼眼模式使用所选眼别中心、以较短边为直径的圆形 180° 等距镜头；特定相机的镜头标定、双鱼眼 360° 拼接与头显输出不在此实现范围内。

## 视角操作

- 左键拖动画面：水平旋转与俯仰。捕获指针，拖出画面仍可继续，松开或窗口失去焦点后结束。
- Shift + 拖动：翻滚，调整水平线。
- 滚轮：缩放，垂直视野角度限定为 30°–120°。普通画面的滚轮仍调整音量。
- Alt + 方向键：按 5° 步进旋转，可连续按住。
- **R / 回正视角**：水平旋转、俯仰、翻滚归零，视野恢复 90°；保持当前模式、布局和眼别。
- 双击：保留切换全屏操作。

180° 水平旋转限定为 ±90°，缺少源画面的半球区域显示黑色。俯仰限制为 ±89.9°；360° 水平旋转和翻滚按一圈回绕。面板同步显示角度，关闭面板仍可拖动。暂停、逐帧、定位及最后一帧均可调整视角，调整不会改变播放位置、音频时钟或启动新的解码进程。

VR 解码画面的边界提升到至少 4096 × 2160，避免沿用普通画面的低分辨率后再放大全景局部。第一次从较低分辨率切入 VR 时在当前位置刷新解码会话，保持播放或暂停状态；之后的视角、布局、投影和缩放调整只更新显示。

**记住此视频设置** 将当前模式、投影、布局、眼别、方向和视野保存到用户数据目录 `AvaMedia/player-views.json`，重新打开同一路径时恢复。没有保存的修改在当前播放器窗口的文件切换中保留；其他视频使用各自设置，默认普通视频。最多保留 512 条已保存设置。已记住的 VR 视频使用内置投影画面，避免被高分辨率原生播放偏好直接转交到外部平面播放器。

## 截图与实现

相机按钮或 Ctrl+E / Cmd+E 保存当前透视画面，包含视角、缩放和选定眼别，不包含播放器控件。尺寸按当前画面区域与屏幕缩放计算，限制在 3840 × 2160 内；沿用原有输出目录、命名、冲突避让与保存提示。

画面通过 [Avalonia 的 Skia 自定义绘制接口](https://docs.avaloniaui.net/docs/graphics-animation/custom-rendering) 与固定 SkiaSharp 2.88.9 的运行时着色器显示。按像素生成透视射线，应用翻滚、俯仰和水平旋转，再映射到源纹理；双眼边缘采样限制在所选半幅内。每帧冻结源像素，绘制操作持有独立着色器，避免解码更新或关闭窗口后读取已释放帧。视角调整复用最后一帧，Skia 软件后端也可投影。

着色器或纹理显示失败时记录异常、提示原因并回到普通画面。当前验证范围是 Desktop/Core 编译、XAML 和翻译静态检查、固定 SkiaSharp 的着色器语法编译；没有运行媒体回归、截图或性能测试。
