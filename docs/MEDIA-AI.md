# AI 标签工作台

从主页「AI 标签 → AI 标签工作台」打开独立窗口。也可直接启动工具：

```sh
AvaMedia.Desktop --ai-tags /path/to/video.mp4
```

macOS 已安装应用可用 `open -na "天池万象转换" --args --ai-tags /path/to/video.mp4`。不需要启用 Beta，也不需要先选择词库。

1. 添加图片、视频或文件夹，或直接拖入文件。导入后默认全部勾选。
2. 点击「开始分析」。首次使用会先下载必需的 JoyTag 标签模型再识别，支持停止及重试；底部提示分别显示标签模型与（勾选场景识别时）语义模型的下载大小。语义模型只在确认后下载，拒绝时本次只做标签识别并提示已跳过场景识别。
3. 左侧选择文件。右侧顶部显示采样画面；封面右侧集中放置图表来源、分数模式、标签类别、两种阈值、搜索与排序，以及视频采样时间和播放操作。只有命中时显示 NSFW「提示 / 疑似 NSFW」徽标，点击查看依据。下方「分数与曲线」默认展开，标签按类别分组并显示数量；没有结果的图表和标签区域自动隐藏。
4. 点击「生成同目录 TXT」，为勾选且已完成分析的文件保存报告；高级设置可开启分析完成后自动生成。

## 图表与阈值

每批推理完成后更新分数和曲线，只展示达标标签。封面右侧直接调整标签阈值；有语义结果或启用场景识别时，同时显示语义相似度阈值。拖动滑杆或图表中的阈值线直接重新筛选结果，无需重跑模型；即使没有达标结果，顶部参数仍可调整。图表获得焦点后，上下方向键微调阈值，曲线左右方向键切换采样时间。

柱状图以排名列表显示前 8 个达标标签：标签和原始分数在同一行，下方显示细条，长标签用省略号，悬停时在图下显示完整标签、峰值及平均分。各行的刻线与贯穿的虚线表示阈值，顶部标出数值，可直接拖动；面板按标签数量收缩。其余标签仍在下方分组中显示和搜索。布局参考 [ScottPlot 横向柱图](https://scottplot.net/cookbook/5/Bar/)的标签定位与简化网格，以及 [ECharts 标签布局](https://echarts.apache.org/handbook/en/how-to/label/rich-text/)的独立文字区域，使用现有 Avalonia 绘图实现，无新增图表依赖。

视频峰值图同时显示各模型的曲线，每个模型默认显示分数最高的三个达标标签。点击柱或标签可手动选择每个模型最多三个标签进行对比，保留其他模型的曲线；调整阈值后，原选择全部失效时自动选取仍然达标的标签。曲线保留这些标签各采样点的原始分数并圈出峰值，悬停时在图外的图例中查看采样时间和分数，点击定位缩略图，再点击「播放此时间」回放原视频。图片显示标签排名，不占用视频曲线区域。

封面右侧的图表来源切换 JoyTag 标签分数或 EmbeddingGemma 语义相似度，峰值图保持多模型对比。JoyTag 使用主题强调色与左轴 0–1；EmbeddingGemma 使用成功色与右轴 -1–1，保留原始余弦相似度。配色按模型固定，排序变化不换色；同一模型的标签分别用实线、虚线、点线，图例放在曲线下方。阈值数值显示在滑杆旁和阈值线的标签上；时间刻度显示整秒，并按实际文字宽度留出间距，采样读数仍保留精确时间。两条阈值线跟随各自的模型颜色，拖动时只调整对应模型；上下方向键调整最近拖动或选择的模型。需要类别比较的语义标签同时满足高级设置中的类别分差才显示。分数未经概率校准。

推荐分数对 NSFW、场景等短暂内容使用采样峰值，其余标签使用采样平均。也可切换到采样峰值、采样平均或当前画面。「全部标签 / NSFW / 场景 / 人物特征」与搜索框过滤图表和显示内容，搜索也支持原始英文标签。分组内可按分数或名称排序；悬停标签可查看模型与分数类型。相同原始标签组合只显示一项，优先使用所选词库的名称；界面、复制、TXT、JSON 与重命名共用去重规则。TXT、JSON 与重命名使用完整的达标标签。

视频默认采样 8 帧，高级设置可调整到 1–32 帧。曲线连接真实采样分数，复用的画面沿用已有分数；曲线不代表逐帧连续检测。分析停止后保留已完成文件和当前文件的部分图表，部分结果不能生成报告或重命名。

## 口交与面部可见性

JoyTag 的 `oral` 显示为「口交」，`cunnilingus`、`fellatio` 分别显示为「舔阴」「口交（男）」，`deepthroat` 显示为「深喉」。这些是模型已有输出的中文名称，使用 NSFW 采样峰值，调整阈值即可筛选。

可选的「识别场景、照明与面部」（新安装默认关闭，已保存的偏好保持不变）使用 EmbeddingGemma 比较「露脸、挡脸、未露脸、面部不明」的图像描述，在面部类别中筛选最佳候选，沿用相似度与类别分差阈值。面部不明作为对照，不显示为肯定结果；露脸使用正向描述，不由未露脸的低分反推。JoyTag 的 `covering_face`、`faceless` 也分别显示为「挡脸」「未露脸」。面部标签归入人物特征筛选，保留每个模型的采样曲线，参与 TXT 和文件名生成。

这属于标签与语义匹配，不进行身份识别，也不保证面部完全可辨或识别准确。少量采样可能漏过短暂动作、遮挡与露脸画面。v1.1.51 已用实际视频验证评分、排序、阈值筛选和导出；该视频的面部候选没有达到默认类别分差，面部识别准确率尚未通过验收。

## 同目录 TXT

文件名以达标标签开头，后面保留原视频名和来源标识，例如：

```text
眼镜_长发_卧室__20251208-1__来源标识.ai-tags.txt
```

文件名按 UTF-8 字节长度限制，优先保留完整标签；TXT 正文包含全部标签、类别、分数类型、阈值、模型和达标采样时间。未命中标签也会生成明确的空结果报告。

同一来源重新生成时替换本工具此前生成的报告；标签变化后更新文件名。用户自己的 TXT 不会被覆盖。工具内重命名视频后，再生成报告时同步更新来源名称。分析与 TXT 生成均不修改源视频内容。

## 标签编辑与重命名

可以编辑标签，或恢复识别标签（需确认，会丢弃手动编辑）。「从列表移除」移除勾选文件前也会确认，并清除这些文件的分析结果与手动编辑，不删除源文件。左侧文件列表下方「批量操作」提供生成 TXT、导出分析结果、标签重命名和撤销重命名；导出只包含勾选且已分析的文件。重命名预览默认把最高分的三个有效标签追加到原文件名，也可改模板和每行标签，确认后才实际修改源文件名。

高级设置保存视频采样、GPU、相似画面复用、子文件夹导入、分数显示和自动 TXT 偏好；模型管理也在这里。标签组选择自动保存。

点击主工具栏「标签组…」，选择词库与类别后勾选标签，或点击「全选当前列表」，再点击「应用选择」。切换词库、类别仅切换浏览列表；底部的已选数量表示实际参与识别的候选。

所选标签会补充到识别候选，不必开启「仅显示所选词库」。有 JoyTag 映射的名称与组合标签使用已保存分数，选择后立即重新筛选；纯语义描述进入 EmbeddingGemma，在下次分析时计算分数，即使关闭内置场景识别也会识别所选语义候选。已有结果缺少新候选时会提示重新分析。达标标签参与图表、TXT、JSON 与重命名；选择标签不会强制把它标为已识别。

JoyTag 通用与画面标签内置 4179 个中文名称，保留原始模型标签用于搜索和原始分数记录；角色、画师、作品专名沿用原名。图表、标签组列表、识别结果、复制、TXT、JSON 的达标标签与重命名共用中文映射。选择完整词库或以原始英文标签命名的单标签候选也使用中文显示；用户自己起的描述名称保持原名。

「户外风景」包含 117 个候选，覆盖自然景观、山脉、原野、花田、竹林、水域、云天、天气、季节、植物和建筑。「NSFW 识别标签」包含 324 个中文候选；本次补充校正 231 个细分名称。新名称使用已有 JoyTag 分数，无需重新下载模型或重新分析。新增成人细节只扩展标签和筛选范围，NSFW 徽标仍使用现有 93 条风险/提示规则与独立分类模型。

成人标签使用简短口语名称，例如「露点、露鸟、大胸、手交、乳交、足交、内射（阴道）、颜射、震动棒、跳蛋、口枷」。图表、标签组、复制和导出沿用同一名称；器官与动作仍区分，衣服下凸点不称为露点，看到精液也不反推射精动作。

「仅显示所选词库」限制两个模型的结果与图表范围。场景、照明、面部与内容分级的多个候选互相比较，使用类别分差；物体、特征与自定义语义标签按各自相似度筛选，可同时命中多个标签。

v1.1.51 已完成相关编译、词库及语言资源静态检查，并按用户要求重新完成本地原生界面、双模型推理、曲线定位播放及同目录 TXT 验收。1.23 GB、约 1 小时 52 分钟的视频以默认 8 帧完成分析，界面耗时 3 分 12 秒，输出 19 个标签；此记录不作为准确率或独立性能基准。详情见 [AI 标签工作台验收](AI-TAG-WORKSPACE-ACCEPTANCE.md)。


## 后台任务队列

工作台可把勾选文件「加入任务队列」，进入与转换、视频总结相同的主窗口任务列表与 `QueueService` 并发队列。每个文件对应一条 `media-ai` 任务，由后台执行 `MediaTagService`（含已开启的画面描述），进度与 `AiActivity` 显示在任务行；完成后写入同目录 `.ai-tags.txt`（或 JSON）侧车，可从任务菜单「打开 AI 标签报告」或「查看结果」打开。队列状态仍持久化到 `queue.json`。工作台内「开始分析」仍可在前台即时运行；独立 `--ai-tags` 启动时无主窗口，不显示加入队列按钮。

## 画面描述

高级设置可开启「生成画面描述」。JoyTag 标签分析完成后，会用设置中的 AI 供应商（推荐本机 Ollama 视觉模型）对采样画面生成自由文本描述，成人/NSFW 内容允许如实描写。描述写入同目录 `.ai-tags.txt` 的「画面描述」区段，并包含在「导出标签 JSON」中；不修改源文件 EXIF 或媒体内容。需先在设置 → AI 供应商中配置可用的视觉模型（例如 Ollama `http://localhost:11434/v1` + `moondream` / `llava`）。

线上配置提供「小红书 Dots」预设，新用户默认显示该预设。点击「注册 / 获取密钥」进入 [Dots API Keys](https://dots.ai/platform/apikeys)，登录或注册后创建自己的 API Key，再粘贴到设置中并点击「连接并获取模型」，应用设置后即可使用。预设已填入 `https://note3-prev-api.askdiandian.com/v1` 与文本、视觉模型 `dots3-note-prev`，使用官方 `api-key` 请求头和提示词约束输出。已有供应商配置保持原样。2026-10-09 [官方文档](https://dots.ai/platform/docs#model-pricing)标明当前免费体验、暂不收费，恢复收费前会提前公告；免费安排以官方最新公告为准。

视频描述发送全部采样画面（默认 8 帧，最多 32 帧），按时间顺序附上实际采样时间和视频总时长。标签分数可复用相似画面的推理结果，描述仍使用每个采样点的原始画面。提示词要求只写有直接画面证据的事实，省略无法确认的人物身份、场所用途、模糊文字和未采样动作；不同帧人数不相加。图片沿用单图描述。提高采样数量会增加请求体积和供应商处理时间，模型也仍可能误读细节；这些约束的准确性提升尚未进行同素材对比验证。

本次按仓库约定检查 Core / Desktop 编译和语言资源语法，未执行原生界面、模型推理、媒体输出或性能回归。

## 真人素材

高级设置默认开启「真人素材」。本地 JoyTag 识别细分标签，Marqo NSFW 独立执行普通／NSFW 二分类；两者使用同一组实际采样画面。首次分析自动下载缺少的模型，支持停止与重试。Marqo ONNX 文件为 22,450,955 字节，固定版本与 SHA256，通过模型管理下载、校验和删除。

「真人 · 姿态与成人标签」包含 688 个中文候选，覆盖人物特征、服饰、朝向、普通姿态、成人动作、体位及户外场景。真人模式显示这些候选及补充细节支持的 JoyTag 标签，过滤角色、作品等输出；仍保留每帧完整的 5813 项原始分数用于 JSON 和曲线。用户明确选择的其他标签组可以补充结果。姿态、成人标签与场景使用采样峰值，避免短暂内容被视频平均分稀释。「姿态 / 体位」筛选可查看对应标签及采样曲线。

NSFW 徽标仅在命中提示或风险时显示；Marqo 分类命中时可展开查看采样平均、峰值、分类阈值、推理后端及达标采样时间的分数。Marqo 分类阈值固定为 0.50，与 JoyTag 标签合格线独立；分类达到阈值或风险标签命中时显示「疑似 NSFW」。TXT 与 JSON 均保存独立分类结果，任务队列使用同样的生产推理和报告路径。关闭「真人素材」后显示完整 JoyTag 的达标标签，本次分析不加载 Marqo。

Marqo 分类与 JoyTag 细分标签属于不同任务。二分类命中不能证明具体体位准确；本次姿态识别使用 JoyTag 图像标签，不输出人体骨架坐标。八帧采样可能遗漏短暂事件，标签分数未经本地概率校准。

模型来源：[Marqo 原模型](https://huggingface.co/Marqo/nsfw-image-detection-384)、[ICIJ ONNX 转换](https://huggingface.co/ICIJ/nsfw-image-detection-384-onnx)，Apache-2.0。中文映射优先使用 AvaMedia 维护的名称，通用标签补充自 [Physton 中文标签表](https://github.com/Physton/sd-webui-prompt-all-in-one-assets)，MIT；固定修订、处理方式和许可证见 `licenses/chinese-tags/`。NSFW 与户外名称使用逐项校正的中文映射。
