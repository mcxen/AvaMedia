# 媒体 AI 标签

在选项中启用 Beta 后打开媒体 AI 标签。

1. 添加图片、视频或文件夹，也可将文件拖入窗口。导入的文件默认全部勾选。
2. 点击“开始分析”。首次使用时主按钮显示“下载模型并分析”，下载、校验和识别连续执行；可停止，失败后可重试。
3. 在左侧选择文件，右侧查看缩略图和按类别排列的标签。搜索框查找当前文件的标签，“复制标签”复制当前显示内容，“导出分析结果”保存所有已分析文件的 JSON。

默认不要求选择词库或填写关键词。分数、后端、采样数量和风险证据在“识别详情”中；标签分数未经校准，不表示概率。视频标签来自有限采样。

## 标签重命名

分析后点击“标签重命名”，进入独立预览窗口。只列出主窗口勾选且已有分析结果的文件，未分析文件会显示跳过数量。

默认将最高分的三个有效标签追加到原文件名。可选择“标签 + 序号”、调整标签数量，或直接编辑每行命名标签；自定义模板支持原名、标签和序号。取消勾选可排除某一行。新文件名随修改更新，过长、冲突和无效名称在对应行显示，存在错误时无法确认。

点击“确认重命名”后才修改源文件名，执行前重新检查源文件与预览。主窗口可以撤销上次成功的重命名，队列中的源文件路径随实际修改同步更新。

## 高级设置

高级设置集中提供标签阈值、视频采样帧数、GPU 选择、相似画面复用、子文件夹导入、分数显示和模型管理。

词库选择会自动保存。“仅显示所选词库”按候选的组合标签筛选结果；不影响模型推理或 JSON 中保存的原始标签分数。查找标签只过滤当前显示内容，不改变重命名建议。

本次界面重构按仓库约定仅检查桌面项目编译和静态诊断，未执行原生界面、模型推理或媒体输出回归。
