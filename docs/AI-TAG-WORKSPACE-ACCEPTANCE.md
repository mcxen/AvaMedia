## 原生操作

| 操作 | 结果 |
| --- | --- |
| 双模型峰值图 | 两模型同时显示，各自三条曲线；JoyTag 蓝色、EmbeddingGemma 绿色，实线、虚线和点线区分同模型标签；各自使用对应纵轴 |
| 自动排序 | 默认分别显示每个模型分数最高的三个标签；切换“当前画面”后排序随所选采样帧更新 |
| 标签阈值 | 0.40 → 0.70 时达标数 19 → 0，恢复后回到 19；曲线和标签即时刷新 |

| 场景阈值 | 0.55 → 0.75 时场景阈值线单独移动，JoyTag 阈值保持 0.40 |
| 模型切换 | 柱状图可在标签分数和场景相似度间切换，两模型曲线仍同时显示 |
| 曲线选择 | 取消一条 JoyTag 曲线后另一模型的三条曲线保留 |
| 时间定位 | 点击曲线并使用右方向键，定位到实际采样时间 4,644.979166 秒；播放器从这一位置打开、解码并继续播放，随后暂停并返回工作台 |
| 文本布局 | 标签和模型图例位于曲线下方，时间刻度根据可用宽度跳过会重叠的中间标签；结果图没有浮动标签遮挡 |
| 悬停读数 | 曲线的实际采样时间和两个模型分数显示在下方图例；柱状图峰值与平均分显示在图外正文 |
| TXT | 通过界面生成到源视频同目录，UTF-8，标题含标签；正文包含 19 行分数、模型、阈值和达标采样时间 |
| TXT 更新 | 阈值改为 0.70 后更新成“未命中标签”报告，恢复后重新生成标签标题；始终只保留一份所属报告，无临时写入文件残留 |
