# 音频输出配置

适用于视频转换、快速剪辑与音频转换的“输出配置 → 音频”。本次实现依据已保存的 FastCopy 音频页属性；回声和降噪使用独立 FFmpeg 算法，尚未证明与格式工厂的白金效果参数相同。

## 编码与音轨

视频编码器和音频编码器均可分别选择 `copy`。例如视频选择 copy，音频选择 AAC 并调整音量，可保留原视频包；音频选择 copy，视频重新编码，可在缩放画面时保留原音频包。

音频 copy 与采样率、声道和音频滤镜转换互斥；视频 copy 与画面滤镜互斥。输出配置确定时校验这些组合。快速剪辑的 Fast Copy 配置显示锁定的两个 copy 编码器；添加需要处理的参数后，外层快速剪辑切换为 MP4 并显示原因。

采样率和声道的“默认”表达保持源参数；音频编码器会根据容器决定可选项。Opus 重新编码使用 48000 Hz。实际能否编码取决于配置的 FFmpeg 构建。

“保留全部音轨”在支持多个音轨的输出容器中提供。普通转换与快速剪辑可保留所有输入音轨；混流可保留第二个输入的全部音轨；音轨提取可输出到多音轨容器。合并和混音当前生成合成音轨，不能使用保留全部独立音轨选项。单音轨容器会拒绝该配置。默认仍选择首个音轨，保持已有流程。

## 音量与音效

- 音量以百分比输入，100% 表示原音量，50% 对应倍率 0.5。
- 音频淡入、淡出独立于视频页的画面淡入、淡出。音频值显式设为 0 时，不会跟随画面效果。
- 回声使用 80 毫秒延迟，输入/输出增益为 0.8/0.9、衰减为 0.35，并裁去额外尾音以保持所选时长。[FFmpeg aecho](https://ffmpeg.org/ffmpeg-filters.html#aecho)
- 降噪使用 FFT 降噪，设置 12 dB 降噪、-35 dB 初始噪声底并开启噪声跟踪。效果随信号和噪声变化；不是人声分离。[FFmpeg afftdn](https://ffmpeg.org/ffmpeg-filters.html#afftdn)
- 反向仅处理所选音频区间，画面继续按原方向输出。先裁出区间再反向，避免从未选中的媒体尾部取音频。该滤镜需要缓存所选音频。[FFmpeg areverse](https://ffmpeg.org/ffmpeg-filters.html#areverse)

预览显示原媒体，以上效果在输出时生效。旧队列/预设未包含独立音频淡入淡出字段时保留过去的联动行为；从新配置页确认后记录显式的音频时长。参数持久化到预设与队列，取消配置不会改变调用方草稿。

## 验证与平台状态

专项项目：[AvaMedia.AudioOptionsTests](../tests/AvaMedia.AudioOptionsTests/Program.cs)。生成自己的双音轨视频、幅度阶梯、脉冲和白噪声音频，验证音轨数与语言标签、音视频包哈希、采样率/声道、完整 PCM 反转与区间反转、音频淡入淡出包络、延迟回声和噪声能量变化。还检查五个页签、百分比、Copy 冲突、草稿隔离、预设保存与浅深色界面。

2026-10-05 Windows 验证：32 项专项检查通过；快速剪辑回归 48 项通过；通用转换回归 75 项通过。实际报告分别位于 `artifacts/audio-options-20261005-192824/report.json`、`artifacts/quick-clip-20261005-192843/report.json`、`artifacts/verification-20261005-192728/report.json`。浅深色输出配置 PNG 位于音频专项报告目录，已人工查看布局。

这些参数处理位于共享 C# / FFmpeg 引擎，未引入平台专属滤镜依赖。本轮只有 Windows 实测证据；macOS 的声音预览、采集后端和真机验收仍待完成，不能将上述检查直接视为双平台支持完成。
