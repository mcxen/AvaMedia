# 文档功能图标

文档页的八个入口使用各自的功能图案，不再借用影音合并、影音分离或光盘图标。

| 入口 | 图案含义 |
|---|---|
| PDF 合并 | 两个输入页、加号与一个合并后的页 |
| PDF 拆分 | 一个输入页分流成两个独立页 |
| PDF → TXT | PDF 页转换为纯文本行 |
| PDF → DOCX | PDF 页转换为带排版段落的文档 |
| PDF → XLSX | PDF 页转换为绿色表格网格 |
| TXT → PDF | 文本行转换为固定版式 PDF 页 |
| 压缩 ZIP | 文件进入拉链归档 |
| 解压 ZIP | 文件从归档取出到文件夹 |

Light / Dark 使用 v2 系列，Mac OS 9 使用单独生成的像素轮廓系列。每枚均由内置图像生成工具以相应 rotate.png 为风格参考独立生成透明 PNG，原图复制后保持不变。新增素材、完整提示词、尺寸及 SHA-256 保存在两系列目录的 documents.manifest.json；总 manifest 中也追加对应条目。TXT / DOCX / XLSX / PDF 标签由 FeatureIcon 绘制在目标页的位置。

功能目录的 Icon 映射、资源注册和实际绘制均已接入。素材两端共用，macOS 的原生显示仍需真机验收。当前只执行相关编译和必要静态检查，不运行界面截图或功能回归。
