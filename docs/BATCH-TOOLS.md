# 批量媒体工具

入口：主窗口 **工具集 → 批量重命名 / 多宫格截图**。两个工具使用独立窗口。

## 导入文件

重命名支持图片和视频混合多选、文件夹和拖入文件；截图工具只接受视频。勾选“包含子文件夹”可递归导入；跳过隐藏、系统和链接目录。列表勾选决定实际处理范围，选中行用于移除。重命名可按导入顺序、名称或修改时间排序，序号按勾选文件的当前列表顺序生成。

## 批量重命名

左侧按用途选择工具，中间逐行比较原文件名与新名称，右侧调整规则顺序和参数。规则可以重复添加、启用或停用、上下移动，并保存为 JSON 预设或重新载入。修改参数、勾选或排序后自动更新预览；只有点击“执行重命名”才在原目录更名。

| 分类 | 操作 |
| --- | --- |
| 名称与文本 | 命名模板、添加文本、普通 / 正则替换、删除 / 移动字符 |
| 规范与清理 | 大小写、去除首尾空白、合并空白、空白转下划线、删除空白 |
| 编号与日期 | 起始序号、递增步长、补零位数；创建 / 修改时间及自定义日期格式 |
| 扩展名 | 设置扩展名、调整扩展名大小写；仅改名，不转换文件格式 |
| 媒体信息 | 宽度、高度、时长与模板组合；按需读取媒体信息 |
| 智能命名 · Beta | 本地关键词匹配，支持图片和视频；详见 [模型说明](MODELS.md#关键词匹配重命名) |

模板支持 `{name}`、`{index}`、`{parent}`、`{ext}`、`{size}`、`{width}`、`{height}`、`{duration}`、`{modified:yyyyMMdd}`、`{created:yyyyMMdd}` 和 `{keyword}`。`{name}` 取前序规则处理后的名称，扩展名默认保留。大小按字节、时长按秒；图片时长为 0。位置从 0 开始，字符操作按完整 Unicode 字符计算，移动位置对应删除所选字符后的名称。

例如模板 `旅行_{index}` 配合起始序号 1、位数 3，混合列表可生成 `旅行_001.jpg`、`旅行_002.mp4`。也可用 `{name}` 模板，再依次添加“清理空白”“替换文本”“自动编号”。工具分类参考 [Ant Renamer](https://www.antp.be/software/renamer/features)，即时预览参考 [PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)。

重名、已有目标和无效名称在对应行显示错误，悬停查看原因；存在错误时不能执行。执行前再次检查系统保留名称、越界路径和源文件是否改变。先暂存全部文件，再分配目标名称，支持交换名称；运行异常时回滚已经移动的文件。点击“撤销上一次重命名”可恢复上一次成功操作，恢复前再次验证文件及目标名称。

成功操作记录位于 `%LOCALAPPDATA%\AvaMedia\batch-rename.json`，执行中的恢复记录位于同目录的 `batch-rename.json.pending`。操作异常中断或进程崩溃后如存在未完成的 `in-progress` / `recovery-required` 状态，记录包含原路径、暂存路径和目标路径，供人工恢复；处理恢复记录前禁止新操作覆盖它。已完整回滚的失败操作保留上一次成功记录，仍可撤销。批量工具打开时暂停主窗口交互，成功重命名或撤销后同步转换队列内的输入路径。

## 多宫格帧截图

每个视频独立生成拼图，支持 2×2、3×3、4×4、5×4 或自定义 1–10 行列。可设置单格长边 / 短边上限、每视频 1–100 张拼图、开始/结束秒数、时间戳和 JPG/PNG。结束秒数 0 表示视频末尾。抽帧时间均匀分布在设定区间内，多个拼图共同覆盖该区间，图片中从左到右、从上到下按时间排序。

格子按每个视频的原始显示宽高比自动计算，横屏、竖屏、方形和宽银幕均等比例缩放，保留完整画面；不补黑边，格子之间和整张图片外围也不增加间隔或外框。默认 320 / 180 上限下，16:9 视频每格为 320×180，9:16 视频每格为 180×320，方形每格为 180×180。显示比例包含视频旋转信息和非方形像素比例。多个视频轨时使用探测到的首个视频轨。

输出命名为 `视频名-grid-列x行-序号.jpg/png`；名称冲突时追加序号，不覆盖既有输出。遇到无视频轨、不可读取时长或损坏媒体时标记当前视频失败并继续下一项。点击“停止”取消后续处理，已生成拼图保留；临时帧在任务完成或取消后清理。

通过工程已有 FFmpeg / FFprobe 外部进程完成探测、抽帧和拼图，不新增第三方库或内置二进制。所选 FFmpeg 需包含 `scale`、`setsar`、`tile`，开启时间戳时还需 `drawtext`。像素比例处理参考 [FFmpeg 官方 scale 文档](https://ffmpeg.org/ffmpeg-filters.html#scale)，旋转遵循 [FFmpeg autorotate](https://ffmpeg.org/ffmpeg.html#Advanced-Video-options)，拼图参考 [tile 文档](https://ffmpeg.org/ffmpeg-filters.html#tile)。

## 验证

独立集成验证项目：`tests/AvaMedia.BatchTests`。覆盖目录递归与去重、命名模板、重名与越界拒绝、重命名/撤销/名称交换/失败回滚、实际横竖屏抽帧、拼图尺寸、多张 JPG/PNG 输出、避免覆盖与取消处理。测试仅操作自动生成的独立测试目录。
