# 批量视频工具

入口：主窗口 **批量 → 视频重命名 / 多宫格截图**。

## 导入视频

支持多选视频、多选文件夹、拖入视频或文件夹。勾选“包含子文件夹”可递归导入。按扩展名筛选视频、去重；跳过隐藏目录、系统目录和链接目录。列表勾选决定实际处理范围，选中行用于移除或查看已生成的拼图。

## 批量重命名

输入命名模板、前后缀、文本替换规则、起始序号和补零位数，点击“预览新名称”。支持 `{name}`、`{index}`、`{parent}`，保留视频扩展名，在原目录中更名。例如 `片段_{index}` 配合起始序号 1、位数 3，可生成 `片段_001.mp4`。

执行前检查重名、已有文件、系统保留名称、越界路径和预览后源文件的变更。先暂存全部文件，再分配目标名称，支持交换名称；运行异常时回滚已经移动的文件。点击“撤销上一次重命名”可恢复上一次成功操作，恢复前再次验证文件及目标名称。

成功操作记录位于 `%LOCALAPPDATA%\AvaMedia\batch-rename.json`，执行中的恢复记录位于同目录的 `batch-rename.json.pending`。操作异常中断或进程崩溃后如存在 `in-progress` / `recovery-required` 状态，记录包含原路径、暂存路径和目标路径，供人工恢复；应用不会自动覆盖或删除这些视频。失败的操作保留上一次成功记录，仍可撤销。批量工具打开时暂停主窗口交互，成功重命名后同步转换队列内的输入路径。

## 多宫格帧截图

每个视频独立生成拼图，支持 2×2、3×3、4×4、5×4 或自定义 1–10 行列。可设置单格尺寸、每视频 1–100 张拼图、开始/结束秒数、时间戳和 JPG/PNG。结束秒数 0 表示视频末尾。抽帧时间均匀分布在设定区间内，多个拼图共同覆盖该区间，图片中从左到右、从上到下按时间排序。竖屏等比例缩放并补黑边。

输出命名为 `视频名-grid-列x行-序号.jpg/png`；名称冲突时追加序号，不覆盖既有输出。遇到无视频轨、不可读取时长或损坏媒体时标记当前视频失败并继续下一项。点击“停止”取消后续处理，已生成拼图保留；临时帧在任务完成或取消后清理。

通过工程已有 FFmpeg / FFprobe 外部进程完成探测、抽帧和拼图，不新增第三方库或内置二进制。所选 FFmpeg 需包含 `scale`、`pad`、`tile`，开启时间戳时还需 `drawtext`。实现参考 [FFmpeg 官方 tile 滤镜文档](https://ffmpeg.org/ffmpeg-filters.html#tile)。

## 验证

独立集成验证项目：`tests/AvaMedia.BatchTests`。覆盖目录递归与去重、命名模板、重名与越界拒绝、重命名/撤销/名称交换/失败回滚、实际横竖屏抽帧、拼图尺寸、多张 JPG/PNG 输出、避免覆盖与取消处理。测试仅操作自动生成的独立测试目录。
