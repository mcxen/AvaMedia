# 空闲内存

2026-10-07 调整以下资源的持有范围，适用于 Light、Dark 和 Mac OS 9；不改变布局、播放器快捷键或转换参数。

- 功能图标按实际显示尺寸和屏幕 DPI 解码，使用 32 / 64 / 128 / 256 像素档位。相同皮肤、图标与尺寸的活动控件共享位图；控件移除、隐藏或更换皮肤后释放引用，最后一个使用者释放时销毁位图。文档图标共用同一缓存，不再重复缓存。窗口图标使用弱键关联，关闭窗口清除其图像引用。
- 默认浅色 / 深色窗口不加载只用于经典标题栏的应用 PNG；经典标题栏的 16 DIP 应用图像改为 64 像素解码，覆盖 4× DPI。
- 播放器 BGRA 缓冲由当前播放对象持有，按实际帧大小分配；定位复用同一缓冲，停止、播放结束或关闭播放器时释放引用。大帧不再归还进程级共享数组池，因此关闭播放器后不会由该池继续保留。暂停保留当前会话和帧，恢复无需重新启动解码进程。
- 队列窗口最小化或隐藏到托盘时，取消活动的封面读取并销毁封面位图；恢复窗口后只为可见任务行重新读取。后台转换继续运行。行摘要只保留时长、尺寸、帧率和编码信息，不缓存可能含大量章节的完整 FFprobe JSON；编辑器和转换引擎仍读取完整信息。
- 队列计时器仅在任务运行期间启动，空闲时停止；耗时标签仅在显示秒数变化时更新。语言注册表定期随新控件注册移除已经失效的弱引用，减少反复打开工具后留下的登记项。
- 完整任务日志写入应用数据目录下的 `logs/<任务 ID>.log`，写入和追加均原子替换文件；任务对象和内部 `queue.json` 只保存最后一个非空行的摘要，最多 512 字符。队列失败时将完整异常追加到日志，任务错误只保留摘要，避免完整 FFmpeg 错误仍由 `Error` 字段持有。查看日志时异步读取全文，不把读取结果缓存回任务；队列保存和启动读取也直接使用文件流，避免额外保留整份 JSON 字符串。移除、清空或重试任务时删除对应日志。显式导出仍包含完整日志，逐任务读取和写出；导入逐条解析、分配新任务 ID 并将日志落盘，解析失败清理本次导入的日志文件。此调整不包含旧队列内嵌日志的迁移。

尺寸预算：单张 64 × 64 BGRA 图标的像素存储为 16 KiB，256 × 256 为 256 KiB；1280 × 720 播放帧为 3,686,400 字节。以上是资源尺寸计算，不是进程内存测量；实际占用还包括 Avalonia / Skia、字体、活动窗口和 .NET 堆。托盘隐藏会释放预览，但主窗口本身仍保留，以便快速恢复。

本次验证限定为 `AvaMedia.Desktop` 及其 Core 依赖的 Release 编译和静态差异检查。未执行性能、内存、媒体输出、截图或功能回归测量，不提供未经实测的进程占用数值。
