# 模型安装

YuNet 人脸检测模型继续内嵌到 Core，不下载。LaMa 图片修复模型在正常首次启动时后台安装，主窗口和独立播放器显示简短进度，其他功能可继续使用。已安装的文件大小与 SHA256 校验通过后，不再请求网络。模型保存在用户本地应用数据目录的 `AvaMedia/models/inpainting_lama_2025jan.onnx`。

下载优先使用 Hugging Face 的稳定 `resolve` 入口，让服务自动跳转到 CDN；不会保存签名有期限的 CDN URL。首个请求失败后重新请求新跳转，仍失败才请求用户提供的飞猫盘解析入口。该入口返回下载重定向，HTTP 客户端跟随它获取文件。全部失败后显示安装失败与重试按钮，下次启动也会重新尝试。

每次下载限制连接、无数据等待和总时长；写入同目录临时文件，严格检查 92591623 字节大小与 `7df918ac3921d3daf0aae1d219776cf0dc4e4935f035af81841b40adcf74fdf2` 校验值，成功后才替换正式文件。退出应用会取消下载；临时文件在此次请求结束时移除。截图及播放器基准入口不触发安装。

这次接入的是模型安装与缓存，LaMa 图片修复推理和编辑入口尚未接入。来源、模型许可及校验信息保存在 `licenses/lama/`。
