# 界面参考图说明

这些图用于结构、层级和控件角色参考；当前规则以 [UISPEC.MD](../../UISPEC.MD) 的编号条目为准，视觉数值以 AvaMedia.Controls 默认和平台 / 窗口专项令牌为准。

- `desktop-video.png`、`remote-demo-create-desktop.png` 及其他图中的独立“导出帧”入口已无效。单帧导出只从播放器“截取当前帧”进入（10.6），工具数由当前 Catalog 与 Beta 设置决定，不复制图中数量。
- 桌面主窗口保留侧栏与持久队列，工具及任务详情为无 Owner 独立窗口（1.3、3、8）；`remote-demo-desktop.png` 右侧检查器仅适用于远程网页（11.1）。
- 浅色参考图表达主要设计方向；默认验收只截深色、zh-CN（14），不能据此宣称其他皮肤已验收。图片中的键帽、搜索等过期内容不覆盖第 1 节禁令。
- 视频比例以 10.4 为准，不从图片读出固定 16:9；投影跟随真实内容。纸页、音频、双页 / 全屏 / VR 舞台按 10.12。
