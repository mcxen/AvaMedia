# 组件库圆角与背景源码审计

范围：AvaMedia.Controls 全部 33 个 ControlTheme、组合控件及桌面宿主样式；同时检查 FileUi 使用点与远程网页控件模板。检查常态、悬停、按下、选中、焦点、禁用及弹出背景的绘制位置、圆角、裁切与投影。

本次是源码审计与相关编译检查，没有运行界面截图、像素比较、功能回归、媒体验证或性能测试，不代表这些项目已验收。

| 类别 | 源码结论及处理 |
| --- | --- |
| 按钮、切换按钮 | 外层 face 原本已圆角；宿主仍向内部内容区绘制矩形反馈。给组件内容区加 ac-content 标记，排除 SimpleTheme 专用规则；主窗口胶囊与编辑器帧按钮的专项底色改绘制在 face。背景过渡也跟随实际绘制层。 |
| 下拉框、可编辑组合框 | 模糊与 XAML 圆角是不同层。改为清除原生窗口底色，并只对原生模糊视图同步表面的位置、尺寸和圆角；保留独立的内容与投影。无法取得模糊视图时使用透明宿主和主题画刷。 |
| 复选框、单选框、开关 | 填色直接作用于圆角选择框、圆形选择框或开关表面，未发现额外矩形状态底色。 |
| 数值步进器 | 步进区域已有圆角裁切；内部文本字段沿用修正后的 TextBox 裁切。 |
| 文本框 | Simple 继承模板的背景在圆角 border，增加子内容裁切，保留外层焦点与错误投影。 |
| 滑块、范围滑块 | 轨道与旋钮独立绘制，未发现同类矩形背景；旋钮投影继续独立显示。 |
| 进度、阶段与状态图标 | 进度轨道已有圆角裁切；状态图形直接绘制。阶段卡片加入统一子内容裁切。 |
| 分段、标签栏 | 分段内部内容区曾受到宿主普通列表选中底色影响，现排除该内容区；状态仍绘制在 segmentFace。标签指示线和透明标签背景保持原角色。 |
| 状态胶囊、徽标 | 填色在圆角 Border，加入统一子内容裁切。 |
| 卡片、设置分组、列表 | 分组 ClipToBounds=True 曾被后置样式覆盖。统一改为仅裁切子内容，保留外层投影；首尾行、零内边距卡片不会越过表面圆角。普通列表和树头使用相同规则。 |
| 菜单、子菜单、提示、气泡、Sheet、通知 | 浮层内容与投影分层；子菜单表面样式改为仅匹配 submenuSurface，避免匹配内部任意 Border。气泡箭头放入实际 6 DIP 布局空间；通知色条随内容一起裁切。 |
| 空状态、滚动条、展开器与树控件 | 空状态和透明容器未发现额外背景；滚动轨道矩形为既有角色，滑块保持圆角；树头和展开表面使用统一子内容裁切。 |
| 远程网页 | 按钮反馈已在 face，内部内容区透明；本次未发现需要修改的同类按钮底色规则。 |

子内容裁切与已有内容 Clip 取交集，布局、圆角或内容变动时更新；拆卸或关闭后恢复原状态。均匀和非均匀圆角均由组件内容裁切支持；原生模糊的非均匀圆角走主题画刷回退。

依据：[UISPEC 7.9.7、7.9.9](../../UISPEC.MD)、[Avalonia Border 圆角裁切实现](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/src/Avalonia.Controls/Border.cs)、[原生窗口透明度实现](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/native/Avalonia.Native/src/OSX/WindowBaseImpl.mm)、[原生模糊视图](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/native/Avalonia.Native/src/OSX/AutoFitContentView.mm)。
