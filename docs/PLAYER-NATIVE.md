# 高分辨率与原盘播放

天池播放器默认对 3840 像素宽、2160 像素高及以上视频，或带 HDR / Dolby Vision 标记的视频，使用原生播放引擎。设置菜单可关闭“4K / HDR 优先原生播放”；“原生 GPU / HDR 播放…”也可手动打开当前文件。

## 原生模式

原生模式打开独立的 mpv 播放窗口，暂时隐藏天池窗口，停止内嵌解码器。关闭原生窗口后返回天池播放器，保留最后播放位置。原生窗口使用以下键位；选轨、字幕等操作仍可使用 mpv 控制栏与其他默认快捷键。删除与 VR 控件用于内嵌模式。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+E / Cmd+E | 当前视频帧截图为 PNG，保存到正在播放的视频目录 |
| Space | 播放 / 暂停 |
| Enter / Alt+Enter / F11；Esc | 切换全屏；关闭快捷键说明或退出全屏 |
| ← / →；Shift+← / →；Ctrl/Cmd+← / → | 后退 / 前进 5、30、60 秒 |
| ↑ / ↓；M | 音量每次调整 5%，范围 0–100%；静音 |
| X / C；Z | 每次减速 / 加速 0.1×，范围 0.25–4×；切换正常 / 上次速度 |
| D / F | 暂停并定位前 / 后一帧 |
| Backspace / Home；F4 | 回到起点；暂停并回到起点 |
| Page Up / Down；F6 | 上一 / 下一文件；显示播放列表 |
| F1；Q | 显示 / 隐藏快捷键；关闭原生窗口 |

截图使用当前文件名、播放时间和递增序号，例如 `视频名_截图_00-00-03.125_0001.png`，已有文件不覆盖，不包含窗口、控件或字幕。切换目录中的文件后，截图目录跟随当前视频；原盘截图保存在所选原盘目录或 ISO 所在目录，目录无法写入时由原生窗口显示错误。快进、音量和倍速支持按住连续调整；截图、暂停、全屏、逐帧和文件切换每次按下执行一次。

客户端内置快捷键脚本随每次原生播放加载，退出时清理本次会话的临时文件，不修改用户的 mpv 配置。

引擎锁定 [mpv 0.41.0 官方 Release](https://github.com/mpv-player/mpv/releases/tag/v0.41.0)，首次使用从官方发布下载，经过固定大小与 SHA256 校验后解压到当前用户的 `AvaMedia/Player/mpv-0.41.0` 缓存。Windows x64 下载约 37.2 MiB；macOS 14 及以上的 Apple Silicon 下载约 41.7 MiB。运行包不放入客户端安装包；安装完成后复用缓存，下载失败可通过右下角气泡重试或停止。

其他系统或架构可用环境变量 `AVAMEDIA_NATIVE_PLAYER` 指定现有 mpv 可执行文件的绝对路径。这个入口使用指定程序自身的解码能力和系统要求。macOS 13.4 的客户端仍可使用内嵌播放；官方原生运行包要求 macOS 14。

原生渲染使用 `gpu-next` 与自动硬件解码，采用解码器自动线程数，避免通过 C# 管道逐帧复制 BGRA；硬件不支持的编码由 mpv 选择软件解码。前向缓存上限 128 MiB，后向缓存上限 32 MiB，不缓存整段视频。当前文件的起始位置、倍速、音量与静音传入原生引擎；首个视频渲染配置就绪后，把当前文件后面的列表追加为连续播放。IPC 同步播放位置、暂停状态和文件路径。

“解码与色彩信息…”展示最近一次原生会话实际报告的硬件解码器、输入 / 输出像素与色彩参数、丢帧计数。打开另一媒体时使用该媒体的解码信息；这些字段不能代替对显示器实际输出的测量。

## HDR

mpv 负责 PQ、HLG 和可处理的 Dolby Vision 色彩转换，开启自动输出色彩提示和 HDR 峰值分析。在 SDR 输出环境进行色调映射，也可勾选“原生播放输出为 SDR”固定 BT.709 / BT.1886、100 nit 输出目标。Windows 选择 D3D11 渲染上下文。

HDR 直出取决于显示器、操作系统 HDR 设置、驱动和 mpv 的渲染后端；不能把读取 HDR 视频标记等同于显示器已进入 HDR。根据 [mpv 输出色彩提示文档](https://mpv.io/manual/stable/#options-target-colorspace-hint)，D3D11 支持 HDR 色彩提示，macOS 上不承诺 HDR 元数据直出；可播放 HDR 内容并进行 GPU 色调映射。Dolby Vision 的支持也取决于源文件的配置与所选解码器。

内嵌模式的画面边界提高至 4096 × 2160，保留比例，不放大小视频；帧率按源帧率调度，上限 240 fps。PQ / HLG 先转线性浮点色彩，再映射至 BT.709 SDR；不直接把 HDR 像素当 SDR 显示。需要特殊 Dolby Vision 转换的源文件引导使用原生模式。支持的 H.264、HEVC、AV1、VP9 源优先尝试系统 VideoToolbox / D3D11VA，初始化失败且未交付首帧时回退软件解码。实际可解码格式由硬件和 FFmpeg 构建决定。剪辑器保留原有预览尺寸。

暂停跳转直接取得与播放相同滤镜链的解码帧，省去 PNG 编码与读取；暂停后保留会话，恢复无需再次定位解码。

## DVD / 蓝光原盘

菜单“打开原盘…”选择 DVD 或蓝光、目录 / 光驱路径或 ISO、标题编号；0 表示最长标题，其他值指定标题。拖入 `BDMV`、`VIDEO_TS` 或包含它们的目录也会识别原盘。直接打开 ISO 默认按蓝光处理，DVD ISO 应通过“打开原盘…”选择 DVD。

蓝光交给 mpv / libbluray，DVD 交给 mpv 的 DVD 标题协议。可播放引擎支持的目录、镜像和实体光驱标题；不提供光盘菜单，不集成 AACS / CSS 密钥或绕过保护。设备需要系统读取权限；实体光驱支持和受保护光盘的可读性由系统及上游库决定。协议与标题编号见 [mpv 光盘协议](https://mpv.io/manual/stable/#protocols)。

## 媒体引擎与验证范围

应用内 FFmpeg / FFprobe 构建锁更新至 [9.0.2](https://ffmpeg.org/download.html)，固定源归档 SHA256，Windows 与 macOS 共用源码版本；后续 Release 工作流构建实际运行包。原生 mpv 使用其官方发布包携带的库，与应用内 FFmpeg 构建分开维护。

本次进行了客户端相关 Release 编译、脚本语法和源码锁静态检查；下载归档仅用于核对结构与哈希。未运行媒体播放、HDR 显示、实体光驱或性能测试，不能据此报告播放帧率、性能提升幅度或 HDR 设备验收通过。
