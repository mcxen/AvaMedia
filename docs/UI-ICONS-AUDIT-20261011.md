## 共用实现

- `Styles/ButtonIcons.axaml` 在应用初始化时加载，匹配普通 `Button`，同时覆盖代码构建的 `Ui.Button` / `Ui.DialogButton` 与 AXAML 按钮。已有图标操作、步进按钮、缩略图、工具卡片、用户数据及显式自定义内容模板保留原处理；`.text-action` 可明确保留文字。
- `Assets/ToolbarIcons/ActionButtonIcons.json` 维护 **133 个完整动作名称**。只有能直接解释实际动作的图形进入映射，添加 SVG 时仍显示原文字；不按关键词或相似文字推断。中英文使用现有完整资源；译文对应不同图形时不添加图标。
- `ActionButtonTemplateConverter` 只选择按钮内容模板，不替换原始 Content、绑定、DataContext、点击事件、默认键或无障碍名称。按钮状态及语言改变时重新选择正确图标；文件名、路径和复杂功能不套图标。
- `StableLayout` 为有状态的文字按钮同时预留 16 DIP 图标和 6 DIP 间距，内容模板或语言变化时更新保留宽度。
- `LucideIcon` 复用看图工具使用的原始 SVG 几何与缓存，颜色绑定实际按钮前景色。`ActionIcon` 在浅 / 深主题使用同一绘制；Mac OS 9 与 Windows XP 的已有操作图形继续由各自绘制。播放器的打开文件按钮从弹出光盘图形改为打开文件图形。
- WiFi 传文件手机页面的选择、上传、取消、清空、保存、刷新、列表移除与下载使用同一套本地 SVG + 原文字；动态图标由 DOM 构建，不拼接文件名 HTML。
- 64 个原始 SVG 来自固定 `lucide-static` 1.55.0，完整包 SHA-512 和每个 SVG 的 SHA-256 记录在 `sources.json`；本地嵌入资源，不需要联网或图标字体，沿用 ISC / MIT 许可证声明。

| 原来 | 现在 | 原因 |
| --- | --- | --- |
| 多数内部操作只有文字，各工具分别构建 | 明确的共用动作显示 Lucide SVG + 原文字 | 操作可辨认且保留范围说明 |
| 通用齿轮 / 任意符号容易掩盖具体功能 | 未列入映射的功能继续使用文字 | 不引入含义不明的图标 |

| 打开文件使用弹出光盘图形 | 打开文件图形与原动作提示 | 图形与操作相符 |
