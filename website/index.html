开始之前。

阅读完整文档
AvaMedia 是开源的吗？

是。原创代码采用 AGPL-3.0-only 许可证，可以在 GitHub 查看源码、报告问题与参与开发。

需要另外安装媒体引擎吗？

Release 安装包包含 .NET 运行时、FFmpeg / FFprobe、yt-dlp 和 QuickJS-NG。无需另装 SDK、Python 或媒体引擎。

macOS 第一次打开需要注意什么？

打开 DMG，把“天池万象转换.app”拖入 Applications。目前仅提供 Apple Silicon ARM64 包，声明最低 macOS 13.4。应用采用 ad-hoc 签名，尚未进行 Developer ID 签名和公证，首次打开可能需要在系统设置的“隐私与安全性”中允许打开。

有哪些使用边界？

Fast Copy 的剪辑起点受关键帧限制；HEIC 压缩处理静态主图；PDF 文本提取不重建原始排版。视频下载受站点、账号和网络条件影响。详细范围与已验证状态见功能说明。
