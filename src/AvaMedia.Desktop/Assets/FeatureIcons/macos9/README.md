# AvaMedia Mac OS 9 专属功能图标

20 款独立透明 PNG，由 Codex 内置 imagegen 分别生成。以 rotate.png 为风格锚点，使用像素阶梯轮廓、灰银色边框和蓝绿橙红功能符号。复制入项目时保留原图像素及 alpha。

选择 Mac OS 9 · Platinum 皮肤时自动使用本系列；Light / Dark 皮肤使用 v2。所有已有窗口实时切换，子窗口继承当前皮肤。格式文字仍由程序绘制。

| gear.png | 视频优化 |
